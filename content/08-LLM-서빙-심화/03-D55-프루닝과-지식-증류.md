큰 모델의 답변 품질은 만족스럽지만, 메모리를 많이 쓰거나 답변이 늦게 나올 수 있습니다. 이런 모델을 더 적은 자원으로 사용하려면 가중치를 줄이거나, 작은 모델이 비슷한 답을 하도록 학습시키는 방법이 필요합니다.

여기서는 **프루닝으로 모델의 일부를 제거하는 방법**과 **지식 증류로 작은 모델의 답변 품질을 높이는 방법**을 배웁니다. 제거할 대상을 고르는 기준부터 시작해, 줄어든 모델을 학습시키고 결과를 비교하는 과정까지 연결합니다.

## 학습 목표와 흐름

| 배울 내용 | 이해할 내용 |
|---|---|
| 프루닝의 종류 | 가중치 하나를 0으로 만드는 것과 층 전체를 제거하는 것의 차이 |
| 제거할 가중치 선택 | 가중치의 크기와 실제 입력을 함께 보는 이유 |
| 희소 저장과 연산 | 0이 많아진 모델의 저장 공간과 계산을 줄이는 방법 |
| 지식 증류 | 큰 모델의 답변이나 확률을 작은 모델의 학습에 사용하는 방법 |
| 결과 비교 | 프루닝과 학습이 답변 품질·메모리·속도에 미친 영향 |

## 자습

### 1. 프루닝과 지식 증류를 사용하는 상황

모델을 경량화할 때는 무엇을 줄일지부터 정합니다. 앞에서 배운 양자화는 가중치 하나를 표현하는 비트 수를 줄였습니다. 이번에 배울 Pruning(프루닝·가지치기)은 모델의 일부 가중치나 구조를 제거합니다.

가중치를 하나씩 골라 0으로 바꾸는 방법을 Unstructured pruning(비구조적 프루닝)이라고 합니다. 예를 들어 가중치 100개 중 50개를 0으로 만들면 희소성이 50%인 상태가 됩니다. 행렬의 행과 열 개수는 그대로이고, 계산에 기여하는 값이 줄어듭니다.

층·채널·헤드 같은 단위를 통째로 제거하는 방법은 Structured pruning(구조적 프루닝)입니다. 28개 층 중 8개를 제거하면 남은 20개 층으로 입력을 처리합니다. 이 경우에는 모델의 구조 자체가 작아집니다.

한편, 이미 준비된 작은 모델의 답변 품질을 높이고 싶을 때는 Knowledge distillation(지식 증류)을 사용할 수 있습니다. 큰 모델을 Teacher model(교사 모델), 작은 모델을 Student model(학생 모델)로 두고 교사가 만든 정보를 학생의 학습에 사용합니다. 프루닝한 모델을 학생으로 삼아 품질을 회복시키는 데도 활용합니다.

### 2. 프루닝에서 제거할 가중치를 선택하는 방법

비구조적 프루닝은 일부 가중치를 0으로 바꾸어 계산에 사용하는 가중치를 줄입니다. 이때 답변 품질을 최대한 유지하려면 **어떤 가중치를 제거했을 때 출력이 적게 달라지는지** 판단해야 합니다. 그래서 제거할 가중치가 출력에 얼마나 기여하는지 살펴봅니다.

선형 계층은 입력 특징과 가중치를 곱한 뒤 그 결과를 더합니다. 입력이 $X$, 가중치가 $W$라면 출력은 다음과 같습니다.

$$Y=XW^{\mathsf T}$$

가중치 하나를 0으로 만들면 그 가중치와 입력을 곱한 항이 사라집니다. 예를 들어 어떤 항이 출력에 0.01을 더하고 있었다면, 그 가중치를 제거했을 때 해당 출력은 0.01만큼 달라집니다.

**Magnitude pruning(크기 기준 프루닝)**은 가중치의 절댓값이 작은 순서로 제거합니다. 가중치만 있으면 적용할 수 있어 제거 기준을 이해하기 쉽습니다.

여기서 입력의 크기까지 함께 보면 더 많은 정보를 얻을 수 있습니다. 가중치가 0.02여도 입력이 100이면 출력에 더해지는 값은 2입니다. 가중치가 0.5이고 입력이 1인 항의 기여는 0.5입니다. 이 예에서는 더 작은 가중치가 출력에 더 크게 기여합니다.

**Wanda는 이 관계를 이용해 가중치의 크기에 해당 입력 채널의 크기를 곱한 점수를 매깁니다.** 입력 채널은 입력 벡터의 한 좌표입니다. 먼저 대표 문장들을 모델에 통과시켜, 각 채널에 어떤 크기의 값이 들어오는지 모읍니다. 이때 사용하는 문장이 Calibration data(보정 데이터)입니다.

여러 토큰에서 관찰한 입력 크기를 하나의 값으로 모으면 Wanda 점수는 다음과 같이 표현됩니다.

$$S_{ij}=|W_{ij}|\sqrt{\sum_t X_{tj}^{2}}$$

$i$는 출력 채널, $j$는 입력 채널, $t$는 관찰한 토큰 위치입니다. 제곱을 더하고 제곱근을 취한 부분은 L2 norm(L2 노름)이며, 해당 입력 채널의 값이 전체적으로 얼마나 큰지 나타냅니다.

Wanda는 각 출력 행에서 점수가 낮은 가중치를 골라 0으로 만듭니다. SparseGPT는 제거할 위치를 고르는 과정에서 남은 가중치도 조정합니다. 가중치를 없애며 생긴 출력 오차를 남은 가중치로 줄이려는 방법입니다.

| 방법 | 제거 대상을 고를 때 사용하는 정보 | 남은 가중치의 값 |
|---|---|---|
| 크기 기준 | 가중치의 절댓값 | 유지 |
| Wanda | 가중치의 절댓값과 입력 채널의 크기 | 유지 |
| SparseGPT | 보정 입력을 이용한 출력 오차 정보 | 오차를 줄이도록 조정 |

### 3. 프루닝한 가중치를 작게 저장하고 빠르게 계산하는 방법

제거할 가중치를 정했다면, 다음은 0이 많아진 행렬을 어떻게 저장하고 계산할지 정할 차례입니다. 일반적인 Dense tensor(밀집 텐서)는 모든 칸의 값을 저장합니다. 8×8 FP32 행렬은 그중 절반이 0이어도 64개 값을 보관하므로 256바이트를 사용합니다.

Sparse representation(희소 표현)은 남은 값과 그 위치를 저장합니다. 예를 들어 네 칸 중 두 칸만 남겼다면 두 값과 두 위치만 기록하는 식입니다. 계산할 때도 이 저장 방식을 읽을 수 있는 Kernel(연산 커널)이 필요합니다. 커널은 GPU에서 실제 수치 연산을 수행하는 코드입니다.

하드웨어가 처리하기 쉬운 규칙으로 0을 배치하는 방법도 있습니다. **2:4 sparsity(2대4 희소성)**는 연속한 가중치 네 개마다 두 개를 남깁니다. 이를 Semi-structured sparsity(반구조적 희소성)라고 합니다.

FP16 값 네 개는 64비트입니다. 두 값만 남기면 값에 32비트, 두 위치를 각각 2비트로 표시하면 위치에 4비트가 들어가 총 36비트가 됩니다. 이 예의 저장량은 원래의 56.25%입니다.

따라서 실제 자원 절약은 **제거할 위치 선택 → 희소 형식으로 저장 → 지원 커널로 실행**으로 이어집니다. 사용할 GPU와 실행 도구가 지원하는 희소 형식을 먼저 확인하면, 그 형식에 맞춰 제거 규칙을 정할 수 있습니다.

### 4. 층이나 채널을 제거해 모델 구조를 줄이는 방법

모델의 가중치 수와 계산 단계를 함께 줄이고 싶다면 구조적 프루닝을 사용합니다. Depth pruning(깊이 프루닝)은 층 수를, Width pruning(너비 프루닝)은 채널·뉴런·헤드 수를 줄입니다.

층을 제거할 때도 어떤 층을 고를지 기준이 필요합니다. 한 가지 방법은 각 층을 지나기 전과 후의 표현을 비교하는 것입니다. 입력과 출력의 변화가 작다면 제거 후보로 검토할 수 있습니다.

Transformer의 Residual connection(잔차 연결)은 입력에 층의 계산 결과를 더합니다.

$$h_{l+1}=h_l+F_l(h_l)$$

여기서 $h_l$은 층의 입력, $F_l(h_l)$은 그 층이 계산한 변화량입니다. Cosine similarity(코사인 유사도)로 입력과 출력 벡터의 방향을 비교하면, 그 층이 표현을 얼마나 바꾸었는지 점수를 만들 수 있습니다. 예를 들어 토큰별 $1-\cos(h_l,h_{l+1})$의 평균을 사용합니다.

후보 층을 제거하면 해당 층의 가중치·연산·KV 캐시가 함께 줄어듭니다. 나머지 조건이 같을 때 28층을 20층으로 줄이면 층별 KV 저장량은 원래의 약 71.4%가 됩니다. 임베딩과 출력층처럼 남겨 둔 부분은 계속 사용합니다.

층이 사라지면 뒤의 층이 받는 입력도 달라집니다. **Recovery fine-tuning(회복 학습)**은 남은 가중치를 추가로 학습해 이 구조에 적응시키는 과정입니다. 저장할 때는 실제 층 목록, 설정 파일의 층 수, 캐시에서 사용하는 층 번호도 새 구조에 맞춥니다.

### 5. 큰 모델의 답변을 작은 모델에 학습시키는 지식 증류

작은 모델로 문서 요약 서비스를 만들 때, 큰 모델이 작성한 좋은 요약을 학습 자료로 사용할 수 있습니다. 질문과 교사의 답변을 한 쌍으로 모으고, 학생이 같은 질문에서 그 답변을 생성하도록 학습시키는 방식입니다.

이처럼 완성된 답변 텍스트를 사용하는 방법이 **Sequence distillation(시퀀스 증류)**입니다. 학생은 질문과 앞의 정답 토큰을 보고 다음 정답 토큰을 예측합니다. 질문은 문맥으로 제공하고, 답변 위치의 예측 오차를 줄이도록 가중치를 학습합니다. 교사의 텍스트를 학생의 토크나이저로 다시 읽기 때문에 두 모델의 어휘가 달라도 자료를 만들 수 있습니다.

답변의 각 위치에서 정답 토큰에 높은 확률을 주도록 학습할 때 사용하는 손실은 다음과 같습니다.

$$\mathcal L=-\frac1N\sum_{t\in\text{답변 위치}}\log p_{student}(y_t\mid\text{질문},y_{<t})$$

$y_t$는 현재 위치의 정답 토큰, $y_{<t}$는 그 앞의 정답 토큰들입니다. 정답 토큰의 확률이 높아질수록 손실이 작아집니다.

교사가 답을 선택하기 전의 정보도 활용할 수 있습니다. 교사가 다음 토큰 후보 A·B·C에 각각 0.8·0.15·0.05의 확률을 주었다면, A가 가장 적절하면서 B도 어느 정도 가능하다고 평가한 것입니다.

**Logit distillation(로짓 증류)**은 학생이 이런 후보들의 확률 분포를 따라가도록 학습합니다. Logit(로짓)은 확률로 변환하기 전의 점수입니다. 점수를 Temperature(온도)로 나눈 뒤 Softmax(소프트맥스)를 적용하며, 온도를 높이면 분포가 완만해져 낮은 순위 후보의 차이도 학습에 활용하기 쉬워집니다.

두 분포의 차이를 계산할 때는 KL divergence(KL 발산) 등을 사용합니다. 같은 위치의 같은 후보를 비교할 수 있도록 교사와 학생의 토큰 대응을 맞춥니다. 정방향 KL은 교사의 확률을, 역방향 KL은 학생의 확률을 기준으로 차이에 비중을 둡니다.

| 방식 | 학생에게 주는 학습 정보 | 준비할 자료 |
|---|---|---|
| 시퀀스 증류 | 교사가 완성한 답변 | 질문과 답변 텍스트 |
| 로짓 증류 | 후보 토큰의 확률 관계 | 대응하는 토큰별 점수·확률 |

학생은 실제 답변을 만들 때 자신이 고른 토큰을 다음 입력으로 사용합니다. 그 과정에서 나타나는 문맥을 학습에도 반영하려면 **On-policy distillation(학생의 현재 생성 방식에 따른 증류)**을 사용할 수 있습니다. 학생이 직접 생성한 문맥에서 교사의 분포를 구해 학습하므로, 학습 도중에도 학생의 생성과 교사의 계산이 필요합니다.

### 6. 증류에 사용할 자료와 학습 결과의 확인

교사의 답변을 학생에게 가르칠 때는 답변의 내용과 형식을 먼저 확인합니다. 예를 들어 숫자를 계산하는 서비스라면 계산이 맞는지, JSON으로 응답해야 한다면 필드와 형식이 맞는지 검사합니다. 이렇게 준비한 학습 자료가 학생이 연습할 문제를 결정합니다.

학습 결과를 확인할 질문도 별도로 준비합니다. 학습에 사용한 질문과 새로운 질문을 나누어 두면, 학생이 새 질문에 얼마나 잘 답하는지 확인할 수 있습니다.

| 자료 | 사용하는 목적 |
|---|---|
| 보정 데이터 | 프루닝에 필요한 입력 통계 수집 |
| 학습 데이터 | 학생의 가중치 학습 |
| 검증 데이터 | 학습 도중 예측 오차와 학습 상태 확인 |
| 평가 데이터 | 완성된 모델의 답변·속도·메모리 비교 |

작은 추가 행렬만 학습하는 LoRA(저랭크 적응)를 학생 학습에 사용할 수도 있습니다. 기본 가중치를 고정한 채 추가 행렬로 변화량을 배우고, 필요하면 학습한 변화량을 기본 가중치에 합칩니다.

학습 도중에는 학습 손실과 검증 손실을 함께 봅니다. 학습 손실은 내려가는데 검증 손실이 올라간다면, 학습 자료의 예측은 좋아졌지만 검증 자료의 예측은 나빠진 상태입니다. 학습을 마친 뒤에는 평가 질문의 정답과 실제 답변을 확인합니다.

### 7. 프루닝과 증류의 효과를 비교하는 기준

경량화 결과를 이해하려면 무엇이 달라졌는지에 맞춰 비교 대상을 정해야 합니다. 프루닝 직후의 품질 변화와 이후 학습으로 회복한 정도를 따로 비교하면 각 단계의 효과가 드러납니다.

| 확인하려는 내용 | 비교할 모델 |
|---|---|
| 제거하면서 생긴 변화 | 원본과 프루닝 직후 모델 |
| 회복 학습의 효과 | 프루닝 직후와 회복 학습 후 모델 |
| 증류 학습의 효과 | 같은 학생의 학습 전과 후 |
| 서비스에 사용할 모델 선택 | 교사와 학습을 마친 학생 |

모든 후보에 같은 질문과 생성 설정을 적용하고, 정답 수·답변 형식·메모리·첫 토큰 시간·생성 속도를 비교합니다. 이전에 11개를 맞힌 학생이 맞던 문제 2개를 틀리고, 틀리던 문제 9개를 새로 맞혔다면 새 정답 수는 $11-2+9=18$개입니다. 이때 달라진 문항을 읽으면 어떤 유형의 답변이 좋아졌는지도 알 수 있습니다.

프루닝과 회복 학습을 마친 모델에 양자화를 적용해 가중치 저장량을 더 줄일 수도 있습니다. 앞 단계에서 모델이 달라졌으므로, 다음 단계의 보정 입력은 변경된 모델에 넣어 통계를 다시 구합니다. 각 단계의 결과를 같은 평가 질문으로 비교하면 최종 모델을 선택하기 쉽습니다.

## 이해 확인

> [!question]- Wanda가 가중치와 함께 입력의 크기를 보는 이유는 무엇인가요?
> 선형 계층의 출력에는 입력과 가중치의 곱이 더해집니다. 작은 가중치도 큰 입력과 곱해지면 출력에 크게 기여하므로, 두 값을 함께 사용해 제거 점수를 정합니다.

> [!question]- 가중치를 0으로 바꾼 다음 저장 공간을 줄이려면 무엇이 필요한가요?
> 남은 값과 위치를 저장하는 희소 표현이 필요합니다. 계산도 줄이려면 해당 표현을 처리하는 연산 커널을 사용합니다.

> [!question]- 프루닝한 모델에 회복 학습을 하는 이유는 무엇인가요?
> 제거 후에는 각 층이 받는 입력과 계산 경로가 달라집니다. 남은 가중치를 학습해 바뀐 구조에서 답변을 잘 만들도록 적응시킵니다.

> [!question]- 시퀀스 증류와 로짓 증류는 학생에게 무엇을 제공하나요?
> 시퀀스 증류는 완성된 답변 텍스트를, 로짓 증류는 후보 토큰들의 확률 관계를 제공합니다.

> [!question]- 증류로 학생이 좋아졌는지 확인하려면 어떤 모델을 비교하나요?
> 같은 학생 모델의 학습 전후를 같은 평가 질문과 생성 조건으로 비교합니다.
