## 1. 문장 요약을 배우는 이유

- 긴 글에서 필요한 내용을 빠르게 파악하려면 중요한 정보를 짧게 표현해야 한다.
- 글의 앞부분을 일정 길이로 자르면 뒤에 있는 핵심 사건이나 결론을 놓칠 수 있다.
- 요약 모델은 어떤 정보가 중요한지 판단하고, 제한된 길이 안에 그 내용을 담는다.
- **요약을 배우면 긴 입력을 읽어 새로운 문장을 출력하는 모델의 흐름을 이해할 수 있다.**

---

## 2. 추출적 요약과 생성형 요약

| 요약 방식 | 동작 |
| --- | --- |
| Extractive summarization(추출적 요약) | 원문에 있는 문장 가운데 중요한 문장을 골라 연결한다. |
| Abstractive summarization(생성형 요약) | 원문을 표현한 정보를 바탕으로 새 토큰을 하나씩 예측해 요약문을 만든다. |

### 원문과 추출 요약의 비교 예시

- 원문: `"시가 버스 노선 세 개를 신설했다. 새 노선은 다음 달부터 운행한다."`
- 추출적 요약: `"시가 버스 노선 세 개를 신설했다."`
- 생성형 요약: `"다음 달부터 신규 버스 노선 세 개가 운행한다."`
- 추출 방식은 원문 문장을 유지한다. 생성 방식은 여러 문장의 정보를 묶어 다시 표현할 수 있다.

## 3. TextRank와 summarize 함수의 활용

- 문서를 문장으로 나누고, 문장 사이의 유사도를 계산한다.
- 문장 하나를 점으로, 유사한 문장 사이의 관계를 연결로 표현한다.
- 다른 중요한 문장들과 많이 연결된 문장에 높은 점수가 가도록 반복 계산한다.
- 높은 점수의 문장을 골라 원문 순서에 맞춰 배치하면 요약문이 된다.
- 이것이 TextRank 기반 추출적 요약의 기본 흐름이다.
- 같은 주제를 반복하는 문장들을 고르기 쉬우므로, 결과를 읽을 때는 중복된 내용이 얼마나 포함됐는지도 살펴본다.

### summa.summarizer 모듈의 summarize 함수의 활용

- `article`은 여러 문장으로 구성된 기사 문자열이라고 가정한다.

- 추출적 요약은 원문 문장 중 중요한 문장을 골라 구성한다. TextRank는 문장 사이의 유사도 관계를 이용해 중요도를 계산하고, 선택 비율에 맞춰 문장을 남긴다.

**코드 예시**

```python
from summa.summarizer import summarize

summary = summarize(article, ratio=0.3)
```

**코드 해설**

- `ratio`는 선택할 문장의 비율을 조절한다. 글자 수의 정확히 30%를 잘라 내는 설정과는 다르다.
- `summary`에는 원문에서 선택한 문장들이 담긴다.
- 너무 짧은 입력처럼 문장을 충분히 고를 수 없는 경우에는 빈 결과가 나올 수 있다.

## 4. 생성형 요약의 본문·정답 쌍

- 학습 데이터 한 건은 긴 본문과 그에 대응하는 요약문으로 구성된다.
- 본문은 모델이 읽는 입력이고, 요약문은 모델이 맞혀야 하는 정답이다.
- Seq2seq(시퀀스 변환 모델)는 입력 토큰의 순서를 읽고 출력 토큰의 순서를 만드는 구조다.
- Encoder(인코더)는 본문을 읽어 정보를 벡터로 표현한다.
- Decoder(디코더)는 그 정보와 지금까지의 요약 토큰을 사용해 다음 토큰을 예측한다.
- 여기서 Sequence(시퀀스)는 토큰처럼 순서가 있는 데이터의 묶음이다. 본문과 요약문의 길이는 달라도 된다.

## 5. 디코더 입력과 한 칸 이동한 정답

- 정답 요약문이 `"버스 노선 신설"`이라고 하자. 이해를 위해 각 단어가 토큰 하나라고 가정한다.
- 디코더에는 문장 시작을 알리는 `<bos>`부터 넣는다.
- 각 위치의 정답은 그다음에 나와야 할 토큰이다.

| 구분 | 토큰 순서 |
| --- | --- |
| 디코더 입력 | `<bos> → 버스 → 노선 → 신설` |
| 맞혀야 할 정답 | `버스 → 노선 → 신설 → <eos>` |

- `<bos>`를 읽은 위치에서는 `버스`를 예측한다.
- `버스`까지 읽은 위치에서는 `노선`을 예측한다.
- 마지막 내용 토큰 뒤에는 `<eos>`를 예측해 문장을 끝낸다.

### Python 슬라이싱과 다음 토큰 학습 자료

- 다음 토큰을 예측하도록 학습하려면 입력 위치마다 바로 뒤 토큰을 정답으로 놓아야 한다. 같은 토큰열의 앞부분과 뒷부분을 한 칸 어긋나게 잘라 입력·정답 쌍을 만든다.

**코드 예시**

```python
sequence = [1, 7, 8, 9, 2]

decoder_input = sequence[:-1]
target = sequence[1:]
```

**코드 해설**

- 첫 위치에서는 시작 토큰 1을 보고 7을 예측한다. 다음 위치에서는 7을 보고 8을, 마지막 위치에서는 9를 보고 종료 토큰 2를 예측한다. 같은 열 위치의 입력과 정답을 짝지어 읽으면 된다.

- 여기서는 `1=<bos>`, `2=<eos>`, `7·8·9=내용 토큰`으로 정했다.
- `[:-1]`은 마지막 원소를 제외한다. 결과는 `[1, 7, 8, 9]`다.
- `[1:]`은 첫 원소를 제외한다. 결과는 `[7, 8, 9, 2]`다.
- 같은 문장에서 한 칸 이동한 입력과 정답을 만들면, 모델이 다음 토큰을 예측하도록 학습시킬 수 있다.

## 6. Attention과 본문 정보 참조

- 긴 본문을 벡터 하나에만 압축하면 서로 다른 내용을 충분히 전달하기 어렵다.
- Attention(어텐션)은 요약 토큰을 만들 때마다 본문의 각 위치를 얼마나 참고할지 계산한다.
- 인코더는 본문 각 위치의 벡터를 남긴다.
- 디코더는 현재 상태와 이 벡터들을 비교해 참고 비율을 구한다.
- 참고 비율로 본문 벡터를 섞어 현재 출력에 필요한 정보를 만든다.
- 예를 들어 `"세 개"`를 생성할 때는 본문에서 노선의 수를 설명하는 부분이 도움이 된다.
- 본문 패딩은 실제 내용이 없으므로 Attention에서 제외한다.

## 7. CrossEntropyLoss와 토큰별 손실

- 디코더는 매 위치에서 사전의 모든 토큰에 점수를 준다.
- Logits(로짓)는 확률로 바꾸기 전의 점수다.
- Cross entropy(교차 엔트로피)는 정답 토큰에 높은 확률을 주도록 학습시키는 손실이다.
- 사전에 토큰이 `V`개 있으면, 출력의 마지막 축 길이도 `V`다.
- 배치 크기가 `B`이고 정답 길이가 `T`라면 로짓은 `(B, T, V)`, 정답 번호는 `(B, T)` 형태가 된다.

### torch.nn 모듈의 CrossEntropyLoss 클래스의 활용

- `logits`와 `target`이 위 형태의 텐서이고, `pad_id`가 패딩 번호라고 가정한다.

- 토큰 생성은 각 위치에서 사전의 후보 중 정답 토큰을 고르는 분류 문제로 계산할 수 있다. 문장·위치 축을 합쳐 모든 유효 위치의 손실을 한 번에 계산한다.

**코드 예시**

```python
from torch import nn

criterion = nn.CrossEntropyLoss(ignore_index=pad_id)
loss = criterion(
    logits.reshape(-1, logits.size(-1)),
    target.reshape(-1),
)
```

**코드 해설**

- 예를 들어 문장 2개, 길이 3, 사전 크기 10이면 로짓은 `(2, 3, 10)`이다. 이를 `(6, 10)`으로 펼치면 토큰 위치 6개를 각각 10개 후보 중 하나로 분류하는 계산이 된다.

- `Tensor` 객체의 메서드인 `size(-1)`은 마지막 축 길이 `V`를 구한다.
- `reshape(-1, V)`는 각 문장의 각 위치를 모아 `(B × T, V)`로 바꾼다.
- 정답도 같은 순서로 펼쳐 `(B × T,)`로 맞춘다.
- `ignore_index`에 해당하는 정답 위치는 손실 계산과 평균에서 제외된다.
- 이 손실 함수가 내부에서 로그 확률을 계산하므로, 입력에는 로짓을 전달한다.

## 8. 학습과 생성에서 다음 입력의 차이

- 학습에서는 정답 요약문의 앞 토큰을 다음 입력으로 사용한다. 이를 Teacher forcing(정답 토큰을 입력하는 학습 방식)이라고 한다.
- 실제 생성에서는 아직 정답 요약문이 없다. 모델이 방금 선택한 토큰을 다음 입력에 붙인다.
- `<bos>`에서 시작해 한 토큰씩 생성하고, `<eos>`를 선택하거나 최대 길이에 도달하면 멈춘다.
- 앞에서 잘못 선택한 토큰이 뒤의 예측에도 영향을 줄 수 있다.
- 전체 흐름은 **본문 읽기 → 현재 요약을 바탕으로 본문 참고하기 → 다음 토큰 점수 계산 → 토큰 선택 → 입력에 추가**다.
