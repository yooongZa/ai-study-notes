## 1. 단어사전과 토크나이저가 필요한 이유

- 모델은 `"학교"`라는 문자열 대신 토큰 번호를 받아 계산한다.
- 학습할 때 `"학교"`가 7번이었다면, 사용할 때도 같은 토큰을 7번으로 바꿔야 해당 벡터를 찾는다.
- 번호를 배정하는 기준이 바뀌면 같은 숫자가 다른 표현을 가리키게 된다.
- **단어사전, 토큰화 규칙, 신경망의 임베딩은 서로 맞물려 동작한다.**

## 2. dict의 get 메서드와 토큰 번호 변환

### Python dict 객체의 get 메서드의 활용

- 모델은 토큰을 일정한 번호로 받아야 한다. 사전에 있는 토큰은 등록된 번호를 쓰고, 사전에 없는 토큰은 미등록 토큰 번호로 처리한다.

**코드 예시**

```python
vocab = {"<pad>": 0, "<unk>": 1, "나는": 2, "간다": 3}
tokens = ["나는", "학교에", "간다"]

ids = [vocab.get(token, vocab["<unk>"]) for token in tokens]
```

**코드 해설**

- 반복문은 `나는`을 찾아 2, 사전에 없는 `학교에`는 기본값 1, `간다`는 3으로 바꾼다. 각 결과를 순서대로 모은 목록이 `ids`다.

- `vocab`은 토큰을 키, 번호를 값으로 가진 Python 사전이다.
- `get(키, 기본값)`은 키가 있으면 그 값을, 없으면 기본값을 반환한다.
- `"학교에"`가 없으므로 결과는 `[2, 1, 3]`이다.
- `[... for token in tokens]`는 각 토큰에 같은 계산을 적용해 목록을 만드는 List comprehension(리스트 컴프리헨션) 문법이다.
- 번호를 문자열로 되돌리려면 `{번호: 토큰}` 방향의 사전도 필요하다.

---

## 3. 시작·종료·패딩·미등록 토큰의 역할

| 특수 토큰 | 필요한 이유 |
| --- | --- |
| `<pad>` | 길이가 다른 문장을 같은 크기로 묶을 때 빈 자리를 채운다. |
| `<unk>` | 사전으로 표현하지 못한 입력이 있음을 나타낸다. |
| `<bos>` 또는 `<sos>` | 생성 모델에 문장의 시작을 알려준다. |
| `<eos>` | 모델이 문장 생성을 끝내야 할 위치를 나타낸다. |

- 패딩은 빈 자리이고, 미등록 토큰은 실제 입력에 있었던 표현이다. 두 역할에 서로 다른 번호를 배정한다.
- 번호 자체는 설정에 따라 달라진다. 위 예시의 `<pad>=0`, `<unk>=1`은 설명을 위한 배정이다.
- SentencePiece에서는 `pad_id()`, `unk_id()`, `bos_id()`, `eos_id()` 메서드로 설정된 번호를 확인할 수 있다.
- 패딩 토큰을 사용하려면 토크나이저에서 패딩용 번호가 활성화되어 있어야 한다.

## 4. SentencePiece의 토큰화 규칙 학습

- SentencePiece는 문장 모음에서 사용할 조각과 토큰화 규칙을 학습한다.
- 학습 결과에는 토큰과 번호뿐 아니라 문자를 정규화하고 문장을 나누는 데 필요한 정보가 포함된다.
- Tokenizer training(토크나이저 학습)은 입력을 나누는 규칙을 만드는 과정이다.
- 신경망 학습은 그 입력으로 예측하고 손실을 줄이도록 가중치를 바꾸는 과정이다.

### BPE와 Unigram

- **BPE**는 작은 조각을 합쳐 가며 자주 쓰이는 조각을 만든다.
- **Unigram**은 여러 후보 조각으로 문장을 나눴을 때의 가능도를 계산한다. 말뭉치를 설명하는 데 기여가 적은 조각을 줄여 사전을 만든다.
- `model_type`은 사용할 알고리즘을 정하는 설정이다.
- `vocab_size`는 만들 사전의 크기를 정하는 설정이다.
- 사전이 작으면 한 표현이 여러 조각으로 나뉘어 문장이 길어지기 쉽다. 사전이 크면 임베딩과 출력층에 필요한 매개변수가 늘어난다.
- 예를 들어 임베딩 차원이 128이면, 사전 8,000개에는 `8,000 × 128`개의 임베딩 값이 필요하다.

## 5. SentencePieceProcessor의 인코딩·디코딩 메서드

- `sentencepiece` 모듈의 클래스인 `SentencePieceProcessor`는 학습된 토크나이저를 사용하는 객체를 만든다.
- 아래의 `sp`는 이미 학습된 모델을 불러온 `SentencePieceProcessor` 객체라고 가정한다.

- 문장을 토큰 조각으로 나누는 규칙과 각 조각의 번호는 함께 저장된다. 같은 토크나이저로 문자열 조각·모델 입력 번호·복원된 문장을 연결해 확인한다.

**코드 예시**

```python
text = "나는 학교에 간다"

pieces = sp.encode_as_pieces(text)
ids = sp.encode_as_ids(text)
restored = sp.decode_ids(ids)
```

**코드 해설**

- `sp`는 토큰화 규칙을 불러온 `sentencepiece.SentencePieceProcessor` 객체라고 가정한다. 같은 객체가 문장 나누기, 번호 변환, 문장 복원을 맡는다.
- 문자열 조각은 사람이 나뉜 결과를 확인할 때, 번호 목록은 모델 입력을 만들 때 사용한다. `decode_ids()`에는 앞에서 얻은 `ids`를 다시 넣는다.

- `encode_as_pieces`는 문장을 나눈 문자열 조각 목록을 반환한다.
- `encode_as_ids`는 같은 조각을 정수 번호 목록으로 반환한다.
- `decode_ids`는 번호 목록에서 텍스트를 복원한다.
- 실제 조각과 번호는 `sp`에 들어 있는 모델에 따라 달라진다.
- 복원 결과에는 토크나이저의 정규화 규칙이 반영된다. 연속된 공백 등을 정규화했다면 정규화된 문장으로 돌아온다.
- `id_to_piece(번호)`는 번호 하나에 해당하는 조각을, `piece_to_id("조각")`는 조각에 해당하는 번호를 찾는 메서드다.
- `get_piece_size()`는 토큰 사전의 크기를 반환한다.

## 6. pad_sequence 함수와 배치 패딩

- 두 문장의 토큰 번호가 `[4, 7, 2]`와 `[6, 2]`라면 길이가 각각 3과 2다.
- 같은 배치에 넣으려면 둘째 문장의 빈 자리를 채워 직사각형 형태를 만든다.
- Batch(배치)는 모델이 한 번에 처리하는 샘플의 묶음이다.

### torch.nn.utils.rnn 모듈의 pad_sequence 함수의 활용

- 길이가 다른 문장을 같은 배치로 계산하려면 짧은 문장에 빈 자리를 채워 직사각형 배열을 만든다. 패딩 번호를 따로 정하면 실제 내용과 채운 위치를 구분할 수 있다.

**코드 예시**

```python
import torch
from torch.nn.utils.rnn import pad_sequence

sequences = [
    torch.tensor([4, 7, 2]),
    torch.tensor([6, 2]),
]
batch = pad_sequence(
    sequences, batch_first=True, padding_value=0
)
```

**코드 해설**

- 결과는 `[[4, 7, 2], [6, 2, 0]]`이고 형태는 `(2, 3)`이다.
- `batch_first=True`는 첫 축을 문장 수, 둘째 축을 토큰 길이로 배치한다.
- `padding_value=0`은 빈 자리를 0으로 채운다. 여기서는 0이 패딩용 번호라고 가정한다.
- 함수에는 각 문장을 나타내는 **텐서의 목록**을 전달한다.
- `batch != 0`은 실제 토큰 위치를 `True`, 패딩 위치를 `False`로 표시한다. 뒤에서 실제 토큰만 계산에 사용하도록 구분할 때 쓴다.

## 7. 길이 제한과 패딩의 차이

- Padding(패딩)은 짧은 문장을 채우는 작업이다.
- Truncation(길이 자르기)은 정한 한도를 넘는 문장의 일부를 제거하는 작업이다.
- 문장 끝을 자르면 결론이나 부정 표현이 없어질 수 있다. 번역·요약에서는 어떤 정보가 잘리는지가 중요하다.
- 생성 문장의 끝을 표시하는 `<eos>`도 길이 한도 안에 들어갈 자리가 필요하다.
- 길이가 비슷한 문장끼리 배치로 묶으면 빈 자리를 적게 채워도 된다.

## 8. 학습과 예측에 같은 토크나이저를 사용하는 흐름

1. 학습용 문장에서 토큰화 규칙과 사전을 만든다.
2. 학습·검증·테스트 문장에 같은 토크나이저를 적용한다.
3. 토큰 번호를 텐서로 만들고 배치 안의 길이를 맞춘다.
4. 패딩 위치를 구분해 임베딩과 모델 계산에 전달한다.
5. 모델이 출력한 번호를 같은 사전으로 읽어 텍스트를 얻는다.

- 이미 학습된 언어 모델을 사용할 때는 그 모델과 함께 제공된 토크나이저를 사용한다.
- 토크나이저가 만든 번호와 임베딩의 행 번호가 일치해야 이 흐름이 이어진다.
