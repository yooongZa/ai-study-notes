## 1. Transformer를 배우는 이유

- RNN은 앞 토큰의 상태를 구한 다음에 뒤 토큰의 상태를 계산한다.
- 문장이 길면 이 순차 계산이 길어지고, 멀리 떨어진 단어의 정보도 여러 단계를 거쳐 전달된다.
- Transformer는 Attention으로 문장 안의 토큰들이 서로 참고할 정보를 직접 계산한다.
- 학습에서는 여러 위치의 계산을 행렬 연산으로 함께 처리할 수 있다.
- **핵심은 토큰의 표현에 다른 토큰의 정보를 필요한 비율로 반영하는 것이다.**

---

## 2. 토큰 임베딩과 위치 정보

- 토큰 임베딩만 사용하면 `"내일 출발"`과 `"출발 내일"`에 같은 벡터들이 순서만 바뀌어 들어간다.
- 기본 Attention 계산에는 위치 번호가 따로 들어 있지 않다.
- Positional encoding(위치 인코딩)은 토큰이 문장 안에서 몇 번째에 있는지를 나타내는 벡터다.
- 토큰 임베딩에 위치 벡터를 더하면 같은 토큰도 위치 정보를 함께 가진다.
- 두 벡터의 길이가 같아야 원소별로 더할 수 있다.
- 원래 Transformer는 위치마다 다른 사인·코사인 값을 사용했다. 차원마다 변하는 속도가 달라 여러 거리의 위치 관계를 표현한다.
- 학습 가능한 위치 임베딩을 사용하는 방식도 있다. 이때 위치 벡터의 값은 학습으로 조정된다.

---

## 3. Query·Key·Value의 역할

- Attention은 현재 토큰에 어떤 정보를 반영할지 계산한다.
- 이를 위해 입력 벡터를 세 가지 가중치로 각각 변환한다.

| 벡터 | 역할 |
| --- | --- |
| Query(질의) `Q` | 현재 위치에서 어떤 정보를 참고할지 비교하는 기준이다. |
| Key(키) `K` | 각 위치가 어떤 정보를 가졌는지 비교할 때 사용하는 표현이다. |
| Value(값) `V` | 비교 결과에 따라 실제로 가져와 섞을 정보다. |

$$
Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V
$$

- `X`는 입력 토큰 벡터를 행으로 모은 행렬이다.
- `W_Q, W_K, W_V`는 각각의 역할에 맞게 입력을 바꾸는 학습 가능한 가중치다.
- Self-attention(자기 어텐션)은 같은 문장에서 `Q, K, V`를 만든다.
- 같은 문장에서 출발해도 서로 다른 가중치를 쓰므로 세 결과의 값은 달라진다.

## 4. Attention 점수·비율·가중합의 계산

$$
\operatorname{Attention}(Q,K,V)
=
\operatorname{softmax}\left(
\frac{QK^\mathsf{T}}{\sqrt{d_k}}
\right)V
$$

1. `Q`의 각 행과 `K`의 각 행을 내적으로 비교한다.
2. Key 벡터의 차원 수 `d_k`의 제곱근으로 점수를 나눈다.
3. 참고하면 안 되는 위치를 가린다.
4. Softmax로 각 행의 점수를 합이 1인 비율로 바꾼다.
5. 그 비율로 `V`의 각 행을 곱해 더한다.

- `Kᵀ`는 Key 행렬의 행과 열을 바꾼 것이다. 모든 Query와 모든 Key를 한 번에 비교할 수 있게 한다.
- 차원 수가 커지면 내적 점수의 크기도 커지기 쉽다. `√d_k`로 나누면 Softmax가 지나치게 한쪽에 몰리는 현상을 줄이는 데 도움이 된다.
- 세 토큰을 서로 비교하면 Attention 가중치는 `(3, 3)`이다.
- 한 행은 현재 토큰 하나, 한 열은 참고할 토큰 하나다.
- 예를 들어 한 행의 비율이 `[0.1, 0.7, 0.2]`라면 둘째 토큰의 Value를 가장 크게 반영한다.
- 결과는 현재 토큰마다 주변 정보를 반영한 새 벡터다.

---

## 5. Multi-head Attention의 여러 관점

- 한 종류의 비교만 사용하면 제한된 방식으로 토큰 관계를 계산하게 된다.
- Multi-head attention(멀티헤드 어텐션)은 여러 가중치로 변환한 표현에서 Attention을 나누어 계산한다.
- 각 Head(헤드)의 출력을 이어 붙이고, 다시 출력 가중치로 변환한다.
- 예를 들어 모델 차원이 8이고 헤드가 2개면, 기본적인 구성에서는 헤드당 4차원으로 계산한다.
- 헤드마다 별도의 가중치를 사용한다. 학습 과정에서 이 가중치가 바뀌며 각 헤드가 참고하는 토큰 관계도 달라진다.
- 헤드를 합친 뒤에는 다시 모델 차원 8의 벡터를 얻는다.

## 6. FFN의 토큰별 비선형 변환

- Attention은 토큰 사이의 정보를 섞는다.
- Feed-forward network(순방향 신경망), 줄여서 FFN은 섞인 정보를 각 위치에서 다시 변환한다.
- 모든 위치에 같은 가중치를 적용하되, 이 단계에서 토큰끼리 직접 섞지는 않는다.

### torch.nn 모듈의 Sequential 클래스의 활용

- FFN은 각 토큰의 벡터를 더 큰 차원으로 펼치고 비선형 변환한 뒤 원래 차원으로 줄인다. 모든 토큰에 같은 가중치를 적용하면서 토큰별 표현을 다시 계산한다.

**코드 예시**

```python
import torch
from torch import nn

ffn = nn.Sequential(
    nn.Linear(8, 16),
    nn.ReLU(),
    nn.Linear(16, 8),
)
x = torch.zeros(2, 3, 8)
out = ffn(x)
```

**코드 해설**

- `ffn`은 `Sequential`로 만든 신경망 객체다. `ffn(x)`를 호출하면 같은 토큰 벡터가 `Linear → ReLU → Linear`를 차례로 통과한다.
- 문장 2개에 토큰이 3개씩 있으므로 벡터 6개를 처리한다. 각 벡터의 길이가 `8 → 16 → 8`로 바뀌고, 문장과 토큰의 개수는 유지된다.

- `Linear(8, 16)`은 마지막 축의 벡터 길이를 8에서 16으로 바꾼다.
- `ReLU`는 음수를 0으로 바꾸는 활성 함수 레이어다.
- 마지막 `Linear(16, 8)`이 다시 모델 차원 8로 돌려놓는다.
- `out`은 입력과 같은 `(2, 3, 8)` 형태다. 배치와 토큰 길이는 유지된다.

## 7. 잔차 연결과 LayerNorm의 역할

- Residual connection(잔차 연결)은 새로 계산한 값에 원래 입력을 더한다.
- `x + F(x)`로 표현하며, `F`는 Attention이나 FFN 같은 변환이다.
- 원래 정보가 다음 층으로 전달되는 경로를 만들고, 여러 층의 학습을 돕는다.
- 더하는 두 텐서는 서로 맞는 형태여야 한다.

### torch.nn 모듈의 LayerNorm 클래스의 활용

- LayerNorm은 토큰 하나의 벡터 안에서 평균과 분산을 구해 값의 크기를 조절한다. 각 토큰을 독립적으로 정규화하므로 문장 길이와 배치 축은 유지된다.

**코드 예시**

```python
norm = nn.LayerNorm(8)
normalized = norm(out)
```

**코드 해설**

- `nn.LayerNorm(8)`의 8은 정규화할 마지막 축의 길이다. `norm(out)`은 각 토큰 안의 숫자 8개를 한 묶음으로 계산하고 같은 형태의 새 텐서를 돌려준다.

- `out`이 `(2, 3, 8)`이면 각 토큰의 마지막 축 8개 값을 기준으로 평균과 분산을 계산한다.
- 해당 벡터를 정규화한 뒤 학습 가능한 크기와 이동 값을 적용한다.
- `normalized`의 형태도 `(2, 3, 8)`이다.
- 샘플들을 한데 모아 통계를 계산하는 BatchNorm과 계산 범위가 다르다.
- Post-LN은 `LayerNorm(x + F(x))`처럼 잔차를 더한 뒤 정규화한다.
- Pre-LN은 `x + F(LayerNorm(x))`처럼 변환 전에 정규화한다.
- 레이어를 읽을 때는 이름과 함께 정규화가 들어가는 위치를 확인한다.

## 8. 번역 Transformer의 인코더와 디코더

- 인코더는 원문을 읽는다. 원문 안의 토큰끼리 Self-attention을 하고 FFN을 거친다.
- 디코더는 생성할 문장의 앞부분을 읽는다. 아직 생성하지 않은 미래 위치는 가린다.
- 디코더에는 인코더 출력을 참고하는 Cross-attention(교차 어텐션)이 추가된다.
- Cross-attention의 Query는 디코더에서, Key와 Value는 인코더 출력에서 가져온다.
- 이후 FFN과 출력층을 거쳐 목표 언어의 다음 토큰 점수를 만든다.
- 각 Attention과 FFN 주위에는 잔차 연결과 정규화가 들어간다.

---

## 9. 학습의 병렬 계산과 순차적인 토큰 생성

- 학습할 때는 정답 문장 전체가 준비되어 있다. 한 칸 이동한 입력과 정답을 만들어 여러 위치를 한 번에 계산한다.
- Causal mask(미래 위치를 가리는 마스크)가 각 위치의 미래 정답을 가린다.
- 실제 생성에서는 다음에 붙일 토큰이 아직 정해지지 않았다. 선택한 토큰을 붙여 가며 계산을 반복한다.
- **토큰·위치 임베딩 → Attention → FFN → 여러 층 반복 → 사전 전체의 다음 토큰 점수**가 기본 흐름이다.
