## 1. 텍스트 전처리와 토큰화가 필요한 이유

- 신경망은 숫자로 계산한다. 문장을 입력하려면 글을 일정한 단위로 나누고, 각 단위를 숫자에 연결해야 한다.
- `"영화가 재미있다"`를 공백으로 나누면 `["영화가", "재미있다"]`가 된다. 더 작게 나누면 `["영화", "가", "재미", "있", "다"]`처럼 표현할 수도 있다.
- 어떤 단위로 나누느냐에 따라 모델이 반복해서 배우는 표현과 문장의 길이가 달라진다.
- **텍스트 전처리의 목적은 필요한 의미를 유지하면서, 모델이 일관되게 처리할 입력을 만드는 것이다.**

---

## 2. 문자열 정리와 필요한 의미의 보존

- Corpus(말뭉치)는 모델 학습이나 분석에 사용하는 텍스트의 모음이다.
- Cleaning(정제)은 HTML 태그, 깨진 문자, 중복 문장처럼 처리에 방해되는 부분을 정리하는 과정이다.
- Normalization(정규화)은 같은 표현을 일정한 형태로 맞추는 과정이다. 연속된 공백을 하나로 바꾸는 것이 한 예다.
- 영어를 소문자로 바꾸면 `Apple`과 `apple`이 같은 문자열이 된다. 사람 이름이나 제품명을 구분해야 하는 작업에서는 대소문자를 유지할 수 있다.
- 감정 분석에서는 `"좋지 않다"`의 `"않다"`를 남겨야 부정의 의미가 유지된다.
- 번역과 요약에서는 숫자, 단위, 이름, 문장부호가 뜻을 이해하는 데 쓰인다. 제거할 항목은 작업 목적에 맞춰 정한다.

### Python str 객체의 strip·lower 메서드 활용

- 같은 표현이 공백이나 대소문자 차이로 따로 처리되지 않도록 표기를 맞춘다. 아래에서는 양 끝 공백과 영문 대소문자를 정리하고, 문장 안의 내용은 유지한다.

**코드 예시**

```python
text = "  Hello,   NLP!  "
text = text.strip().lower()
```

**코드 해설**

- `text.strip().lower()`는 왼쪽부터 계산한다. 먼저 양 끝 공백을 지운 문자열을 만들고, 그 문자열에 `lower()`를 적용한 뒤 최종 결과를 `text`에 대입한다.

- `strip()`은 문자열 양 끝의 공백을 없앤다. 가운데 있는 공백은 그대로 둔다.
- `lower()`는 영문 대문자를 소문자로 바꾼다.
- 결과는 `"hello,   nlp!"`다. 문자열 메서드는 새 문자열을 반환하므로 결과를 변수에 저장한다.

### re 모듈의 sub 함수의 활용

- 연속된 공백을 하나로 맞추면 이후 단어 분리와 문자열 비교 기준이 일정해진다. 공백에 해당하는 패턴을 찾아 한 칸으로 치환한다.

**코드 예시**

```python
import re

text = re.sub(r"\s+", " ", text)
```

**코드 해설**

- `re.sub(찾을 패턴, 바꿀 문자열, 원문)` 순서로 인자를 넣는다. 여기서는 원문에서 연속된 공백을 찾아 공백 한 칸으로 바꾼 문자열을 반환한다.

- `re`는 Python의 정규표현식 모듈이다.
- `\s`는 공백·탭·줄바꿈 같은 문자를, `+`는 한 번 이상 반복됨을 뜻한다.
- `r"..."`는 역슬래시를 정규표현식에 전달하기 편하게 쓰는 문자열 문법이다.
- 결과는 `"hello, nlp!"`다. 문장부호와 글자는 유지된다.

## 3. 토큰의 의미와 split 메서드

- Token(토큰)은 문장을 나눈 한 조각이다. 단어, 형태소, 부분 단어, 문자 등이 토큰이 될 수 있다.
- Tokenization(토큰화)은 문장을 토큰의 순서로 바꾸는 과정이다.
- Tokenizer(토크나이저)는 나누는 규칙과 토큰을 번호에 연결하는 기능을 제공한다.

| 나누는 방법 | 특징과 쓰임 |
| --- | --- |
| 공백 기반 | 띄어쓰기를 기준으로 나눈다. 한국어에서는 `학교`와 `학교에서`가 다른 토큰이 된다. |
| 형태소 기반 | 의미나 문법 기능을 가진 작은 단위로 나눈다. `학교에서`를 `학교 + 에서`로 분석할 수 있다. |
| 부분 단어 기반 | 자주 나타나는 글자 조합을 학습한다. 처음 보는 단어도 알고 있는 작은 조각으로 나눠 처리한다. |

### Python str 객체의 split 메서드의 활용

- 토큰화는 모델이 처리할 단위로 문장을 나누는 과정이다. 가장 단순한 기준으로 공백을 사용하면 어절 단위의 목록을 얻을 수 있다.

**코드 예시**

```python
tokens = "나는   학교에 간다".split()
```

**코드 해설**

- 결과는 `["나는", "학교에", "간다"]`다.
- 인자 없이 호출하면 연속된 공백을 하나의 구분으로 처리한다.
- `"학교에"` 안의 조사까지 나누려면 형태소 분석처럼 추가 규칙이 필요하다.
- KoNLPy의 `Mecab`, `Okt` 같은 분석기 객체에서 `morphs`는 형태소 목록을, `pos`는 형태소와 품사 정보를 반환하는 메서드다.

## 4. 처음 보는 단어와 서브워드 토큰화

- Vocabulary(단어사전)는 모델이 사용하는 토큰의 집합이다.
- `"고양이"`만 사전에 있고 `"고양이는"`이 없다면, 단어 전체를 사용하는 방식에서는 새 단어로 처리해야 한다.
- OOV(사전 밖 단어)는 이런 상황을 가리킨다.
- `<unk>`는 사전에 없는 입력을 나타내는 특수 토큰이다. 여러 낯선 단어가 모두 이 토큰으로 바뀌면 단어 사이의 차이가 사라진다.
- Subword(부분 단어)는 `고양이 + 는`처럼 익숙한 조각을 재사용해서 낯선 표현을 처리한다.
- 조각의 경계는 학습한 사전에 따라 달라진다. 형태소 분석처럼 문법 단위를 직접 찾는 과정과 구분해서 이해한다.
- 사전에 없는 문자까지 처리하려면 문자 범위나 Byte fallback(바이트 대체) 같은 설정도 필요하다.

## 5. BPE의 조각 병합 원리

- BPE(Byte Pair Encoding)는 작은 단위에서 시작해 자주 이웃하는 두 조각을 반복해서 합치는 방법이다.
- 예를 들어 `l o w`가 여러 번 등장하면 `l + o`를 `lo`로 합치고, 이후 `lo + w`를 `low`로 합칠 수 있다.
- 실제로 어느 쌍을 먼저 합칠지는 말뭉치의 등장 횟수가 결정한다.
- 자주 쓰는 표현은 큰 조각으로, 드문 표현은 작은 조각의 조합으로 남는다.
- 학습이 끝나면 새 문장에도 같은 병합 규칙을 적용한다.

### 토큰·토크나이저·단어사전의 뜻

- **WordPiece**는 BERT 등에 쓰이는 부분 단어 토큰화 방식이다. 사전의 조각을 이용해 단어를 나누며, BERT 방식의 `##ing` 같은 표기는 단어 중간에 붙는 조각을 나타낸다.
- **SentencePiece**는 부분 단어 토크나이저를 학습하고 사용하는 도구다. BPE와 Unigram 같은 알고리즘을 지원한다.
- SentencePiece에서 보이는 `▁`는 공백을 나타내는 기호다. 예를 들어 `▁학교`의 앞 기호는 원래 공백 위치를 표현한다.
- 알고리즘 이름, 도구 이름, 토큰에 붙는 표시를 따로 구분하면 설정과 출력이 읽히기 시작한다.

## 6. 토큰 번호와 임베딩 벡터의 역할

- `"학교" → 7`은 단어사전에서 학교에 7번을 배정한 것이다.
- `"병원" → 8`처럼 토큰마다 고유한 번호를 붙인다. 이 번호는 사전에서 해당 토큰을 찾을 때 사용한다.
- Embedding(임베딩)은 토큰 번호를 여러 실수로 이루어진 벡터에 연결한다.
- 벡터의 값은 학습 목표에 맞춰 바뀐다. 문맥이 비슷한 표현을 구분하고 연결하는 데 쓰인다.
- 같은 `"배"`라도 `"배를 먹었다"`와 `"배를 탔다"`의 의미를 구분하려면 주변 토큰의 정보까지 함께 처리해야 한다.

## 7. 문장에서 모델 입력까지의 흐름

1. **정제·정규화**: 불필요한 형식을 정리하고 표현 규칙을 맞춘다.
2. **토큰화**: 문장을 일정한 단위의 순서로 나눈다.
3. **정수 인코딩**: 각 토큰을 단어사전에 있는 번호로 바꾼다.
4. **길이 맞추기**: 여러 문장을 묶어 계산할 수 있도록 빈 자리를 채운다.
5. **임베딩**: 번호마다 학습 가능한 벡터를 가져온다.
6. **문맥 처리**: 토큰 사이의 관계를 계산해 분류·번역·요약 등에 사용한다.

- 앞의 네 단계는 입력을 준비하고, 뒤의 두 단계는 신경망이 문장의 정보를 계산하는 과정이다.
