## 1. 프롬프트와 지시 학습을 배우는 이유

- 모델에게 같은 질문을 해도 지시와 예시에 따라 답변 형식이 달라진다. 원하는 결과를 얻으려면 무엇을 입력하고 무엇을 학습시키는지 이해해야 한다.
- **프롬프트는 지금 답할 때 참고할 정보를 주고, 지시 학습은 여러 질문·답변을 이용해 모델의 가중치를 바꾼다.**
- 예를 들어 이번 답변만 세 줄로 받으려면 프롬프트에 형식을 적는다. 여러 질문에서 일정한 답변 방식을 배우게 하려면 그 형식의 학습 데이터를 준비한다.
- 이 두 방법을 구분하면 입력을 바꿀지, 학습 데이터를 보완할지 판단하기 쉽다.

---

## 2. 언어 모델의 다음 토큰 예측

- 통계적 언어 모델은 단어 조합의 등장 횟수 등으로 다음 단어의 가능성을 계산했다.
- 신경망 언어 모델은 토큰을 벡터로 바꾸고, 가중치를 학습해 다음 토큰을 예측한다.
- 사전학습 언어 모델은 많은 글로 이 계산을 학습한 뒤 여러 작업에 활용된다.
- Large language model, LLM(대규모 언어 모델)은 많은 파라미터와 학습 데이터를 사용하는 언어 모델을 가리킨다.
- 생성형 LLM에서는 입력과 지금까지 만든 문장을 읽고 다음 토큰을 선택하는 과정을 반복한다.

### 기본 모델과 지시 학습 모델

- Base model(기본 모델)은 사전학습을 마친 모델을 뜻한다.
- `내일 할 일을 정리해 줘`를 넣어도, 학습 데이터에서 비슷한 글 뒤에 이어질 내용을 생성할 수 있다.
- 질문에 답하는 형식과 요청한 행동을 더 잘 따르도록 추가 학습한 모델을 Instruction-tuned model(지시 학습 모델)이라고 한다.
- 여러 작업에 활용할 수 있도록 넓은 데이터로 학습한 기반 모델은 Foundation model(기반 모델)이라고도 부른다.

## 3. 모델 크기·학습 데이터·계산량의 관계

- 파라미터는 학습으로 조정하는 숫자다. `7B`는 약 70억 개의 파라미터를 뜻한다.
- 파라미터 수를 늘리면 저장할 가중치와 수행할 계산도 늘어난다.
- 모델이 충분한 언어 패턴을 배우려면 학습 토큰의 양과 품질도 필요하다.
- 같은 계산 예산에서는 모델 크기를 늘리는 데 쓸 자원과, 더 많은 토큰을 학습하는 데 쓸 자원을 나누어야 한다.
- Chinchilla 연구는 이 두 크기의 균형을 비교했다. 모델 크기와 학습 데이터 양을 함께 조절하는 문제다.
- 한국어 작업에서는 한국어 학습 데이터의 양과 품질, 토크나이저가 한국어를 나누는 방식도 함께 살펴본다.

## 4. 프롬프트의 지시·참고 자료·출력 형식

- Prompt(프롬프트)는 모델에게 주는 입력 내용이다.
- 할 일, 참고할 글, 출력 형식, 답변 예시를 넣을 수 있다.
- 모델은 이 입력을 문맥으로 사용해 다음 토큰을 예측한다.

```text
다음 문장의 감정을 긍정 또는 부정으로 분류해 줘.
답에는 분류 이름만 적어 줘.

문장: 배우의 연기가 좋았다.
답:
```

- 할 일은 감정 분류이고, 출력 형식은 분류 이름 하나다.
- 모델은 이미 학습한 가중치를 사용해 입력을 읽고, `긍정` 또는 `부정`이라는 다음 출력을 계산한다.

---

## 5. Zero-shot·One-shot·Few-shot의 입력 예시

- In-context learning(문맥 내 학습)은 입력에 들어 있는 지시와 예시를 참고해 새 문제에 답하는 방식을 말한다.
- Zero-shot(예시 없음)은 답변 예시를 주지 않는다.
- One-shot(예시 한 개)은 입력과 답의 예시 한 쌍을 준다.
- Few-shot(소수 예시)은 몇 개의 예시를 함께 준다.

```text
문장의 감정을 분류해 줘.

문장: 또 보고 싶다.
답: 긍정

문장: 너무 지루하다.
답: 부정

문장: 배우의 연기가 좋았다.
답:
```

- 모델은 앞의 두 예시에서 라벨 이름과 답변 형식을 참고한다.
- 예시 두 쌍은 현재 입력의 일부다. 모델은 학습해 둔 가중치로 예시의 형식을 읽고 마지막 문장에 대한 답을 생성한다.
- 입력 길이 제한 안에 지시, 예시, 실제 질문을 함께 넣어야 한다.

## 6. 지시 학습과 가중치 갱신

- Instruction tuning(지시 학습)은 여러 작업을 지시와 정답 답변의 쌍으로 바꾸어 추가 학습하는 방법이다.
- 번역, 요약, 질문 답변 등에서 지시문이 무엇을 요구하는지 배우도록 한다.
- FLAN은 여러 작업을 지시 형태로 구성해 미세조정한 연구다.

| 방법 | 달라지는 부분 |
| --- | --- |
| 프롬프트에 예시 추가 | 이번 추론에서 읽을 입력이 달라진다. |
| 지시 학습 | 지시와 답변 데이터로 모델 가중치가 달라진다. |
| 생성 옵션 조절 | 계산된 토큰 점수에서 다음 토큰을 고르는 방식이 달라진다. |

- 지시 학습을 마친 모델에도 프롬프트와 예시를 줄 수 있다.
- 다음 문서에서 볼 SFT는 정답 답변을 사용해 이런 추가 학습을 수행하는 기본 방법이다.

## 7. 풀이 단계를 포함한 프롬프트 예시

- 한 번의 답 선택에 여러 계산이 필요한 문제는 중간 단계를 표현하는 것이 도움이 될 수 있다.
- Chain-of-thought prompting, CoT(풀이 단계 예시를 사용하는 프롬프트)는 풀이 과정을 포함한 예시를 주는 방법이다.

```text
문제: 사과 2개를 샀고 3개를 더 샀다. 모두 몇 개인가?
풀이: 처음 2개와 추가 3개를 더하면 2 + 3 = 5다.
답: 5개

문제: 사과 4개를 샀고 2개를 더 샀다. 모두 몇 개인가?
풀이:
```

- 모델은 중간 계산을 글로 표현하는 형식도 참고한다.
- 답의 정확성은 실제 계산과 정답으로 확인한다. 설명이 얼마나 길게 나왔는지는 별도의 출력 특성이다.

## 8. 모델 규모에 따른 성능 변화와 평가 기준

- Emergent ability(창발 능력)는 작은 모델에서는 잘 관찰되지 않던 작업 성능이 큰 모델에서 나타나는 현상을 설명할 때 쓰는 말이다.
- 무엇을 능력으로 측정했는지 알려면 문제 종류와 채점 방식을 함께 읽어야 한다.
- 예를 들어 여러 자리 수의 정답을 전부 맞혀야 1점을 주면, 일부 자리만 개선된 동안에는 점수가 0에 머문다.
- 토큰별 정답 확률이나 부분 점수를 보면 변화가 더 연속적으로 보일 수 있다.
- **모델 크기, 학습 데이터, 프롬프트, 채점 기준이 어떤 결과를 만들었는지 연결해서 읽는다.**
- AGI(범용 인공지능)는 폭넓은 작업 수행 능력을 다루는 논의다. 이 단원에서는 요약, 분류, 질문 답변처럼 실제 측정할 수 있는 작업으로 학습 목표를 잡는다.

---

## 9. 사전학습부터 답변 생성까지의 흐름

1. 사전학습으로 언어 패턴과 다음 토큰 예측을 배운다.
2. 지시와 좋은 답변의 쌍으로 SFT를 수행한다.
3. 같은 질문의 답변들을 비교해 어떤 답을 더 선호하는지 학습할 수 있다.
4. 학습한 선호 점수를 사용해 답변 생성 방식을 추가 조정할 수 있다.
5. 실제 사용 시에는 프롬프트와 생성 옵션을 받아 답을 만든다.

- 뒤의 세 문서는 정답 답변 학습, 선호 점수 학습, 보상을 이용한 생성 모델 갱신을 차례로 설명한다.
