## 1. 답변 선호를 학습하는 이유

- 질문 하나에도 여러 답변이 가능하다. 두 답이 모두 문장으로 자연스러워도, 하나가 더 정확하거나 질문에 더 직접적으로 답할 수 있다.
- 좋은 답변 하나를 보여 주는 SFT에 더해, 여러 답변의 상대적인 선호를 학습할 수 있다.
- **Reward model, RM(보상 모델)은 질문과 답변을 읽고, 선호 기준에 맞는 정도를 숫자 하나로 계산한다.**
- 이 점수는 이후 생성 모델을 추가 학습하는 데 사용된다.

---

## 2. 같은 질문의 선호·비선호 답변 쌍

- 보상 모델은 같은 질문에 대한 두 답변 중 어느 쪽이 더 좋은지 비교한 자료로 학습한다. 질문은 고정하고 답변을 비교해야, 답변의 어떤 차이가 선호와 연결되는지 배울 수 있다.

```text
질문: 비가 올 때 외출하려면 무엇을 챙길까?
선호 답변: 우산을 챙기고 날씨에 맞는 신발을 신으면 좋다.
비선호 답변: 외출은 집 밖으로 나가는 것이다.
```

- 질문은 같고, 비교할 답변이 다르다.
- `chosen`은 더 선호하는 답변, `rejected`는 그보다 덜 선호하는 답변을 가리키는 데이터 필드 이름이다.
- 답변의 이름보다 두 답변 중 어느 쪽을 선택했는지가 학습 정보다.
- 선호 기준에는 질문과의 관련성, 사실의 정확성, 필요한 정보의 충족 여부 등이 들어갈 수 있다.
- 사람이 직접 비교한 선호와 모델이 만든 선호는 라벨을 정한 주체가 다르다. 어떤 기준으로 선택했는지 알고 데이터를 사용한다.

## 3. combinations 함수와 순위 데이터 변환

- 세 답변에 순위를 매겼다면 두 개씩 묶어 선호 쌍을 만들 수 있다.
- 이 예시에서는 작은 순위 숫자가 더 좋은 답변을 뜻한다.
- `ranking = [2, 0, 1]`이면 답변 0은 3등, 답변 1은 1등, 답변 2는 2등이다.
- 배열의 위치는 답변 번호이고, 그 위치의 값은 순위다.

### itertools 모듈의 combinations 함수 활용

- 답변의 전체 순위를 두 답변씩 비교하는 쌍으로 바꾸면, 보상 모델이 어느 쪽에 높은 점수를 줘야 하는지 학습할 수 있다. 한 질문 안의 모든 조합에서 선호 답변을 앞에 배치한다.

**코드 예시**

```python
from itertools import combinations

ranking = [2, 0, 1]
pairs = []

for i, j in combinations(range(3), 2):
    if ranking[i] < ranking[j]:
        pairs.append((i, j))
    else:
        pairs.append((j, i))
```

**코드 해설**

- 반복문은 답변 번호 두 개를 고른다. `ranking[i] < ranking[j]`이면 i를 선호 답변으로 앞에 넣고, 반대면 j를 앞에 넣어 모든 쌍의 순서를 통일한다.

- `combinations(range(3), 2)`는 `(0, 1)`, `(0, 2)`, `(1, 2)`를 만든다.
- Python 내장 `range(3)`은 답변 번호 0, 1, 2를 차례로 제공한다.
- 리스트의 `append()` 메서드는 값 하나를 뒤에 추가한다.
- `pairs`의 각 쌍은 `(선호 답변 번호, 비선호 답변 번호)`다.
- 결과는 `[(1, 0), (2, 0), (1, 2)]`다. 세 경우 모두 앞쪽 답변의 순위가 더 높다.
- 같은 질문에서 나온 쌍들은 학습·평가로 나눌 때 같은 쪽에 둔다. 일부 답변을 이미 본 상태로 평가하지 않게 하기 위해서다.

## 4. 보상 모델의 문맥 벡터와 점수층

- 보상 모델은 질문과 답변을 함께 읽는다. 질문에 맞는 답인지 판단하려면 두 내용이 모두 필요하다.
- 기본 언어 모델이 문맥을 계산하고, 점수용 출력층이 이를 Scalar(숫자 하나)로 바꾼다.
- 어떤 위치의 벡터를 사용할지, 여러 위치를 어떻게 합칠지는 모델 구현에서 정한다.
- 마지막 실제 토큰의 표현을 사용하거나, 패딩을 제외한 표현을 모아서 사용할 수 있다.

### torch.nn 모듈의 Linear 클래스 활용

- 보상 모델은 질문과 답변의 문맥 표현을 점수 하나로 바꾼다. 같은 질문에 대한 두 답변의 점수 차이를 이용해 선호 순서가 맞도록 학습한다.

**코드 예시**

```python
import torch
from torch import nn

answer_vectors = torch.tensor([
    [0.3, 0.7, -0.1],
    [0.8, 0.2, 0.4],
])
score_head = nn.Linear(3, 1)
scores = score_head(answer_vectors).squeeze(-1)
```

**코드 해설**

- `answer_vectors`는 질문과 답변을 읽은 표현 두 개를 가정한 값이다.
- `nn.Linear(3, 1)`은 벡터 차원 3을 점수 1개로 바꾼다.
- `Tensor.squeeze(-1)` 메서드는 마지막 크기 1인 축을 없애 `(2, 1)`을 `(2,)`로 바꾼다.
- 새 점수층은 학습 전 상태다. 선호 데이터로 점수의 방향을 배워야 한다.
- 점수는 음수도 나올 수 있다. 선호 학습에서는 같은 질문의 두 답변 사이 점수 차이를 사용한다.

## 5. 점수 차이와 선호 학습 손실

- 선호 답변의 점수를 `r_good`, 비교 답변의 점수를 `r_other`라고 하자.
- 점수 차이 `r_good - r_other`가 커지도록 학습한다.
- 이 차이를 Sigmoid(시그모이드) 함수에 넣으면, 두 답변 중 앞쪽을 선호할 가능성을 나타내는 값이 0과 1 사이로 나온다.

$$
L = -\log \sigma(r_{good} - r_{other})
$$

- `σ`는 시그모이드 함수다.
- 선호 답변의 점수가 충분히 높으면 괄호 안 차이가 양수이고, 손실이 작아진다.
- 순위가 뒤집혀 차이가 음수가 되면 손실이 커진다.

### torch.nn.functional 모듈의 logsigmoid 함수와 선호 손실

- 선호한 답변의 점수가 더 높으면 손실을 작게, 더 낮으면 크게 주어 순서를 학습한다. 점수 차이에 시그모이드와 로그를 적용하면 연속적으로 미분할 수 있는 손실을 만들 수 있다.

**코드 예시**

```python
import torch
import torch.nn.functional as F

chosen_scores = torch.tensor([2.0, 0.5])
rejected_scores = torch.tensor([0.0, 1.5])

margins = chosen_scores - rejected_scores
loss = -F.logsigmoid(margins).mean()
```

**코드 해설**

- 각 위치는 질문 하나의 답변 쌍이다. 먼저 선호 점수에서 비선호 점수를 빼서 순서가 맞는지 계산한다.
- 차이 2에는 작은 손실 약 0.127이, 차이 -1에는 큰 손실 약 1.313이 부여된다. 두 값을 평균한 0.720을 줄이는 방향으로 학습한다.

- `margins`는 `[2.0, -1.0]`이다.
- 첫 번째 쌍은 선호 순서대로 점수가 나왔다. 두 번째 쌍은 순위가 뒤집혔다.
- `F.logsigmoid()`는 시그모이드의 로그를 수치적으로 안정된 방식으로 계산한다.
- `Tensor.mean()`은 쌍별 손실의 평균을 구한다.
- 평균 손실은 약 0.7201이다. 학습에서는 이 값을 줄이도록 보상 모델의 가중치를 바꾼다.

## 6. 보상 점수의 의미와 비교 범위

- 점수 2.0은 모델이 학습한 선호 척도의 값이다. 두 답변의 점수 차이를 시그모이드에 넣었을 때 비교 확률이 된다.
- 두 답변 점수가 `2, 0`일 때와 `12, 10`일 때는 차이가 모두 2이므로 위 손실에서 같은 비교 결과를 만든다.
- 평가에서는 새로운 질문의 답변 쌍에 대해, 사람이 정한 선호 순서와 모델의 점수 순서가 맞는지 확인한다.
- 특정 표현이나 길이에 점수를 몰아주는지 알아보려면, 내용이 비슷하고 길이만 다른 답변 등 구체적인 쌍을 비교한다.
- 학습된 선호 점수와 실제 답변의 정확성은 각각 평가 항목으로 둔다.

## 7. 보상 모델에서 생성 모델 학습으로의 연결

1. 같은 질문에 대한 여러 답변을 모은다.
2. 선호 기준에 따라 답변 쌍의 순서를 정한다.
3. 각 질문과 답변을 보상 모델에 넣어 점수를 구한다.
4. 선호 답변의 점수가 높아지도록 비교 손실로 학습한다.
5. 학습을 마친 보상 모델을 고정한다.
6. 생성 모델이 새로 만든 답변에 점수를 준다.

- 생성 모델이 보상 점수를 이용해 바뀌는 과정은 다음 문서의 PPO에서 다룬다.
- **보상 모델은 답변을 평가하는 점수를 만들고, 생성 모델은 실제 답변의 다음 토큰을 선택한다.**
