## 1. 사전학습 모델의 차이를 배우는 이유

- 긴 문서를 읽는 문제, 손상된 문장을 복원하는 문제, 적은 메모리로 학습하는 문제는 필요한 해결 방법이 다르다.
- 모델 이름만 외우면 어떤 구조가 어떤 문제를 해결했는지 구분하기 어렵다.
- **각 모델을 만든 이유와 바꾼 부분을 연결하면, 학습 목표와 모델 구조를 비교할 수 있다.**
- 여기서는 긴 문맥, 예측 순서, 글 복원, 파라미터 수, 마스킹 단위의 순서로 살펴본다.

---

## 2. Transformer-XL의 이전 구간 재사용

- 긴 글을 독립된 짧은 구간으로 잘라 읽으면, 다음 구간을 처리할 때 앞 구간의 문맥이 끊긴다.
- Transformer-XL은 이전 구간에서 계산한 Hidden state(은닉 상태)를 저장한다.
- 다음 구간의 토큰은 현재 구간과 저장된 이전 상태를 함께 참고한다.
- 학습할 때 저장한 상태는 과거 구간으로 기울기를 계속 전달하지 않도록 분리한다. 문맥 정보는 읽되, 역전파의 길이를 제한하는 것이다.
- 위치를 각 구간의 첫째·둘째 자리로만 표시하면 저장된 과거 위치와 현재 위치를 구분하기 어렵다.
- 그래서 Attention 계산에 토큰 사이의 상대적인 거리를 반영한다.

### 이전 구간에서 다음 구간으로의 정보 전달

1. 첫 구간을 계산하고 중간 상태를 저장한다.
2. 다음 구간의 토큰과 저장된 상태를 함께 Attention에 사용한다.
3. 두 위치가 얼마나 떨어져 있는지 상대 위치 정보로 계산한다.
4. 사용할 길이만큼 상태를 갱신하고 다음 구간으로 넘어간다.

## 3. XLNet의 토큰 예측 순서

- 왼쪽부터 예측하는 모델은 각 예측에서 왼쪽 문맥을 읽는다.
- XLNet은 문장 안의 위치들을 여러 순서로 예측하도록 학습한다.
- 이를 Permutation language modeling(순열 언어 모델링)이라고 한다.
- 문장의 원래 위치는 유지하고, 어떤 위치를 먼저 참고할지 Attention 마스크로 조절한다.

### 세 위치를 예측하는 예

- 원래 문장의 위치가 `1, 2, 3`이라고 하자.
- 예측 순서를 `3 → 1 → 2`로 잡으면, 위치 2를 예측할 때 위치 3과 1의 내용을 참고할 수 있다.
- 위치 2의 원래 오른쪽과 왼쪽을 모두 참고하는 학습 문제가 만들어진다.
- 예측할 위치 번호는 알려 주되, 그 위치의 정답 내용은 숨겨야 한다.
- XLNet은 이를 위해 내용을 포함하는 표현과, 정답 내용을 숨긴 예측용 표현을 따로 계산한다.
- 이 두 경로를 Two-stream self-attention(두 경로의 셀프 어텐션)이라고 부른다.

## 4. BART의 손상된 글 복원

- 빈칸 하나의 토큰을 맞히는 학습만으로는 긴 문장을 생성하는 과정을 직접 배우기 어렵다.
- BART는 일부를 지우거나 문장 순서를 바꾼 글을 입력으로 받아, 원래 글 전체를 복원한다.
- 인코더는 손상된 입력 전체를 읽는다.
- 디코더는 인코더의 출력을 참고하며 원래 글을 앞에서부터 생성한다.

```text
원래 글: 민수는 아침에 우산을 챙겼다.
입력:   민수는 [MASK] 챙겼다.
정답:   민수는 아침에 우산을 챙겼다.
```

- `[MASK]` 하나가 여러 토큰이 지워진 구간을 나타낼 수 있다.
- 이처럼 손상된 입력을 복원하도록 학습하는 목표를 Denoising objective(손상 복원 학습 목표)라고 한다.
- 요약으로 미세조정할 때는 기사 원문을 인코더에 넣고, 요약문을 디코더의 학습 정답으로 사용한다.

## 5. T5의 텍스트 입력·출력 형식

- 감정 분류는 번호, 번역은 문장, 유사도 판단은 점수처럼 작업마다 정답 형식이 다를 수 있다.
- T5는 입력과 정답을 모두 텍스트로 표현한다.
- 작업 종류를 입력 앞부분의 Prefix(접두 문구)로 알려 준다.

| 입력 예 | 출력 예 |
| --- | --- |
| `감정 분류: 영화가 재미있었다.` | `긍정` |
| `영어로 번역: 고마워.` | `Thank you.` |
| `요약: 오늘 오전에 비가 내려…` | `오전에 비가 내렸다.` |

- 위 문구는 형식을 설명하는 예다. 실제로는 모델이 학습한 작업 문구와 언어를 사용한다.
- T5의 기본 구조는 인코더와 디코더다. 인코더는 입력 전체를 읽고, 디코더는 출력의 앞부분을 참고한다.

### T5 사전학습의 지운 구간 복원

- T5의 이 사전학습에서는 연속된 토큰 구간을 지우고, 각 자리에 서로 다른 특수 토큰을 넣는다. 모델은 그 표시를 따라 지운 내용들을 순서대로 복원한다.

```text
입력: 오늘 <extra_id_0> 내려 <extra_id_1> 챙겼다.
정답: <extra_id_0> 비가 <extra_id_1> 우산을 <extra_id_2>
```

- 각 특수 토큰은 지운 구간의 위치를 구분한다.
- 디코더는 특수 토큰과 해당 구간의 원래 내용을 차례대로 생성한다.
- 이런 방식을 Span corruption(연속된 토큰 구간을 가리는 학습)이라고 한다.
- BART의 글 전체 복원과 비교하면, T5의 이 학습 방식은 지운 구간들을 정답으로 모아서 생성한다.

## 6. ALBERT의 파라미터 수 절감

- 사전 크기와 벡터 차원이 커지면 입력 임베딩 표만으로도 많은 파라미터가 필요하다.
- ALBERT는 작은 토큰 벡터를 먼저 찾고, 별도의 변환으로 인코더의 큰 벡터 차원에 맞춘다.
- 사전 크기를 `V`, 작은 임베딩 차원을 `E`, 인코더 차원을 `H`라고 하자.
- 하나의 큰 표에 필요한 파라미터는 `V × H`개다.
- 두 단계로 나누면 `V × E + E × H`개가 된다. 여기서는 편향 값을 제외해 계산한다.

- 큰 임베딩 표를 작은 표와 차원 변환 행렬로 나누면 저장할 숫자를 줄일 수 있다. 아래에서는 한 번에 큰 벡터를 찾는 방식과 작은 벡터를 확장하는 방식의 크기를 비교한다.

**코드 예시**

```python
vocab_size = 1000
hidden_size = 100
embedding_size = 10

original_count = vocab_size * hidden_size
factorized_count = (
    vocab_size * embedding_size
    + embedding_size * hidden_size
)
```

**코드 해설**

- 원래 표는 토큰 1,000개마다 숫자 100개를 저장하므로 `1,000×100`개 값이 필요하다.
- 두 단계로 나누면 토큰마다 숫자 10개를 저장하는 표와, 길이 10을 길이 100으로 바꾸는 행렬이 필요하다. 두 크기를 더한 `10,000 + 1,000 = 11,000`이 새 파라미터 수다.

- `original_count`는 100,000, `factorized_count`는 11,000이다.
- 작은 차원을 거쳐 큰 차원으로 바꾸므로, 파라미터 수와 표현 방식이 함께 바뀐다.

### 여러 층의 가중치 공유

- ALBERT는 여러 인코더 층에서 같은 파라미터를 재사용하는 방법도 쓴다.
- 층을 통과할 때마다 입력 표현은 달라지고, 같은 변환을 다시 적용한다.
- 저장할 가중치는 줄지만, 층을 여러 번 계산하는 과정은 남는다.
- 학습 목표에는 MLM과 함께 SOP를 사용한다. SOP는 문장 두 부분의 순서가 맞는지 판단하는 문제다.

## 7. ERNIE의 의미 단위 마스킹

- 여러 토큰으로 된 이름의 한 조각만 가리면 나머지 조각을 보고 답을 쉽게 맞힐 수 있다.
- Baidu의 초기 ERNIE는 구나 개체명 전체를 묶어 가리는 학습을 사용한다.
- Phrase(구)는 여러 단어가 모여 하나의 의미 단위를 이루는 표현이다.
- Entity(개체)는 사람, 장소, 조직처럼 문장에서 특정 대상을 가리킨다.
- 예를 들어 장소 이름 전체를 가리면 모델은 주변 문장에서 그 장소를 추론해야 한다.
- **무엇을 한꺼번에 가리느냐에 따라 모델이 참고해야 할 문맥이 달라진다.**

## 8. 해결할 문제에 따른 모델 비교

| 해결하려는 문제 | 바꾼 방법 |
| --- | --- |
| 구간 경계에서 문맥이 끊김 | Transformer-XL은 이전 구간의 상태를 재사용한다. |
| 여러 방향의 문맥으로 토큰을 예측하고 싶음 | XLNet은 예측 순서를 바꾼다. |
| 입력을 읽고 새 문장을 만들고 싶음 | BART와 T5는 인코더와 디코더를 함께 사전학습한다. |
| 저장할 가중치가 너무 많음 | ALBERT는 임베딩 차원을 나누고 층의 파라미터를 공유한다. |
| 가린 토큰을 너무 적은 단서로 맞힘 | ERNIE는 의미 단위를 묶어서 가린다. |

- 모델을 볼 때는 입력을 읽는 범위, 예측할 정답, 결과를 꺼내는 방식을 먼저 확인한다.
- 같은 Transformer 계열이어도 이 세 가지가 달라지면 학습하는 문제가 달라진다.
