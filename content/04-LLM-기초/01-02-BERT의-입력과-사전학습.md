## 1. BERT의 입력과 학습 정답을 배우는 이유

- 모델 구조를 알아도 무엇을 정답으로 삼는지 모르면, 학습이 무엇을 바꾸는지 이해하기 어렵다.
- BERT는 글에서 일부 토큰을 숨기거나 문장 두 개를 묶어서 학습 문제를 만든다.
- **입력에는 무엇을 보여 주고, 어떤 위치의 답을 채점하는지 이해하면 마스킹과 손실 계산이 연결된다.**
- 여기서는 원래 BERT의 MLM과 NSP를 기준으로 보고, 문장 순서를 맞히는 SOP도 함께 구분한다.

---

## 2. 문장 쌍과 특수 토큰의 구성

- 두 문장을 각각 A와 B라고 하자.
- BERT는 특수 토큰을 넣어 다음 형태로 읽는다.

```text
[CLS] 문장 A [SEP] 문장 B [SEP]
```

| 특수 토큰 | 역할 |
| --- | --- |
| `[CLS]` | 맨 앞에 놓는다. 이 위치의 출력 벡터를 문장 전체나 문장 쌍의 분류에 활용한다. |
| `[SEP]` | 문장의 경계와 끝을 표시한다. |
| `[MASK]` | 사전학습에서 일부 토큰의 내용을 가린다. |
| `[PAD]` | 여러 입력을 같은 길이로 맞출 때 빈자리를 채운다. |

- 특수 토큰도 사전 안에 고유한 번호가 있다.
- 원래 BERT는 WordPiece를 사용한다. BERT 구조를 새로 학습할 때는 SentencePiece 같은 다른 토크나이저와 사전을 구성할 수도 있다.
- 이미 학습된 BERT를 불러올 때는 해당 모델과 짝을 이루는 사전과 토크나이저를 사용한다.

---

## 3. 토큰·위치·문장 구분 임베딩

- BERT의 초기 입력 벡터에는 세 가지 정보가 들어간다.
- Token embedding(토큰 임베딩)은 어떤 토큰인지 표현한다.
- Position embedding(위치 임베딩)은 입력 안에서 몇 번째 위치인지 표현한다.
- Segment embedding(문장 구분 임베딩)은 A와 B 중 어느 부분에 속하는지 표현한다.
- 세 벡터의 차원을 같게 만들고 위치별로 더한다. 그 뒤 정규화와 드롭아웃을 적용한다.

```text
input_ids       : [CLS]  오늘  비가  온다  [SEP]  우산을  챙긴다  [SEP]
token_type_ids  :   0     0    0    0      0      1      1       1
```

- 위의 `input_ids` 행은 이해를 돕기 위해 토큰 글자로 표시했다. 실제 입력은 정수 번호다.
- `token_type_ids`의 0과 1은 문장 구분 번호다.
- 패딩이 추가되면 `attention_mask`로 실제 토큰과 패딩을 구분한다. Hugging Face의 BERT 입력에서는 실제 토큰에 1, 패딩에 0을 쓴다.

## 4. MLM의 예측 위치와 입력 변경

- Masked language modeling, MLM(가려진 토큰 예측)은 앞뒤 문맥으로 빈칸을 맞히는 학습이다.
- 원래 BERT는 일반 토큰 중 약 15%를 예측 대상으로 고른다.
- **선택된 위치 안에서** 80%는 `[MASK]`로 바꾸고, 10%는 임의의 토큰으로 바꾸고, 10%는 그대로 둔다.
- 세 경우 모두 정답은 바꾸기 전의 원래 토큰이다.
- 15%는 예측할 위치의 비율이고, 80·10·10은 선택된 위치를 처리하는 비율이다.

### 예측 대상 선택과 입력 변경의 차이

- 토큰 100개 중 15개를 예측 대상으로 골랐다고 하자.
- 평균적으로 약 12개를 `[MASK]`로 바꾸고, 나머지 3개는 임의의 토큰 교체와 원형 유지에 나누어 사용한다.
- 입력에서 보이는 `[MASK]`만 세면 전체 예측 대상의 수와 달라질 수 있다.
- 여러 부분 토큰으로 나뉜 단어를 한꺼번에 가리는 Whole-word masking(단어 단위 마스킹)도 있다.
- 단어의 나머지 조각만 보고 쉽게 답을 맞히는 상황을 줄이고, 문장 문맥을 더 참고하도록 만든다.

## 5. 입력 마스크와 손실 제외 표시

| 구분 | 무엇을 정하는가 |
| --- | --- |
| 입력의 `[MASK]` | 모델에게 숨길 토큰의 내용 |
| `attention_mask` | Attention에서 참고할 실제 입력 위치 |
| 손실 계산용 라벨 | 어떤 위치의 예측을 정답과 비교할지 |

- `[MASK]`가 있는 위치도 입력 시퀀스의 일부다. 보통 `attention_mask`는 1이다.
- BERT 인코더는 앞뒤 문맥을 함께 읽으므로, GPT처럼 미래 위치 전체를 가리는 마스크를 쓰지 않는다.
- MLM의 손실은 예측 대상으로 선택한 위치에서 계산한다.

### torch 모듈의 full_like 함수와 라벨 텐서 구성

- MLM은 문맥에서 가린 토큰을 복원하는 학습이다. 모델이 읽을 입력과 맞혀야 할 원래 정답을 따로 보관하고, 선택한 위치에서만 손실을 계산한다.

**코드 예시**

```python
import torch

original = torch.tensor(2, 5, 6, 3)
selected = torch.tensor(False, False, True, False)

input_ids = original.clone()
input_ids[selected] = 4

labels = torch.full_like(original, -100)
labels[selected] = original[selected]
```

**코드 해설**

- `selected`의 `True` 한 칸이 입력 수정과 정답 배치에 공통으로 쓰인다. 입력에서는 그 자리를 4로 가리고, 라벨에서는 원래 값 6을 남긴다.
- 따라서 모델이 읽는 값은 4이고 맞혀야 할 답은 6이다. 나머지 세 위치는 문맥으로 읽되 이 예시의 손실 계산에서는 제외한다.

- 번호는 설명용이다. 여기서는 원래 토큰 `6`을 `[MASK]` 번호 `4`로 바꾼다.
- `Tensor.clone()` 메서드는 원본과 별도의 텐서를 만든다. 입력을 바꿔도 원래 정답을 보존할 수 있다.
- `torch.full_like(original, -100)`은 같은 형태의 텐서를 만들고 모든 값을 `-100`으로 채운다.
- Boolean indexing(참·거짓 값으로 위치 선택)을 사용해 선택된 위치만 바꾼다.
- 결과는 `input_ids = 2, 5, 4, 3`, `labels = -100, -100, 6, -100`이다.
- `-100`은 라벨 텐서에서 손실 계산을 제외할 위치를 표시한다. 입력 텐서에는 실제 토큰 번호를 사용한다.
- `torch.nn.CrossEntropyLoss`의 기본 `ignore_index`는 `-100`이다. 제외할 라벨 값과 손실 함수의 설정이 같아야 한다.

## 6. NSP와 SOP의 학습 문제

### NSP의 실제 다음 문장 판별

- Next sentence prediction, NSP(다음 문장 판별)는 원래 BERT의 학습 목표다.
- 절반은 같은 문서에서 실제로 이어지는 A와 B를 묶는다.
- 나머지 절반은 다른 문서에서 B를 뽑아 묶는다.
- `[CLS]` 위치의 표현을 사용해 두 경우를 구분한다.

### SOP의 문장 순서 판별

- Sentence order prediction, SOP(문장 순서 판별)는 ALBERT에서 사용한 학습 목표다.
- 같은 문서의 이어진 두 부분을 A→B 또는 B→A 순서로 놓는다.
- 문장의 주제는 비슷하게 유지하면서 순서가 자연스러운지 판단하도록 학습한다.
- A와 B를 뒤집어서 만드는 학습 문제는 순서 판별이다. 다른 문서의 B를 뽑아 비교하는 NSP와 정답을 만드는 방법이 다르다.

## 7. 토큰 예측 손실과 문장 관계 손실

- 인코더의 각 층은 Attention으로 토큰 사이의 정보를 섞고, FFN으로 각 위치의 벡터를 변환한다.
- 원래 BERT는 FFN에 GELU 활성 함수를 사용한다. 음수와 양수 입력을 크기에 따라 부드럽게 조절한다.
- 잔차 연결과 정규화를 포함한 층들을 반복해 문맥 표현을 만든다.
- 원래 BERT의 사전학습에서는 인코더 출력을 MLM과 NSP에 함께 사용한다.
- MLM 출력층은 토큰 위치마다 사전에 있는 토큰들의 점수를 계산한다.
- NSP 출력층은 문장 쌍마다 두 종류의 점수를 계산한다.
- MLM 손실과 NSP 손실을 더해 학습한다. 두 학습 목표가 같은 인코더의 가중치를 조정한다.

| 출력 | 형태의 의미 |
| --- | --- |
| MLM 점수 `(B, T, V)` | 문장 묶음 B개, 위치 T개, 토큰 후보 V개 |
| NSP 점수 `(B, 2)` | 문장 쌍 B개, 관계 종류 2개 |

- 예를 들어 문장 쌍 2개, 길이 8, 사전 크기 100이면 MLM 점수는 `(2, 8, 100)`이다.
- 사전학습을 마친 뒤 감정 분류를 한다면, 새 분류 출력층과 감정 라벨을 사용해 미세조정한다.

## 8. BERT 사전학습의 전체 흐름

1. 문서를 토큰으로 바꾸고 문장 두 부분을 묶는다.
2. 특수 토큰과 문장 구분 번호를 넣는다.
3. MLM 예측 위치를 고르고 원래 토큰을 정답으로 보관한다.
4. 선택한 입력 토큰을 정해진 비율로 바꾼다.
5. 세 임베딩을 더해 인코더에 넣는다.
6. 토큰 예측과 문장 관계 예측의 손실을 구한다.
7. 손실이 줄어들도록 가중치를 조정한다.

- **입력을 만드는 방식이 학습 문제를 결정한다. 입력, 정답, 손실에서 제외할 위치를 함께 읽는 것이 핵심이다.**
