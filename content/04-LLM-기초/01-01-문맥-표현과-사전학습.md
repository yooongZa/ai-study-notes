## 1. 사전학습 모델이 필요한 이유

- 영화 리뷰를 긍정과 부정으로 분류하려면 단어의 뜻과 문장 전체의 표현을 함께 읽어야 한다.
- 리뷰 몇백 개만으로 처음부터 학습하면, 모델은 언어의 기본 패턴과 감정 분류를 한꺼번에 배워야 한다.
- **많은 글로 언어의 패턴을 먼저 학습한 뒤, 리뷰 데이터로 감정 분류를 배우게 하면 앞서 학습한 내용을 활용할 수 있다.**
- 이때 먼저 학습하는 과정을 Pre-training(사전학습), 특정 작업에 맞춰 추가 학습하는 과정을 Fine-tuning(미세조정)이라고 한다.
- 사전학습 모델을 이해하면 모델을 불러오는 이유와, 추가로 어떤 데이터를 준비해야 하는지 알 수 있다.

## 2. 단어의 의미와 문맥 벡터

- `차를 마셨다`에서 `차`는 음료를 가리킨다.
- `차를 주차했다`에서 `차`는 자동차를 가리킨다.
- Word2Vec처럼 단어마다 하나의 벡터를 저장하는 방식은 두 문장의 `차`에 같은 벡터를 꺼내 준다.
- Contextual representation(문맥을 반영한 표현)은 주변 단어까지 계산해 각 위치의 벡터를 만든다.
- `마셨다`와 함께 읽은 `차`의 벡터와, `주차했다`와 함께 읽은 `차`의 벡터가 달라진다.

### 입력 임베딩과 문맥 벡터의 차이

- 입력 임베딩은 토큰 번호로 표에서 찾아오는 기본 벡터다.
- 문맥 벡터는 기본 벡터들이 LSTM이나 Transformer의 계산을 거친 결과다.
- 같은 토큰 번호는 같은 입력 임베딩에서 출발해도, 함께 입력된 문장에 따라 서로 다른 문맥 벡터가 될 수 있다.
- 모델을 설명할 때 나오는 Hidden state(은닉 상태)는 이런 중간 계산 결과를 뜻한다.

## 3. 글에서 학습 정답을 만드는 방법

- 언어 모델은 문장의 일부를 읽고, 아직 보지 못한 토큰이 무엇인지 예측하도록 학습할 수 있다.
- 정답 토큰은 원래 문장 안에 있다. 사람이 모든 문장에 분류 라벨을 붙일 필요가 없다.
- 데이터 자체에서 학습 문제와 정답을 만드는 방식을 Self-supervised learning(자기지도학습)이라고 한다.

| 학습 문제 | 입력과 정답의 예 |
| --- | --- |
| 다음 토큰 예측 | `나는 밥을`을 읽고 `먹는다`를 예측한다. |
| 가려진 토큰 예측 | `나는 [MASK]을 먹는다`를 읽고 가려진 내용을 예측한다. |
| 손상된 글 복원 | 일부가 지워진 글을 읽고 원래 글을 생성한다. |

- 어떤 문제를 풀게 하는지가 모델의 학습 목표다.
- 입력을 읽을 수 있는 범위도 이 목표에 맞게 정한다. 다음 토큰을 맞힐 때는 정답이 있는 미래 부분을 가린다.

## 4. ELMo의 문맥 표현과 층별 가중합

- ELMo는 단어를 항상 같은 벡터로 표현할 때 생기는 문제를 해결하려는 모델이다.
- 단어를 이루는 문자 정보에서 기본 벡터를 만들고, 두 방향의 LSTM으로 문맥을 읽는다.
- 순방향 언어 모델은 앞의 내용을 읽고 뒤의 토큰을 예측한다.
- 역방향 언어 모델은 뒤의 내용을 읽고 앞의 토큰을 예측한다.
- 두 방향은 사전학습에서 각각 예측한다. 표현을 사용할 때 각 방향과 각 층의 결과를 결합한다.
- 작업에 맞춰 각 층의 결과에 서로 다른 비중을 주면, 필요한 정보를 더 많이 반영할 수 있다.

### 가중합의 의미

- 두 층의 벡터가 `[1, 0]`, `[0, 1]`이라고 하자.
- 첫 층에 0.2, 둘째 층에 0.8의 비중을 주면 결과는 `[0.2, 0.8]`이다.
- ELMo에서는 이런 비중을 작업 데이터로 학습한다. 실제 모델은 더 큰 벡터와 여러 층을 사용한다.

## 5. GPT와 BERT의 문맥 범위와 학습 목표

### GPT의 앞 문맥과 다음 토큰 예측

- GPT는 Transformer의 디코더를 바탕으로 만든 언어 모델이다.
- 각 위치에서 자기 위치까지의 토큰을 읽고, 다음 토큰 후보들의 점수를 계산한다.
- 다음 토큰을 선택해 입력 뒤에 붙이는 과정을 반복하면 문장을 생성할 수 있다.
- 학습 때는 Causal mask(미래를 가리는 마스크)를 사용해 정답 토큰을 미리 읽지 못하게 한다.

### BERT의 양방향 문맥 표현

- BERT는 Transformer의 인코더를 사용한다.
- 입력의 앞부분과 뒷부분을 함께 읽고 각 토큰의 표현을 만든다.
- 사전학습에서는 일부 토큰을 가린 뒤 원래 토큰을 맞힌다.
- 문장 분류, 문장 관계 판단, 문서에서 답의 위치 찾기처럼 주어진 입력을 분석하는 작업에 연결할 수 있다.

| 구조 | 입력을 읽고 출력을 만드는 방식 |
| --- | --- |
| Encoder(인코더) | 입력 전체를 함께 읽고 토큰별 표현을 만든다. |
| Decoder(디코더) | 앞의 내용을 읽고 다음 토큰을 예측한다. |
| Encoder-decoder | 인코더가 입력을 읽고, 디코더가 그 결과를 참고해 출력 문장을 만든다. |

## 6. 사전학습 표현과 작업용 출력층

- Transfer learning(전이학습)은 한 작업에서 학습한 내용을 다른 작업에 활용하는 방법이다.
- 리뷰 분류에서는 문장을 읽는 모델에 긍정·부정 점수 두 개를 내는 출력층을 붙인다.
- 이 출력층을 Head(헤드)라고 부른다. 문맥을 계산하는 기본 모델과 역할을 나누어 이해하면 쉽다.
- 전체 미세조정에서는 기본 모델과 출력층의 가중치를 함께 바꾼다.
- 기본 모델을 고정하고 출력층만 학습하는 방법도 있다. 이때는 기존 문맥 표현을 분류에 맞게 조합하는 방법을 배운다.

### torch.nn 모듈의 Linear 클래스 활용

- 사전학습 모델이 만든 문장 표현을 특정 작업에 쓰려면 작업에 맞는 출력층이 필요하다. 감정 분류에서는 문장 벡터를 긍정·부정 점수로 바꾸는 작은 선형층을 연결한다.

**코드 예시**

```python
import torch
from torch import nn

sentence_vectors = torch.tensor([
    [0.2, 0.8, -0.1, 0.4],
    [0.7, 0.1, 0.3, -0.2],
])
classifier = nn.Linear(4, 2)
logits = classifier(sentence_vectors)
```

**코드 해설**

- `classifier`는 `nn.Linear` 클래스로 만든 분류 레이어 객체다. 문장 벡터 한 개를 읽어 클래스별 점수 두 개를 계산한다.
- 예를 들어 0번을 부정, 1번을 긍정으로 정했다면 각 행의 두 점수를 비교해 감정을 고른다. 학습에서는 이 점수와 실제 감정 라벨을 비교해 가중치를 조정한다.

- `sentence_vectors`는 문장 두 개의 표현을 가정한 값이다. 문장 하나를 숫자 4개로 표현했다.
- `nn.Linear(4, 2)`는 숫자 4개를 받아 점수 2개를 내는 레이어를 만든다.
- `logits`의 형태는 `(2, 2)`다. 첫 축은 문장 수, 둘째 축은 분류할 종류의 수다.
- Logit(로짓)은 확률로 바꾸기 전의 점수다.
- 새로 만든 `classifier`는 아직 학습되지 않았다. 정답 라벨과 점수를 비교하며 분류 기준을 배워야 한다.

## 7. 사전학습부터 미세조정까지의 흐름

1. 많은 글에서 다음 토큰이나 가려진 토큰을 예측하도록 학습한다.
2. 학습한 토크나이저, 모델 구조, 가중치를 함께 보관한다.
3. 리뷰 분류처럼 해결할 작업과 정답 형식을 정한다.
4. 해당 작업에 맞는 출력층을 연결한다.
5. 작업 데이터로 미세조정한다.
6. 학습에 쓰지 않은 데이터로 결과를 평가한다.

- **문맥 표현은 문장을 읽는 계산 결과이고, 사전학습은 그 계산에 필요한 가중치를 배우는 과정이다.**
