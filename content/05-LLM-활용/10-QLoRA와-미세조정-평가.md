---
title: "10. QLoRA와 미세조정 평가"
---

사내 요청을 정해진 분류나 JSON 형식으로 답하게 하려면 좋은 입력·답변 예시로 모델을 학습시킬 수 있습니다. 큰 모델의 모든 가중치를 학습하면 메모리가 많이 필요하므로, 기본 모델은 작게 보관하고 일부 추가 가중치를 학습하는 방법을 사용합니다. 이 강의에서는 **QLoRA의 메모리 절약 원리부터 데이터 준비와 학습 전후 평가까지** 연결합니다.

## 학습 목표와 흐름

먼저 줄이려는 오류와 원하는 답변 행동을 정합니다. LoRA의 두 작은 행렬과 QLoRA의 양자화를 이해한 뒤, 학습할 데이터와 답변 토큰을 구성합니다. 마지막에는 프롬프트 효과와 학습 효과를 나누어 평가하고 모델을 다시 사용할 정보를 보관합니다.

## 자습

### 1. 미세조정으로 바꾸려는 답변 행동을 정하는 방법

항상 같은 업무 분류 기준을 적용하거나 정해진 출력 형식을 지키게 하고 싶다면, 원하는 답변의 예시를 반복해서 학습시킬 수 있습니다. Fine-tuning(미세조정)은 이런 학습으로 가중치와 출력 경향을 바꿉니다.

먼저 기본 모델에 명확한 지시와 예시를 주고 어떤 오류가 남는지 확인합니다. 답변에 필요한 사실이 입력에 없다면 RAG로 근거를 보완합니다. 반복되는 형식·분류·응답 방식의 오류는 학습 목표로 구체화합니다. 최신 규정은 검색으로 전달하면서 그 규정을 설명하는 방식은 학습으로 조정할 수 있습니다.

“사내 데이터로 학습한다”는 목표를 “입력의 부서와 날짜를 지정한 JSON 필드에 넣고, 정보가 없으면 누락으로 표시한다”처럼 정하면 데이터와 평가 기준을 만들기 쉬워집니다.

### 2. 작은 추가 행렬을 학습하는 LoRA의 원리

선형 계층의 큰 가중치 전체를 갱신하면 그만큼 많은 기울기와 옵티마이저 상태를 보관해야 합니다. LoRA(Low-Rank Adaptation, 저랭크 적응)는 기존 가중치를 고정하고 변화량을 두 작은 행렬의 곱으로 표현합니다.

사용할 가중치는 다음처럼 나타낼 수 있습니다.

$$W_{\text{사용}}=W_0+sBA$$

$W_0$는 고정할 기존 가중치입니다. 출력 차원이 $d_{out}$, 입력 차원이 $d_{in}$이면 $W_0$의 모양은 $d_{out}\times d_{in}$입니다. 새 행렬 $A$는 $r\times d_{in}$, $B$는 $d_{out}\times r$이며, 곱 $BA$가 원래 가중치와 같은 모양의 변화량을 만듭니다. Rank(랭크) $r$은 두 행렬 사이의 작은 차원입니다.

입출력 차원이 각각 1,000이고 $r=8$이라면 원래 가중치는 100만 개, 추가 행렬은 $8\times1,000+1,000\times8=16,000$개입니다. 기본 LoRA의 배율 $s$는 $\alpha/r$입니다. 어느 층에 붙이는지와 랭크가 추가 학습량을 정합니다.

### 3. 기본 가중치를 4비트로 보관하는 QLoRA

LoRA를 사용해도 큰 기본 모델의 가중치는 메모리에 있어야 합니다. QLoRA는 그 기본 가중치를 4비트 양자화 형태로 보관하고, 작은 LoRA 가중치를 학습합니다. 계산할 때 필요한 기본 가중치를 연산 자료형으로 복원해 추가 경로와 함께 사용합니다.

이때 **저장하는 값, 계산하는 값, 학습으로 바꾸는 값**을 나누어 보면 구조가 분명해집니다. 기본 가중치는 4비트로 저장하고, 계산에는 FP16·BF16 등을 사용할 수 있으며, LoRA의 행렬은 기울기로 갱신합니다. 기본 가중치가 고정되어 있어도 필요한 계산 경로를 따라 학습 가능한 행렬까지 기울기가 전달됩니다.

NF4는 정규분포를 기준으로 표현값을 배치한 4비트 형식입니다. Double quantization(이중 양자화)은 양자화 스케일도 더 작은 형식으로 저장해 추가 공간을 줄입니다. Paged optimizer(페이지 기반 옵티마이저)는 학습 중 메모리 사용 급증을 다루는 장치입니다. 실제 학습 메모리에는 활성값·추가 가중치·기울기·옵티마이저 상태도 포함됩니다.

### 4. 학습 예시와 데이터 분할을 구성하는 방법

학습은 데이터에 반복되는 대응 관계를 익힙니다. 따라서 입력에는 판단에 필요한 조건을, 목표 답변에는 그 조건에 맞는 결과를 넣습니다. 형식만 맞고 숫자나 대상이 틀린 예시는 수정합니다. 정상 사례와 함께 예외, 자료 부족, 모호한 입력을 포함하면 실제 요청에서 필요한 행동을 가르칠 수 있습니다.

Train(학습)은 가중치를 바꾸고, Validation(검증)은 설정과 종료 시점을 고르며, Test(평가)는 선택이 끝난 모델을 확인합니다. 같은 문서나 질문에서 표현만 바꾼 예시는 한 그룹으로 묶어 한쪽에 배치합니다. 서로 비슷한 예시가 학습과 평가에 섞이지 않도록 분리하기 위해서입니다.

데이터 양은 질문 유형과 목표 행동을 얼마나 잘 다루는지와 함께 봅니다. 먼저 좋은 예시로 기준선을 만들고, 실패하는 유형을 확인해 필요한 데이터를 보완합니다. 합성한 예시도 원문과 대조해 사실과 조건을 확인합니다.

### 5. 질문을 보고 답변을 만들도록 학습하는 방법

대화 학습에서는 사용자 질문과 원하는 답변을 모델의 대화 템플릿으로 연결합니다. 모델은 앞 토큰을 보고 다음 토큰을 예측합니다. 이때 어떤 위치의 예측을 학습에 반영할지 정해야 합니다.

Assistant-only loss(답변 부분의 손실)는 답변 토큰 중심으로 손실을 계산합니다. 질문과 패딩처럼 제외할 위치에는 손실 함수의 무시 값을 넣습니다. PyTorch 교차 엔트로피 손실의 기본 `ignore_index`는 `-100`입니다. 답변 시작과 종료 토큰까지 맞춰야 원하는 답을 내고 적절히 끝내는 방식을 학습합니다.

다음 토큰에 맞춰 예측과 정답 위치를 이동하는 처리는 모델·학습기의 구현을 확인합니다. 이미 이동하는 구현에는 정답을 다시 이동시키지 않습니다. 실제 예시 하나의 토큰과 학습 대상 위치를 읽으면 질문을 학습하는지, 답변을 학습하는지 확인할 수 있습니다.

### 6. 설정에서 학습할 파라미터까지 연결하는 방법

양자화 설정은 기본 가중치의 저장 형식과 계산 자료형을 정합니다. LoRA 설정은 추가 행렬을 붙일 모듈, 랭크, 배율, 드롭아웃을 정합니다. 학습률·에포크·배치·입력 길이는 별도의 학습 설정이며, 검증 결과와 메모리를 보며 선택합니다.

PEFT의 `prepare_model_for_kbit_training()`은 기본 가중치 고정과 필요한 자료형 조정 등 저비트 학습 준비를 수행합니다. `get_peft_model()`은 설정에 맞는 어댑터를 연결합니다. 이 과정은 전달한 모델의 내부 모듈에도 영향을 주므로 학습 전 비교 결과를 먼저 확보합니다. [PEFT 저비트 학습 안내](https://huggingface.co/docs/peft/developer_guides/quantization)

목표 모듈은 모델 안의 실제 이름과 맞춰야 합니다. 랭크를 키우면 표현할 변화량과 추가 파라미터가 늘고, 많은 층에 붙이면 학습량도 늘어납니다. 학습 가능한 파라미터를 확인하면 의도한 부분만 바뀌도록 구성됐는지 알 수 있습니다.

### 7. 프롬프트 효과와 학습 효과를 나누어 평가하는 방법

학습 후 답변이 좋아졌는데 프롬프트도 함께 바뀌었다면 무엇의 효과인지 나누어 봐야 합니다. 같은 평가 질문에서 다음 네 조건을 비교할 수 있습니다.

| 조건 | 확인할 변화 |
|---|---|
| 학습 전 + 간단한 지시 | 기본 수행 능력 |
| 학습 전 + 자세한 안내 | 안내와 예시의 효과 |
| 학습 후 + 간단한 지시 | 학습한 행동이 나타나는지 |
| 학습 후 + 자세한 안내 | 학습과 안내를 함께 쓴 결과 |

모델 판본·양자화·생성 설정을 유지하고 출력 형식, 사실 정확성, 예외 처리를 나누어 평가합니다. 학습 손실과 함께 새로운 질문의 결과를 봅니다. 학습 점수만 좋아지고 검증 결과가 나빠지면 Overfitting(과적합)을 살핍니다. 원래 잘하던 작업도 확인해 기존 능력이 크게 떨어지는 Catastrophic forgetting(파국적 망각)이 있는지 봅니다.

### 8. 학습한 모델을 다시 사용하는 데 필요한 정보

LoRA 어댑터에는 학습한 추가 가중치와 설정이 들어갑니다. 이를 다시 사용하려면 같은 기본 모델과 토크나이저, 대화 템플릿이 필요합니다. 기본 모델의 판본, 양자화 설정, 데이터 구성과 평가 결과를 함께 기록합니다.

Merge(병합)는 LoRA 변화량을 기본 가중치에 반영하는 방법입니다. 사용할 기본 가중치의 정밀도와 저장 형식을 정하고, 저장 후 다시 불러와 답변을 평가합니다. 학습 중의 손실 감소에서 끝내지 않고 실제 사용할 파일에서 목표 행동이 유지되는지 확인합니다.

## 이해 확인

> [!question]- QLoRA에서 저장·계산·학습 대상은 각각 무엇인가요?
> 기본 가중치를 4비트로 저장하고 필요한 계산 자료형으로 복원해 사용하며, 작은 LoRA 행렬을 학습합니다.

> [!question]- 같은 질문을 바꿔 쓴 예시를 한 그룹으로 나누는 이유는 무엇인가요?
> 비슷한 예시가 학습과 평가에 함께 들어가는 것을 막고 새로운 질문에 대한 수행 능력을 확인하기 위해서입니다.

> [!question]- 어댑터 파일과 함께 보관할 것은 무엇인가요?
> 기본 모델의 이름·판본, 토크나이저와 대화 템플릿, 양자화·학습 설정, 데이터 구성과 평가 결과입니다.
