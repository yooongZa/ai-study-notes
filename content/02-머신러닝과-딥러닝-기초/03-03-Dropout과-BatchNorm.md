## 1. Dropout과 BatchNorm을 배우는 이유

- 신경망은 여러 레이어를 거치며 입력을 변환한다. 학습 중에는 앞 레이어의 가중치도 계속 바뀐다.
- 일부 중간 값에 지나치게 의존하거나 중간 값의 크기가 학습을 어렵게 만들 수 있다.
- Dropout(드롭아웃)은 학습 중 일부 값을 무작위로 0으로 만들어 다양한 계산 경로를 사용하게 한다.
- Batch normalization(배치 정규화)은 중간 값의 크기를 조정해 학습을 돕는다.
- 두 방법 모두 **학습할 때와 평가할 때의 동작이 다르다**. 이 차이를 이해해야 예측 코드를 올바르게 읽을 수 있다.

---

## 2. Dropout의 무작위 제거와 출력 크기 조정

- 어떤 중간 값이 항상 강한 단서가 되면 뒤 레이어가 그 값에 크게 의존할 수 있다.
- 드롭아웃은 학습할 때마다 일부 원소를 무작위로 0으로 만든다.
- 뒤 레이어는 매번 남아 있는 값들로 예측해야 하므로 여러 정보를 함께 활용하도록 학습된다.
- 각 실행에서 선택된 중간 출력이 0으로 바뀐다. 다음 실행에서는 다시 출력값을 계산하고, 새로 고른 위치에 Dropout을 적용한다.
- 확률 `p=0.5`는 각 원소가 0이 될 확률이 50%라는 뜻이다. 매번 정확히 절반을 고정해서 지우는 방식과는 다르다.

### torch.nn 모듈의 Dropout 클래스의 활용

- Dropout은 학습 때 일부 중간 출력을 무작위로 0으로 만들어 특정 값에만 의존하는 현상을 줄인다. 학습과 평가에서 같은 입력이 어떻게 처리되는지 비교한다.

**코드 예시**

```python
import torch
from torch import nn

dropout = nn.Dropout(p=0.5)
x = torch.ones(4)
dropout.train()
y_train = dropout(x)
dropout.eval()
y_eval = dropout(x)
```

**코드 해설**

- 같은 입력 `x`를 두 번 사용하지만, 호출 전의 모드가 다르다. `train()` 뒤의 호출은 무작위 제거를 적용하고, `eval()` 뒤의 호출은 입력을 그대로 돌려준다.

- `torch` 모듈의 함수인 `ones(4)`는 1 네 개를 가진 텐서를 만든다.
- 학습 모드에서는 각 값이 0 또는 2가 될 수 있다. 0이 되지 않은 값을 `1 / (1-p)`배 하기 때문이다.
- 남은 값의 크기를 조정하면 출력의 기댓값을 원래 입력과 같게 유지할 수 있다.
- 평가 모드에서는 모든 값을 그대로 전달한다. 위 코드의 `y_eval`은 `[1, 1, 1, 1]`이다.
- 모델 안에 있는 드롭아웃은 모델의 `train()`과 `eval()`을 호출하면 함께 모드가 바뀐다.

## 3. BatchNorm의 평균·분산과 정규화

- 한 배치에 들어온 중간 값의 평균과 분산을 계산한다.
- 평균을 빼고 표준편차에 해당하는 값으로 나눠 크기를 조정한다.
- 그다음 학습 가능한 배율 `γ`와 이동량 `β`를 적용한다.

$$\hat x=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}$$

$$y=\gamma\hat x+\beta$$

- `μ_B`는 해당 배치에서 계산한 평균, `σ_B²`는 분산이다.
- `ε`는 분모가 지나치게 작아지는 것을 막는 작은 양수다.
- `γ`와 `β`는 학습으로 정한다. 정규화한 값을 뒤 레이어에 필요한 크기와 위치로 다시 조정한다.
- 평균과 분산은 데이터에서 계산하는 통계값이다. `γ`, `β`는 기울기로 갱신하는 매개변수다.
- 이런 변환은 중간 값의 스케일을 관리해 최적화를 돕는다. 배치마다 달라지는 통계가 규제 효과를 내기도 한다.

## 4. BatchNorm1d·BatchNorm2d의 계산 축

### torch.nn 모듈의 BatchNorm1d 클래스의 활용

- BatchNorm은 특성마다 배치의 평균과 분산을 구해 값을 정규화한다. 한 열에 모인 여러 샘플의 값을 함께 계산하므로 어느 축이 특성인지가 중요하다.

**코드 예시**

```python
bn = nn.BatchNorm1d(3)
x = torch.tensor([
    [1.0, 10.0, 100.0],
    [3.0, 20.0, 200.0],
])
y = bn(x)
```

**코드 해설**

- 세 열을 따로 읽어 각각 평균을 구하면 2, 15, 150이다. 각 열의 값에서 그 열의 평균을 빼고 크기를 조정하므로, 단위가 다른 세 특성을 비슷한 규모로 다룰 수 있다.

- 입력 형태는 `(샘플 2개, 특성 3개)`다.
- `BatchNorm1d(3)`의 3은 특성 열의 수다. 이 입력에서는 행이 샘플 2개, 열이 특성 3개를 나타낸다.
- 첫 특성은 `[1, 3]`, 둘째는 `[10, 20]`, 셋째는 `[100, 200]`을 각각 묶어 평균과 분산을 계산한다.
- 출력 형태는 입력과 같은 `(2, 3)`이다.
- 이미지의 `(N, C, H, W)` 형태에는 같은 모듈의 클래스인 `BatchNorm2d(C)`를 사용한다.
- BatchNorm2d는 채널마다 배치와 공간 위치를 함께 묶어 통계를 계산한다.

## 5. 학습 중 통계와 평가 시 통계의 사용

- 기본 BatchNorm은 학습 중 배치의 평균과 분산을 계산하면서 이동 평균도 저장한다.
- 평가에서는 저장한 이동 평균과 분산으로 입력을 변환한다.
- 이렇게 하면 한 샘플의 평가 결과가 같은 배치에 어떤 다른 샘플을 넣었는지에 따라 바뀌는 영향을 줄일 수 있다.
- `nn.Module` 객체의 메서드인 `eval()`을 호출하면 기본 BatchNorm이 저장된 통계를 사용하도록 바뀐다.
- `torch.no_grad()`는 기울기 기록을 끈다. BatchNorm의 통계 사용 방식은 `eval()`로 정한다.

### BatchNorm의 momentum과 누적 통계 갱신

$$새\ 통계=(1-m)\times 기존\ 통계+m\times 현재\ 배치\ 통계$$

- `momentum=0.1`이면 기존 통계를 90%, 현재 배치 통계를 10% 반영한다.
- 이 인자는 통계값 갱신에 사용하는 비율이다. 옵티마이저에서 사용하는 같은 이름의 인자와 구분한다.
- 학습 모드에서 특성당 값이 하나뿐이면 분산을 제대로 추정하기 어렵다. 예를 들어 `(1, C)` 입력의 BatchNorm1d는 학습 중 오류가 난다.
- 평가 모드에서는 기본 설정으로 저장된 통계를 사용하므로 배치 크기 1도 처리할 수 있다.

## 6. Linear·BatchNorm·ReLU·Dropout의 연결

- 레이어를 연결할 때는 앞 출력이 다음 입력이 된다. 가중합, 정규화, 비선형 변환, 무작위 제거, 최종 점수 계산을 차례로 연결해 각 역할을 살펴본다.

**코드 예시**

```python
model = nn.Sequential(
    nn.Linear(10, 32),
    nn.BatchNorm1d(32),
    nn.ReLU(),
    nn.Dropout(p=0.3),
    nn.Linear(32, 2),
)
```

**코드 해설**

- `Linear(10, 32)`는 입력 특성 10개에서 중간 값 32개를 계산한다.
- `BatchNorm1d(32)`는 그 중간 값의 크기를 특성별로 조정한다.
- `ReLU`는 음수를 0으로 바꾸는 비선형 변환을 적용한다.
- `Dropout`은 학습 중 각 원소를 확률 0.3으로 0으로 만든다.
- 마지막 `Linear`는 클래스 2개의 로짓을 계산한다.
- 이 순서는 각 부품의 역할을 읽기 위한 한 가지 구성이다. 출력의 형태를 확인하면서 다음 레이어의 입력 크기를 맞춘다.

## 7. 학습 곡선으로 확인하는 효과

- 같은 데이터 분할과 같은 평가 조건에서 기법을 적용하기 전후를 비교한다.
- 드롭아웃을 쓰면 학습이 더 어려워져 학습 손실이 높아질 수 있다. 검증 손실이 낮아지는지 함께 확인한다.
- BatchNorm은 학습 속도와 안정성에 영향을 준다. 검증 성능과 학습 손실의 변화를 함께 살펴본다.
- 드롭아웃이 켜진 학습 상태와 꺼진 평가 상태는 계산 조건이 다르다. 곡선의 차이를 해석할 때 이 차이를 반영한다.
- 예측 전에는 `model.eval()`, 학습을 다시 시작할 때는 `model.train()`을 호출한다.
