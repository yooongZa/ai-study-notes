## 1. 실제 데이터로 수치 예측을 배우는 이유

- 회귀 공식을 알아도 실제 표에서는 무엇을 입력으로 정할지, 어떤 자료로 평가할지 먼저 결정해야 한다.
- 예측하려는 답을 입력에 넣거나 평가 방법을 잘못 정하면 수치가 좋아 보여도 실제 사용 목적에 맞지 않을 수 있다.
- 이 두 예제는 **문제 정의 → 입력 준비 → 학습 → 예측 → 오차 해석**을 연결해서 이해하기 위한 사례다.
- 당뇨병 예제는 여러 특성으로 수치를 예측하는 구조를, 자전거 예제는 시간 정보와 입력 선택을 보여준다.

## 2. 당뇨병 데이터의 입력 특성과 정답

- scikit-learn의 당뇨병 데이터에는 환자별 나이, 성별, BMI, 혈압 등 10개 특성이 들어 있다.
- 정답은 기초 측정 후 1년이 지난 시점의 질병 진행 정도를 나타내는 수치다.
- 이 데이터에서는 진행 정도를 수치로 예측하는 회귀 문제를 다룬다.
- 입력 `X`는 `(환자 수, 10)`, 정답 `y`는 `(환자 수,)` 형태다.
- 선형 회귀에서는 특성별 가중치 10개와 편향 1개를 학습한다.

### sklearn.datasets 모듈의 load_diabetes 함수의 활용

- 회귀 문제의 자료는 입력 특성과 연속된 수치 정답으로 구성된다. 당뇨병 예제에서는 환자별 측정 특성으로 질환 진행 정도를 예측한다.

**코드 예시**

```python
from sklearn.datasets import load_diabetes

X, y = load_diabetes(return_X_y=True)
```

**코드 해설**

- `return_X_y=True`는 입력과 정답을 두 배열로 받겠다는 옵션이다.
- 기본 입력은 스케일이 조정된 수치다. 각 값은 원래 나이·혈압을 학습용 기준에 맞춰 변환한 결과다.
- `X @ w + b`로 환자별 예측값을 계산하고 MSE로 정답과의 차이를 구할 수 있다.
- 직접 구현한 경사하강법과 라이브러리의 회귀 모델은 모두 입력과 수치 정답의 관계를 학습한다.

## 3. 자전거 대여량 예측의 입력 선택

- 한 행은 특정 날짜·시간의 대여 기록이다.
- `count`는 해당 시간의 전체 대여량이며 예측할 정답이다.
- 기온인 `temp`, 습도인 `humidity`, 풍속인 `windspeed`, 시간 정보 등은 입력 후보가 된다.
- `casual`은 비회원 대여량, `registered`는 회원 대여량이다. 두 값을 더하면 `count`가 된다.
- 앞으로의 대여량을 예측할 때는 아직 집계되지 않은 `casual`, `registered`를 입력에서 제외한다.
- **예측 시점에 알 수 있는 정보**로 입력을 구성해야 실제 사용 상황과 같은 문제를 풀 수 있다.
- 날씨를 입력으로 쓴다면 예측 시점에 확보할 수 있는 예보값인지, 나중에 기록된 실제 날씨인지도 구분한다.

## 4. 날짜 자료형과 시간·요일 특성 추출

- `'2011-01-03 15:00:00'`이라는 문자열에는 연도, 월, 날짜, 시간 정보가 함께 들어 있다.
- 날짜 자료형으로 바꾸면 시간대와 요일 등을 별도 특성으로 꺼낼 수 있다.
- 출퇴근 시간과 한밤중의 수요 차이를 학습하려면 이런 정보가 숫자로 표현되어야 한다.

### pandas 모듈의 to_datetime 함수의 활용

- 날짜 전체보다 시간대나 요일에 따라 수요가 반복될 수 있다. 날짜를 해석한 뒤 필요한 부분을 따로 꺼내 입력 특성으로 만든다.

**코드 예시**

```python
import pandas as pd

time = pd.to_datetime(df['datetime'])
df['hour'] = time.dt.hour
df['weekday'] = time.dt.dayofweek
```

**코드 해설**

- `2011-01-03 15:00:00`을 읽으면 `hour`는 15, `weekday`는 월요일을 뜻하는 0이 된다. 문자열 하나에서 모델이 사용할 숫자 두 개를 꺼낸다.
- `time`은 여기서 날짜 자료를 담은 변수다. `.dt.hour`처럼 속성을 읽어 얻은 값이 `df`의 새 열에 저장된다.

- `df`는 대여 기록을 담은 표다.
- `to_datetime`은 날짜와 시간으로 해석할 수 있는 값을 날짜 자료형으로 바꾼다.
- `Series`의 `.dt`는 날짜·시간 정보를 꺼내는 접근자다.
- `.hour`는 0~23의 시각, `.dayofweek`는 월요일 0부터 일요일 6까지의 요일을 반환하는 속성이다.
- 매일 같은 시각에 수요가 반복된다면 `hour`가 유용한 입력이 될 수 있다.
- 모든 기록이 정각이라 `minute` 값이 전부 0이면, 그 열은 기록 간 차이를 설명하지 못한다.

### 시간대의 효과를 표현하는 방법

- 선형 회귀에 시간 숫자 하나만 넣으면 시간이 1 증가할 때 대여량이 일정하게 변하는 관계를 학습한다.
- 출근·퇴근 시간에 두 번 수요가 높아지는 형태는 시간대별로 구분해서 표현할 수 있다.
- 시간대를 범주로 나눠 원 핫 인코딩하면 시간별 가중치를 따로 학습한다.
- 시간의 주기성을 표현할 때는 사인·코사인 값으로 바꾸는 방법도 있다. 23시와 0시가 이어진다는 관계를 반영하는 데 사용한다.

## 5. 예측 시점에 맞는 데이터 분할

- 같은 시기의 여러 기록 중 일부를 맞히는 문제라면 무작위 분할로 성능을 살펴볼 수 있다.
- 앞으로의 날짜에 대한 수요를 예측하려면 과거 구간으로 학습하고 이후 구간으로 평가한다.
- 날짜순으로 나누면 계절 변화나 수요 변화가 생겼을 때의 예측 성능도 함께 확인한다.
- 결측치 대체와 스케일 기준은 학습 구간에서 정하고 평가 구간에 그대로 적용한다.
- 모델 설정은 검증 구간에서 선택한다. 테스트 구간은 최종 성능 확인에 사용한다.

## 6. MSE·RMSE·MAE와 오차의 단위

- MSE는 오차를 제곱한 평균이므로 대여량이 단위일 때 결과 단위는 대여량의 제곱이다.
- RMSE(평균제곱근오차)는 MSE에 제곱근을 취해 예측값과 같은 단위로 되돌린다.
- MAE(평균절대오차)는 오차의 절댓값을 평균한 값이다. 평균적으로 얼마나 빗나갔는지 읽기 쉽다.

$$\mathrm{RMSE}=\sqrt{\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2}$$

- 실제 대여량 `[10, 20]`, 예측량 `[12, 16]`이면 오차는 `[2, -4]`다.
- MSE는 `(4 + 16) / 2 = 10`, RMSE는 약 3.16, MAE는 3이다.
- RMSE는 큰 오차를 더 강하게 반영한다. 대여량 예측에서는 몇 번의 큰 실패가 점수에 크게 영향을 줄 수 있다.

### sklearn.metrics 모듈의 mean_squared_error 함수의 활용

- MSE는 큰 오차를 더 강하게 반영하고, RMSE는 제곱근을 취해 정답과 같은 단위로 돌아온다. MAE는 오차의 절댓값을 평균해 전형적인 오차 크기를 보여 준다.

**코드 예시**

```python
import numpy as np
from sklearn.metrics import mean_squared_error, mean_absolute_error

mse = mean_squared_error([10, 20], [12, 16])
rmse = np.sqrt(mse)
mae = mean_absolute_error([10, 20], [12, 16])
```

**코드 해설**

- 두 예측의 오차는 2와 -4다. `mean_squared_error()`는 10, `sqrt()`는 약 3.162, `mean_absolute_error()`는 3을 반환한다.

- 첫 번째 인자는 실제값, 두 번째 인자는 예측값이다.
- `numpy` 모듈의 함수인 `sqrt`는 제곱근을 구한다.
- `mean_absolute_error`는 오차 절댓값의 평균을 계산한다.
- 수치의 크기는 정답의 단위와 범위에 따라 달라진다. 같은 대여 자료에서 기준 모델과 비교하면 개선 정도를 읽기 쉽다.

## 7. 잔차와 시간대별 예측 오류

- Residual(잔차)을 여기서는 `실제값 - 예측값`으로 정의한다.
- 잔차가 양수이면 실제보다 적게 예측했다. 음수이면 실제보다 많이 예측했다.
- 전체 RMSE와 함께 시간대별 오차를 보면 어떤 상황을 놓치는지 알 수 있다.
- 출근 시간에 잔차가 반복해서 크면 그 시간대의 높은 수요를 충분히 반영하지 못한 것이다.
- 실제값을 가로축, 예측값을 세로축에 놓으면 두 값이 같은 대각선 가까이에 점이 모일수록 예측이 정확하다.
- 기온과 대여량을 그릴 때는 같은 기온에서도 시간·요일 등 다른 입력이 달라 대여량이 퍼질 수 있다.

## 8. 수치 예측의 전체 흐름

1. 예측할 수치와 예측할 시점을 정한다.
2. 그 시점에 알 수 있는 입력을 선택한다.
3. 날짜·범주·수치를 모델이 계산할 수 있게 표현한다.
4. 예측 목적에 맞게 학습·검증·테스트 자료를 나눈다.
5. 학습 자료로 전처리 기준과 모델의 가중치를 정한다.
6. 평가 자료를 예측하고 MSE·RMSE·MAE를 해석한다.
7. 오류가 큰 시간대와 조건을 찾아 입력이나 모델을 개선한다.
