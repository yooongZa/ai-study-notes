## 1. 거리·기울기·선형변환을 배우는 이유

- 비슷한 자료를 찾을 때는 입력 사이의 거리를 계산한다.
- 모델을 학습할 때는 가중치 변화에 따른 손실의 변화율을 구한다.
- 신경망 레이어에서는 행렬로 입력 벡터를 바꾼다.
- 이 문서는 세 계산을 작은 숫자로 살펴보는 선택 보충자료다. 필요한 절부터 읽어도 된다.

## 2. kNN의 거리 계산과 다수결 분류

- kNN(k-최근접 이웃)은 새 입력과 가까운 학습 자료 k개를 찾고, 그 자료들의 정답으로 예측한다.
- 분류에서는 가까운 자료 중 가장 많은 클래스를 선택할 수 있다.
- 예를 들어 길이가 1·2·3인 물건은 A, 7·8·9인 물건은 B로 기록돼 있다고 하자.
- 새 물건의 길이가 4이면 거리는 각각 `3, 2, 1, 3, 4, 5`다.
- `k=1`이면 가장 가까운 길이 3의 정답 A를 예측한다.
- k를 늘리면 더 넓은 주변의 자료가 예측에 참여한다.

### 2-1) Python 내장 min·abs 함수로 가장 가까운 자료 선택

- 가장 가까운 이웃의 정답을 사용하는 분류에서는 입력 사이의 거리가 판단 기준이다. 숫자 하나로 된 입력은 두 값의 차이의 절댓값으로 거리를 구할 수 있다.

**코드 예시**

```python
examples = [(1, "A"), (3, "A"), (8, "B")]
new_value = 4
nearest = min(examples, key=lambda row: abs(row[0] - new_value))
print(nearest[1])  # A
```

**코드 해설**

- `abs()`는 절댓값을 구하는 내장 함수다. 한 개의 수로 표현한 입력 사이의 거리를 계산한다.
- `lambda row: ...`는 자료 하나를 받아 거리를 반환하는 짧은 함수다.
- `min(..., key=...)`은 이 함수의 결과가 가장 작은 자료를 고른다.
- 예시에서는 길이 3이 가장 가깝고, `nearest`는 `(3, "A")`가 된다.
- 두 특성 이상이면 각 특성의 차이를 함께 계산한다. 유클리드 거리는 각 차이의 제곱을 더한 뒤 제곱근을 구한다.
- 단위가 큰 특성의 차이가 거리를 크게 좌우하므로, 나이·연봉처럼 단위가 다르면 스케일 조정을 함께 고려한다.

## 3. 수치 미분과 손실의 변화율

- 기울기는 가중치를 조금 바꿨을 때 손실이 얼마나 변하는지 나타낸다.
- Numerical differentiation(수치 미분)은 실제 값을 조금씩 바꿔 계산한 차이로 기울기를 근사한다.
- `w`의 양옆 `w-h`, `w+h`에서 손실을 구하고, 손실 차이를 가중치 간격 `2h`로 나눈다.

$$L'(w)\approx\frac{L(w+h)-L(w-h)}{2h}$$

### 3-1) Python 함수와 작은 변화량으로 기울기 계산

- 수치 미분은 현재 값의 양쪽을 조금 바꿔 보고 출력 변화량을 입력 변화량으로 나누는 방법이다. 직접 구한 미분값이 맞는지 작은 예시로 비교할 때 사용한다.

**코드 예시**

```python
def loss(w):
    return (w - 3) ** 2

w = 1.0
h = 0.001
gradient = (loss(w + h) - loss(w - h)) / (2 * h)
print(round(gradient, 3))  # -4.0
```

**코드 해설**

- `loss(w)`는 3에서 가장 작은 이차식이다. `w=1`, `h=0.001`로 두어 1.001과 0.999의 손실을 비교하고, 두 입력의 간격 `2*h`로 나누어 기울기를 얻는다.

- `loss()`는 이 예시에서 직접 정의한 함수다. `w=3`일 때 손실이 0이 된다.
- `w=1` 주변의 기울기는 약 -4다. 이 위치에서는 w를 조금 키우면 손실이 줄어든다.
- 수식으로 미분해도 `2(w-3)`이므로, `w=1`에서 -4가 나온다.
- 이런 비교를 Gradient check(기울기 검사)라고 한다. 직접 구현한 미분 계산을 확인할 때 유용하다.
- 가중치가 많으면 숫자를 하나씩 바꿔 확인하는 계산량도 늘어난다. 작은 예시에서 원리를 확인하고, 신경망 학습에서는 자동 미분으로 기울기를 구한다.

## 4. 기저 벡터와 행렬의 열

- 행렬의 숫자가 입력을 어떻게 바꾸는지 이해하려면, 두 기본 방향이 어디로 이동하는지 보면 된다.
- 평면에서 `e₁=[1, 0]`, `e₂=[0, 1]`을 표준 Basis vector(기저 벡터)라고 한다.
- `[3, 4]`는 `3e₁ + 4e₂`로 만들 수 있다. 가로 방향 세 배와 세로 방향 네 배를 더한 것이다.
- Linear transformation(선형변환)은 벡터를 더하거나 배수로 만든 관계를 변환 뒤에도 유지한다.
- 그래서 `A[3, 4]`는 `3Ae₁ + 4Ae₂`로 계산할 수 있다.
- 행렬 A의 첫째 열은 `Ae₁`, 둘째 열은 `Ae₂`다. 각 열은 기본 방향이 변환된 결과다.

### 4-1) NumPy 배열과 @ 연산자의 행렬 곱

- 행렬의 각 열은 입력의 기본 방향이 어디로 이동하는지 나타낸다. 입력 성분만큼 각 열을 곱해 더하면 변환된 위치를 구할 수 있다.

**코드 예시**

```python
import numpy as np

A = np.array([[2, 0], [0, 1]])
x = np.array([3, 4])
result = A @ x
print(result)  # [6 4]
```

**코드 해설**

- `np.array()`는 NumPy 모듈의 함수다. 숫자 목록을 배열로 만든다.
- `@`는 배열의 행렬 곱 연산자다.
- 첫째 열 `[2, 0]`은 가로 기본 방향을 두 배로 늘리고, 둘째 열 `[0, 1]`은 세로 기본 방향을 유지한다.
- `[3, 4]`는 `3[2, 0] + 4[0, 1] = [6, 4]`로 바뀐다.
- 신경망의 선형층에서도 같은 원리로 `Wx`를 계산한다. 여기에 편향 `b`를 더하면 결과의 위치를 이동시킨다.
