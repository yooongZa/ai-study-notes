## 1. 데이터 시각화가 필요한 이유

- 데이터가 많아지면 숫자만 읽어서는 자주 나타나는 값과 유난히 큰 값을 찾기 어렵다.
- 그래프는 숫자의 분포, 집단별 차이, 시간에 따른 변화를 눈으로 살펴보는 방법이다.
- 예를 들어 요일별 주문량을 그리면 어느 요일에 주문이 몰리는지 알 수 있다. 이 차이는 모델에 요일 정보를 넣을지 결정하는 데 도움이 된다.
- **EDA(탐색적 데이터 분석)는 모델을 만들기 전에 데이터의 특징을 살펴보는 과정**이며, 시각화는 그 과정에서 사용하는 도구다.

## 2. 표의 행·열과 변수의 종류

- 식당의 결제 기록을 예로 들면 한 행은 한 번의 결제다.
- `total_bill`은 결제 금액, `tip`은 팁, `day`는 요일을 나타내는 열이다.
- 수치형 변수는 금액처럼 크기와 차이를 계산할 수 있는 값이다.
- 범주형 변수는 요일처럼 종류를 구분하는 값이다.
- 손님 수는 수치형 변수다. 손님 수별 집단을 비교할 때는 각 수를 하나의 범주로 나눠 볼 수도 있다.

### pandas DataFrame의 head·info·describe 메서드 활용

- 그래프를 고르기 전에 표의 열 이름, 자료형, 빈 값과 값의 범위를 알아야 한다. 일부 행과 전체 요약 통계를 함께 보면 어떤 비교가 가능한지 판단할 수 있다.

**코드 예시**

```python
df.head()
df.info()
df.describe()
```

**코드 해설**

- `df`는 행과 열로 구성된 pandas의 `DataFrame` 객체다.
- `head()`는 기본적으로 첫 5행을 보여준다. 값의 모양과 열 이름을 먼저 살펴볼 때 쓴다.
- `info()`는 열별 자료형과 비어 있지 않은 값의 개수를 출력한다.
- `describe()`는 기본적으로 수치형 열의 평균, 표준편차, 최솟값, 사분위수 등을 계산한다.
- `df.shape`는 `(행 수, 열 수)`를 담은 **속성**이다. `rows, columns = df.shape`처럼 값을 바로 읽는다.

## 3. 알고 싶은 내용에 맞는 그래프 선택

| 알고 싶은 내용 | 적합한 그래프 |
| --- | --- |
| 요일별 평균 팁은 얼마나 다른가 | Bar chart(막대그래프)로 집단별 값을 비교한다. |
| 결제 금액이 클수록 팁도 커지는가 | Scatter plot(산점도)에서 두 값의 관계를 본다. |
| 팁 금액은 어느 구간에 많이 모이는가 | Histogram(히스토그램)으로 값의 분포를 본다. |
| 날짜가 지날수록 대여량이 어떻게 변하는가 | Line chart(선그래프)로 시간에 따른 변화를 본다. |

![[02-머신러닝과-딥러닝-기초/assets/그래프-네-가지.png]]

- 그림의 수치는 그래프를 읽는 방법을 보여주기 위한 예시다.
- 막대그래프는 범주별 값을 비교한다. 막대 높이가 개수인지, 합계인지, 평균인지 먼저 확인한다.
- 히스토그램은 숫자 범위를 여러 구간으로 나눈 뒤 각 구간에 들어간 값의 개수를 센다.
- 산점도의 점 하나는 관측값 한 건이다. 점의 가로 위치와 세로 위치가 각각 두 변수의 값이다.
- 선그래프는 순서가 있는 값을 이어서 그린다. 시간 자료는 날짜순으로 정렬해야 변화 방향을 읽을 수 있다.

## 4. Matplotlib의 Figure·Axes와 그래프 작성

- Matplotlib는 그래프의 축, 선, 눈금, 제목 등을 조정하는 라이브러리다.
- `Figure`는 그래프 전체를 담는 객체다.
- `Axes`는 가로축·세로축과 실제 데이터를 함께 담는 하나의 그래프 영역이다.

### matplotlib.pyplot 모듈의 subplots 함수의 활용

- 그래프는 데이터를 표시할 영역과 그 안에 그릴 값으로 구성된다. 아래에서는 요일별 주문량을 막대의 높이로 표현하고 축에 단위를 붙인다.

**코드 예시**

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(6, 4))
ax.bar(['Mon', 'Tue', 'Wed'], [10, 15, 12])
ax.set_xlabel('Day')
ax.set_ylabel('Orders')
```

**코드 해설**

- 실행 순서는 **그래프 영역 만들기 → 막대 그리기 → 축 이름 붙이기**다. `ax`에 속한 메서드들이 같은 그래프 영역을 차례로 수정한다.
- 그려진 막대의 높이는 월요일 10, 화요일 15, 수요일 12다. 가장 높은 화요일 막대가 주문량이 가장 많음을 보여 준다.

- `plt`는 `matplotlib.pyplot`에 붙인 짧은 이름이다.
- `figsize=(6, 4)`는 그림의 가로와 세로 크기를 인치 단위로 지정한다.
- `Axes` 객체의 메서드인 `bar`는 첫 번째 인자를 가로 위치, 두 번째 인자를 막대 높이로 사용한다.
- `Axes` 객체의 메서드인 `set_xlabel`, `set_ylabel`은 축 이름을 지정한다.
- 같은 `ax`에서 `scatter(x, y)`는 산점도, `plot(x, y)`는 선그래프, `hist(values, bins=10)`은 히스토그램을 만든다.
- `bins=10`은 값의 범위를 10개 구간으로 나눈다는 뜻이다. 구간을 너무 크게 잡으면 세부 분포가 뭉쳐 보인다.

## 5. pandas의 그룹별 집계와 Seaborn 그래프

- 요일별 평균 팁을 비교하려면 먼저 결제 기록을 요일별로 묶어야 한다.
- 그다음 각 묶음의 팁 평균을 구한다. 개별 결제 기록이 요일별 요약값으로 바뀐다.

### pandas DataFrame의 groupby 메서드의 활용

- 집단별 평균은 같은 집단에 속한 관측값을 모아 하나의 대표값으로 줄인 것이다. 요일을 기준으로 묶고 팁만 골라 평균을 구한다.

**코드 예시**

```python
average_tip = df.groupby('day')['tip'].mean()
```

**코드 해설**

- 예를 들어 월요일 팁이 2와 4, 화요일 팁이 5라면 결과는 월요일 3, 화요일 5다. 여러 결제 행이 요일당 요약값 하나로 바뀐다.

- `groupby('day')`는 요일이 같은 행을 묶는다.
- `['tip']`은 묶음 안에서 팁 열을 선택하는 인덱싱 문법이다.
- 그룹 객체의 메서드인 `mean()`은 각 요일의 평균 팁을 계산한다.
- 평균 3인 집단에 기록이 2개 있는 경우와 200개 있는 경우는 정보량이 다르다. 집단별 기록 수도 함께 확인한다.
- pandas `Series`의 메서드인 `value_counts()`는 값별 등장 횟수를 센다. `df['day'].value_counts()`로 요일별 건수를 확인할 수 있다.

### seaborn 모듈의 barplot 함수의 활용

- 평균 비교와 개별 기록의 관계는 서로 다른 질문이다. 막대그래프는 요일별 평균을, 산점도는 결제 금액과 팁이 함께 변하는 모습을 보여 준다.

**코드 예시**

```python
import seaborn as sns

sns.barplot(data=df, x='day', y='tip', errorbar=None)
sns.scatterplot(data=df, x='total_bill', y='tip', hue='day')
```

**코드 해설**

- `sns`는 `seaborn`의 별칭이다. Seaborn은 표의 열 이름을 이용해 통계 그래프를 만들기 편하다.
- `barplot`은 기본적으로 각 요일의 `tip` 평균을 막대 높이로 사용한다. 여기서는 `errorbar=None`으로 오차 막대를 생략했다.
- 같은 모듈의 함수인 `scatterplot`은 결제 기록마다 점을 하나 그린다.
- `hue='day'`는 요일마다 점의 색을 달리한다. 팁과 결제 금액의 관계를 요일별로 비교할 수 있다.

## 6. 히트맵의 의미와 그래프 해석 순서

- Heatmap(히트맵)은 표의 각 값을 색의 진하기나 색상으로 나타낸다.
- 월별 승객 수처럼 행과 열로 비교할 값이 많을 때 전체 패턴을 찾기 좋다.
- 예를 들어 행이 월, 열이 연도라면 한 칸은 특정 연도의 특정 월에 해당한다.
- seaborn 모듈의 함수인 `heatmap`은 `sns.heatmap(table)`처럼 사용한다. `table`은 그릴 숫자를 행과 열로 배치한 표다.
- 상관계수 히트맵에서는 1에 가까울수록 두 값이 같은 방향으로 움직이는 선형 관계가 강하다. -1에 가까우면 반대 방향이다.
- 두 값이 함께 변하는 이유를 설명하려면 다른 조건도 살펴봐야 한다. 예를 들어 기온과 대여량이 함께 늘어도 요일과 계절의 영향이 함께 들어 있을 수 있다.

그래프를 읽을 때는 다음 순서로 확인한다.

1. 가로축과 세로축이 무엇을 뜻하는지 확인한다.
2. 값의 단위와 집계 방식이 개수·합계·평균 중 무엇인지 확인한다.
3. 값이 모인 구간, 집단별 차이, 큰 값과 작은 값을 찾는다.
4. 발견한 특징이 전처리와 모델 입력 선택에 어떤 영향을 주는지 생각한다.

## 7. 상자 그림과 밀도 곡선으로 분포 비교

- 평균만 보면 값들이 한곳에 모여 있는지, 넓게 퍼져 있는지 알기 어렵다.
- 예를 들어 `[4, 5, 5, 6]`과 `[0, 1, 9, 10]`의 평균은 모두 5다.
- 첫 집단은 5 근처에 모여 있고, 둘째 집단은 양 끝에 나뉘어 있다.
- 분포를 비교하면 집단의 차이를 찾고, 전처리에서 살펴볼 값을 고를 수 있다.

### 7-1) Box plot의 중앙값·사분위수·수염

- Box plot(상자 그림)은 데이터의 가운데 위치와 퍼진 범위를 요약한다.
- Median(중앙값)은 값을 순서대로 놓았을 때 가운데에 해당하는 값이다.
- Q1은 아래쪽 25%, Q3은 아래쪽 75%에 해당하는 위치의 값이다.
- 상자는 Q1부터 Q3까지다. 가운데 50%가 차지하는 범위를 보여 준다.
- 상자 안의 선은 중앙값이다. 상자 높이가 크면 가운데 값들이 더 넓게 퍼져 있다.
- IQR(사분위 범위)은 `Q3 - Q1`이다.
- Seaborn의 기본 수염은 `Q1 - 1.5 × IQR`부터 `Q3 + 1.5 × IQR` 안에 있는 실제 값의 끝까지 이어진다.
- 수염 밖의 점은 다른 값들과 떨어진 관측값이다. 입력 오류인지 드문 실제 사례인지 원자료에서 확인한다.

### 7-2) KDE와 Violin plot의 밀도 표현

- KDE(커널 밀도 추정)는 관측값마다 작은 곡선을 놓고 합쳐, 값이 모인 정도를 부드러운 곡선으로 나타낸다.
- 곡선이 높은 구간일수록 그 주변에 값이 많이 모여 있다고 추정한다.
- 가로축은 관측값, 세로축은 밀도다. 구간 아래의 면적으로 그 구간에 속할 비율을 읽는다.
- Bandwidth(대역폭)는 곡선을 얼마나 부드럽게 만들지 조절한다. 작으면 세부 굴곡이 많고, 크면 넓게 이어진다.
- Violin plot(바이올린 그림)은 밀도 곡선을 좌우로 붙여 집단별 분포를 표현한다.
- 한 집단 안에서 폭이 넓은 구간은 추정 밀도가 높다. 여러 봉우리가 있으면 값이 모인 구간도 여러 곳이다.

![[02-머신러닝과-딥러닝-기초/assets/분포-그림-비교.png|620]]

- 위 그림의 두 집단은 평균이 같다. A는 가운데에 모이고 B는 두 구간으로 나뉜다.
- 상자 그림에서는 중앙값과 범위를, 바이올린 그림과 밀도 곡선에서는 값이 모인 구간을 비교한다.

### 7-3) seaborn 모듈의 boxplot·violinplot·kdeplot 함수

- 같은 데이터도 중앙값·사분위수로 요약하거나 값이 모이는 구간을 밀도로 표현할 수 있다. 아래에서는 같은 값들을 세 가지 그림으로 나란히 비교한다.

**코드 예시**

```python
import matplotlib.pyplot as plt
import seaborn as sns

values = [1, 2, 2, 3, 7, 8, 8, 9]
fig, axes = plt.subplots(3, 1, figsize=(6, 8))
sns.boxplot(x=values, ax=axes[0])
sns.violinplot(x=values, cut=0, ax=axes[1])
sns.kdeplot(x=values, cut=0, ax=axes[2])
fig.tight_layout()
```

**코드 해설**

- `subplots(3, 1)`이 세로로 세 영역을 만든다. `boxplot`, `violinplot`, `kdeplot`이 각 영역에 상자 그림·바이올린 그림·밀도 곡선을 그리고, 마지막 줄이 간격을 정리한다.

- 세 함수에 같은 `values`를 전달해 표현 방식의 차이를 본다.
- `ax`는 그래프를 그릴 영역이다. `axes[0]`부터 `axes[2]`까지 위에서 아래로 사용한다.
- `cut=0`은 밀도 그림의 표시 범위를 관측값의 최솟값과 최댓값 사이로 제한한다.
- Figure 객체의 `tight_layout()` 메서드는 제목과 축이 겹치지 않도록 그래프 사이 간격을 조절한다.
