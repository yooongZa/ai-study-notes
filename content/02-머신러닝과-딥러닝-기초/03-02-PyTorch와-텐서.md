## 1. PyTorch와 텐서를 배우는 이유

- 신경망은 많은 숫자를 한꺼번에 계산하고, 각 가중치가 손실에 미친 영향을 구해야 한다.
- 이를 직접 구현하면 숫자 배열의 형태와 미분 계산을 모두 관리해야 한다.
- PyTorch는 **텐서 계산, 자동 미분, 신경망 구성, 가중치 갱신**을 연결하는 도구다.
- 입력의 형태와 학습의 각 단계를 이해하면 모델 코드가 어떤 계산을 하는지 읽을 수 있다.

---

## 2. 텐서의 축·형태·자료형·장치

- Tensor(텐서)는 숫자를 여러 축으로 배치한 자료구조다.
- 숫자 하나는 Scalar(스칼라), 숫자 한 줄은 Vector(벡터), 행과 열이 있는 표는 Matrix(행렬)로 표현할 수 있다.
- 이미지를 여러 장 묶으면 더 많은 축이 필요하다.
- `(32, 3, 28, 28)`은 이미지 32장, 색상 채널 3개, 높이 28, 너비 28로 해석할 수 있다.
- Shape(형태)는 각 축의 길이다. 축마다 무엇을 뜻하는지 함께 알아야 계산을 이해할 수 있다.

### torch 모듈의 tensor 함수의 활용

- 텐서는 여러 값을 축으로 묶어 한 번에 계산하기 위한 자료 구조다. 어떤 축이 데이터와 특성을 나타내는지 알아야 이후 연산과 모델 입력을 맞출 수 있다.

**코드 예시**

```python
import torch

x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
```

**코드 해설**

- `x.shape`는 `(2, 2)`다. 행 2개, 열 2개인 텐서다.
- `x.dtype`은 숫자의 자료형, `x.device`는 저장된 계산 장치를 나타내는 속성이다.
- 실수 계산에는 보통 `torch.float32`, 클래스 번호에는 `torch.int64` 또는 같은 자료형인 `torch.long`을 사용한다.
- `torch.zeros(2, 3)`은 0으로 채운 `(2, 3)` 텐서를 만든다. `zeros`는 `torch` 모듈의 함수다.
- 같은 모듈의 함수인 `arange(6)`은 0부터 5까지 정수 6개를 만든다.
- 같은 모듈의 함수인 `manual_seed(0)`은 난수 생성의 시드를 정한다. 작은 예제를 반복해서 비교할 때 사용한다.

## 3. 텐서의 인덱싱과 기본 연산

- 같은 텐서에서도 행·열 선택, 원소별 계산, 행렬 곱은 쓰임이 다르다. 아래에서는 앞의 2×2 텐서에서 일부 값을 고르거나 계산하는 방법을 비교한다.

**코드 예시**

```python
x[0]
x[:, 1]
x * 2
x @ x
```

**코드 해설**

- `x[0]`은 첫 행 `[1, 2]`를 선택하는 인덱싱 문법이다. 인덱스는 0부터 시작한다.
- `:`는 해당 축 전체를 뜻한다. `x[:, 1]`은 모든 행의 둘째 열 `[2, 4]`를 선택한다.
- `x * 2`는 모든 원소에 2를 곱한다. `x * x`라면 같은 위치의 값끼리 곱한다.
- `@`는 행렬 곱이다. 앞 행렬의 열 수와 뒤 행렬의 행 수가 맞아야 한다.
- `Tensor` 객체의 메서드인 `mean(dim=0)`은 행 방향으로 평균을 내서 열마다 평균 하나를 남긴다. `x.mean(dim=0)`은 `[2, 3]`이다.
- `dim`은 계산으로 묶을 축의 번호다. `x.mean(dim=1)`은 각 행의 평균 `[1.5, 3.5]`다.

## 4. reshape·permute와 텐서 결합

### torch Tensor의 reshape 메서드의 활용

- 형태를 바꾸는 일과 축의 의미를 바꾸는 일을 구분해야 한다. 원소의 묶음 크기를 바꿀 때는 reshape, 행·열처럼 축의 위치를 바꿀 때는 permute를 사용한다.

**코드 예시**

```python
t = torch.tensor([[1, 2, 3], [4, 5, 6]])
reshaped = t.reshape(3, 2)
transposed = t.permute(1, 0)
```

**코드 해설**

- `reshape(3, 2)`의 결과는 `[[1, 2], [3, 4], [5, 6]]`이다. 원소를 읽는 순서를 유지하며 묶는 크기를 바꾼다.
- 전체 원소 수는 6개로 같아야 한다. `reshape(3, -1)`이라고 적으면 나머지 크기 2를 자동 계산한다.
- `Tensor`의 메서드인 `view`도 형태를 바꾸지만 메모리 배치가 새 형태와 맞아야 한다. `reshape`는 필요하면 복사해서 새 형태를 만든다.
- `Tensor`의 메서드인 `permute(1, 0)`은 두 축의 순서를 바꾼다. 결과는 `[[1, 4], [2, 5], [3, 6]]`이다.
- 이미지의 `(채널, 높이, 너비)`를 `(높이, 너비, 채널)`로 바꾸려면 `permute(1, 2, 0)`을 사용한다. 각 축이 뜻하는 정보의 위치를 바꾸는 작업이다.

### torch 모듈의 cat·stack 함수와 텐서 결합

- `torch.cat([a, b], dim=0)`은 기존 0번 축을 따라 이어 붙인다. `(2, 3)` 두 개를 합치면 `(4, 3)`이 된다.
- `torch.stack([a, b], dim=0)`은 새로운 축을 만든다. `(2, 3)` 두 개를 쌓으면 `(2, 2, 3)`이 된다.
- 여러 샘플을 하나의 배치로 묶을 때는 샘플을 구분하는 축이 추가된다.

## 5. 브로드캐스팅과 자료형·장치 맞추기

- Broadcasting(브로드캐스팅)은 크기가 1인 축을 다른 텐서에 맞춰 적용해 계산하는 규칙이다.
- `(2, 3)` 텐서와 `(3,)` 텐서를 더하면 길이 3인 값이 각 행에 적용된다.
- 뒤쪽 축부터 비교해서 크기가 같거나 한쪽이 1이면 대응할 수 있다. 없는 앞쪽 축은 크기 1로 본다.

- 각 데이터에 같은 편향 벡터를 더하려면 그 벡터를 모든 행에 적용해야 한다. 브로드캐스팅은 이 반복 적용을 텐서의 형태에 맞춰 처리한다.

**코드 예시**

```python
a = torch.tensor([[1, 2, 3], [4, 5, 6]])
b = torch.tensor([10, 20, 30])
result = a + b
```

**코드 해설**

- `a`의 두 행에 `b`의 세 값이 각각 더해진다. `result = a + b`의 출력 형태는 입력 `a`와 같은 `(2, 3)`이다.

- 결과는 `[[11, 22, 33], [14, 25, 36]]`이다.
- 선형 레이어에서 모든 샘플에 같은 편향을 더할 때 이 규칙이 쓰인다.
- 입력을 계산하기 전에는 형태뿐 아니라 자료형과 장치도 맞춘다.
- `Tensor`의 메서드인 `to`는 `x = x.to(dtype=torch.float32, device='cpu')`처럼 자료형·장치를 지정한다. 반환된 텐서를 변수에 받는다.
- `torch.from_numpy(array)`는 NumPy 배열에서 텐서를 만들며 지원되는 배열과 메모리를 공유한다. 원본과 독립된 값을 원하면 텐서의 `clone()` 메서드로 복사한다.

## 6. 자동 미분과 backward 메서드

- Autograd(자동 미분)는 실행한 텐서 연산을 기록하고 연쇄 법칙으로 미분값을 계산한다.
- Calculation graph(계산 그래프)는 값들이 어떤 연산으로 연결됐는지 나타내는 구조다.
- 신경망에서는 손실부터 연산을 거슬러 올라가며 각 가중치가 손실에 미친 영향을 구한다. 이를 Backpropagation(역전파)라고 한다.

### torch Tensor의 backward 메서드의 활용

- 가중치를 바꿀 방향을 찾으려면 손실이 그 값에 따라 어떻게 변하는지 알아야 한다. 자동 미분은 순방향 계산을 기록하고 결과에서 입력 쪽으로 기울기를 계산한다.

**코드 예시**

```python
x = torch.tensor(3.0, requires_grad=True)
y = x ** 2
y.backward()
```

**코드 해설**

- `requires_grad=True`는 `x`에 대한 기울기를 구할 수 있도록 연산을 기록하겠다는 뜻이다.
- `y=x²`의 미분은 `2x`이므로 `x.grad`에 6이 저장된다.
- `grad`는 미분값을 담는 속성이다.
- 신경망에서는 `loss.backward()`를 호출해 모델 매개변수의 기울기를 구한다.
- 미분값은 기본적으로 기존 `grad`에 누적된다. 새 배치의 기울기만 사용하려면 이전 값을 초기화한다.
- [[02-머신러닝과-딥러닝-기초/03-02-보충-02-미분과-역전파|미분과 연쇄 법칙으로 역전파 이해하기]]에서 계산 과정을 이어서 볼 수 있다.

## 7. nn.Module과 레이어를 이용한 모델 구성

- Layer(레이어)는 입력 텐서를 받아 정해진 계산을 수행하고 출력 텐서를 반환하는 구성 요소다.
- `torch.nn` 모듈은 레이어와 손실 함수를 만드는 클래스를 제공한다.

### torch.nn 모듈의 Linear 클래스의 활용

- 신경망은 가중합으로 정보를 바꾸고 활성화 함수로 비선형 관계를 표현한다. 아래 모델은 입력 특성 3개를 중간 특성 4개로 바꾼 뒤 클래스 점수 2개를 계산한다.

**코드 예시**

```python
from torch import nn

model = nn.Sequential(
    nn.Linear(3, 4),
    nn.ReLU(),
    nn.Linear(4, 2),
)
```

**코드 해설**

- `Linear(3, 4)`는 샘플마다 입력 3개를 출력 4개로 바꾼다. 가중치와 편향은 학습할 값이다.
- `ReLU`는 같은 모듈의 활성화 함수 클래스다. 음수는 0, 양수는 그대로 반환한다.
- Activation function(활성화 함수)은 비선형 변환을 넣어 복잡한 관계를 표현하도록 한다.
- 선형 변환만 연달아 적용하면 전체 계산도 하나의 선형 변환으로 합쳐진다. 중간에 비선형 변환을 넣어 표현할 수 있는 관계를 늘린다.
- [[02-머신러닝과-딥러닝-기초/03-02-보충-01-행렬과-선형변환|행렬 곱으로 입력을 바꾸는 원리]]에서 계산 과정을 이어서 볼 수 있다.
- `Sequential`은 같은 모듈의 클래스로, 전달한 레이어를 순서대로 실행하는 모델을 만든다.
- 입력이 `(배치 크기, 3)`이면 출력은 `(배치 크기, 2)`다.

### torch.nn 모듈의 Module 클래스의 활용

- 직접 만든 모델에서는 사용할 레이어와 실제 계산 순서를 나누어 정의한다. 레이어를 모델에 등록하면 학습·저장·장치 이동에서 같은 매개변수를 관리할 수 있다.

**코드 예시**

```python
class SmallModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.layer = nn.Linear(3, 2)

    def forward(self, x):
        return self.layer(x)
```

**코드 해설**

- `SmallModel`은 직접 정의한 클래스이고, `SmallModel()`을 호출하면 모델 객체가 만들어진다. `self.layer`는 그 모델이 계속 사용할 레이어를 저장하는 속성이다.
- `model(x)`를 호출하면 입력 `x`가 `forward()`로 전달되고, `self.layer(x)`의 결과가 밖으로 반환된다.

- `class SmallModel(nn.Module)`은 `nn.Module`의 기능을 물려받는 Python 클래스 선언이다.
- `__init__()`에서 사용할 선형층을 준비하고, `forward()`에서 입력을 그 층에 통과시키는 계산을 정의한다.
- `super().__init__()`은 상위 클래스의 초기화를 실행한다. PyTorch가 레이어와 매개변수를 관리할 준비를 한다.
- `forward`는 입력이 들어왔을 때의 계산 순서를 적는 메서드다.
- `model = SmallModel()`로 만든 뒤 `model(x)`처럼 호출하면 PyTorch가 `forward`를 포함한 모델 실행 절차를 처리한다.

## 8. 로짓·정답·손실 함수의 관계

- 회귀에서는 연속된 수치를 출력한다. `torch.nn.MSELoss` 클래스는 예측과 정답의 평균제곱오차를 계산하는 객체를 만든다.
- 다중 클래스 분류에서는 클래스별 Logit(로짓)을 출력한다. 로짓은 확률로 바꾸기 전의 점수다.
- `torch.nn.CrossEntropyLoss` 클래스는 로짓과 정답 클래스 번호로 교차 엔트로피 손실을 계산한다.

- 교차 엔트로피는 각 샘플의 클래스 점수에서 정답 클래스에 얼마나 높은 점수를 줬는지 계산한다. 점수 배열과 정답 번호의 샘플 순서가 일치해야 한다.

**코드 예시**

```python
logits = torch.tensor([[2.0, 0.5, 0.1], [0.1, 0.2, 3.0]])
target = torch.tensor([0, 2], dtype=torch.long)
loss_fn = nn.CrossEntropyLoss()
loss = loss_fn(logits, target)
```

**코드 해설**

- `loss_fn`이 손실 계산 객체를 만든다. `loss_fn(logits, target)`은 두 행의 점수와 정답 0·2를 대응시켜 기본 설정에서 평균 손실 하나를 반환한다.

- 입력 점수의 형태는 `(샘플 2개, 클래스 3개)`다.
- `target`은 `(2,)`이며 첫 샘플의 정답 클래스는 0, 둘째는 2다.
- `CrossEntropyLoss`에는 확률 변환 전의 로짓을 전달한다. 클래스 점수를 손실로 계산하는 데 필요한 확률 관련 연산을 내부에서 처리한다.
- `Tensor`의 메서드인 `argmax(dim=1)`은 각 행에서 가장 큰 값의 위치를 고른다. `logits.argmax(dim=1)`의 결과는 `[0, 2]`다.

## 9. Dataset·DataLoader와 배치 구성

- Batch(배치)는 한 번의 계산에 함께 넣는 데이터 묶음이다.
- 많은 자료를 한 번에 장치에 올리면 메모리가 부족할 수 있으므로 작은 배치로 나눠 계산한다.
- `torch.utils.data` 모듈의 클래스인 `Dataset`은 데이터 한 건을 어떻게 가져올지 표현하는 기본 구조다.
- 직접 만드는 Dataset에서는 `__len__`으로 데이터 수를, `__getitem__`으로 한 건의 입력과 정답을 제공한다.
- 같은 모듈의 클래스인 `DataLoader`는 Dataset에서 데이터를 가져와 배치로 묶는다.

- 배치 학습은 작은 데이터 묶음마다 예측·손실·갱신을 반복한다. 데이터를 가져오는 방법과 한 번에 묶을 개수를 분리하면 입력 공급을 일정하게 유지할 수 있다.

**코드 예시**

```python
from torch.utils.data import DataLoader

loader = DataLoader(dataset, batch_size=32, shuffle=True)
```

**코드 해설**

- `dataset`은 입력과 정답을 한 건씩 제공하는 객체라고 가정한다.
- `batch_size=32`는 한 번에 최대 32개를 묶는다는 뜻이다. 남은 데이터가 적으면 마지막 배치는 더 작을 수 있다.
- `shuffle=True`는 학습용 데이터를 읽는 순서를 섞는다.
- 이미지 한 장이 `(1, 28, 28)`이면 배치는 `(32, 1, 28, 28)`이 된다.
- Epoch(에폭)는 학습 자료 전체를 한 번 처리한 단위다. 배치가 여러 개이면 한 에폭 안에서 매개변수를 여러 번 갱신한다.

## 10. 손실 계산부터 가중치 갱신까지의 흐름

### torch.optim 모듈의 SGD 클래스의 활용

- 옵티마이저는 갱신할 가중치와 갱신 규칙을 관리한다. 먼저 모델의 학습 매개변수와 학습률을 전달해 준비한다.

**코드 예시**

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
```

**코드 해설**

- 모델의 메서드인 `parameters()`는 학습할 매개변수를 전달한다.
- `SGD` 객체는 이 매개변수들을 관리하며, 기본 설정에서는 기울기의 반대 방향으로 값을 갱신한다.
- `lr`은 학습률이다. 같은 모듈의 `Adam` 클래스는 기울기의 이동 평균과 크기를 이용해 매개변수별 갱신 폭을 조정한다.
- [[02-머신러닝과-딥러닝-기초/03-02-보충-03-옵티마이저와-학습률|옵티마이저와 학습률이 가중치를 바꾸는 방법]]에서 계산 과정을 이어서 볼 수 있다.

**다음 예시의 원리**

- 한 배치를 학습할 때는 같은 가중치로 예측과 기울기를 계산한 뒤 값을 갱신한다. 이전 배치의 기울기를 정리하는 단계까지 포함해야 이번 계산이 의도대로 반영된다.

**코드 예시**

```python
optimizer.zero_grad()
pred = model(x_batch)
loss = loss_fn(pred, y_batch)
loss.backward()
optimizer.step()
```

**코드 해설**

- 다섯 줄은 **이전 계산 정리 → 이번 입력 예측 → 틀린 정도 계산 → 수정 방향 계산 → 가중치 변경**이다. 다음 배치에서는 변경된 가중치로 다시 예측한다.
- `optimizer`와 `loss`는 서로 다른 객체다. `loss.backward()`가 기울기를 채우면 `optimizer.step()`이 모델 매개변수에서 그 기울기를 읽어 갱신한다.

1. 옵티마이저 객체의 메서드인 `zero_grad`는 이전 기울기를 초기화한다.
2. `model(x_batch)`는 현재 가중치로 배치의 예측값을 계산한다.
3. `loss_fn` 객체는 예측값과 정답을 비교해 손실을 계산한다.
4. 손실 텐서의 메서드인 `backward`는 매개변수별 기울기를 계산한다.
5. 옵티마이저 객체의 메서드인 `step`은 그 기울기를 사용해 매개변수를 갱신한다.

- `x_batch`, `y_batch`, `model`, `loss_fn`은 앞에서 정한 문제에 맞는 형태여야 한다.
- `backward`까지는 기울기를 계산하는 단계다. 실제 매개변수 갱신은 `step`에서 일어난다.
- 텐서의 메서드인 `item()`은 원소가 하나인 텐서에서 Python 숫자를 꺼낸다. 손실값을 기록할 때 `loss.item()`을 사용한다.

## 11. train·eval 모드와 미분 기록 설정

- 평가에서는 학습용 무작위 처리와 통계 갱신을 평가 방식으로 바꾸고, 가중치 수정에 필요한 미분 기록도 생략한다. 두 설정의 역할을 나누어 적용한다.

**코드 예시**

```python
model.eval()
with torch.no_grad():
    prediction = model(x_batch)
```

**코드 해설**

- `model.eval()`이 레이어의 평가 동작을 선택한다. 이어지는 `no_grad()` 구간에서 `model(x_batch)`를 호출해 현재 가중치의 예측값을 얻는다.

- `nn.Module` 객체의 메서드인 `train()`은 Dropout과 BatchNorm 등의 레이어를 학습 방식으로 동작시킨다.
- 같은 객체의 메서드인 `eval()`은 해당 레이어를 평가 방식으로 동작시킨다.
- `torch.no_grad()`는 블록 안에서 기울기 계산용 기록을 끄는 컨텍스트 관리자다.
- `eval()`은 레이어의 동작 방식을 바꾸고, `no_grad()`는 미분 기록을 관리한다. 평가할 때 함께 사용하는 이유는 두 역할이 다르기 때문이다.
- 학습을 재개할 때는 `model.train()`으로 돌린다.

## 12. 모델 구조와 state_dict의 역할

- 모델 구조는 어떤 레이어를 어떤 순서로 연결했는지다.
- 학습한 값은 각 레이어의 가중치·편향과 필요한 상태값이다.
- 모델의 메서드인 `state_dict()`는 이런 값들을 이름과 텐서로 묶은 사전 형태로 반환한다.
- 같은 모델 구조를 준비한 뒤 `load_state_dict(state)` 메서드로 저장한 상태값을 채운다.
- `torch` 모듈의 함수인 `save`와 `load`는 이런 값을 파일에 저장하고 읽을 때 사용한다.
- 구조와 학습한 값을 구분하면, 똑같은 구조라도 가중치가 다르면 예측이 달라지는 이유를 이해할 수 있다.

## 13. 텐서 준비부터 예측 평가까지의 흐름

1. 입력을 텐서로 만들고 형태·자료형·장치를 맞춘다.
2. DataLoader가 데이터를 배치로 묶는다.
3. 모델의 레이어들이 배치에서 예측값을 계산한다.
4. 손실 함수가 예측과 정답의 차이를 구한다.
5. 자동 미분이 매개변수별 기울기를 계산한다.
6. 옵티마이저가 매개변수를 갱신한다.
7. 학습에 쓰지 않은 자료를 평가 모드에서 예측해 성능을 확인한다.
