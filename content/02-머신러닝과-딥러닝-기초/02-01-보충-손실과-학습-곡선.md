## 1. 손실과 정확도를 함께 배우는 이유

- 학습 결과에는 손실과 정확도가 함께 표시되는 경우가 많다.
- 두 값은 서로 다른 내용을 보여 준다. 그래서 한쪽만 좋아지는 상황도 생긴다.
- Loss(손실)는 예측값과 정답의 차이를 나타내며, 학습은 이 값을 줄이는 방향으로 진행한다.
- Accuracy(정확도)는 전체 데이터 중 정답을 맞힌 비율이다.
- 두 값을 함께 이해하면 **학습 자료를 얼마나 잘 맞추는지, 새 자료에서도 예측이 좋아지는지** 구분해 읽을 수 있다.

## 2. 정답 여부와 정답 확률의 차이

- 두 클래스 중 하나를 고르는 분류 문제라고 하자.
- 정답 클래스의 확률이 0.5보다 크면 맞혔다고 판단한다.
- 정답에 준 확률이 0.51이든 0.99든, 정확도에서는 둘 다 정답 한 건이다.
- Cross-entropy(교차 엔트로피)는 정답 클래스에 준 확률 `p`로 손실을 계산한다.

$$L=-\log p$$

- `log`는 여기서 자연로그다.
- 정답에 준 확률이 높을수록 손실이 작다.
- 정답 확률이 0에 가까우면 손실이 커진다.

| 정답 클래스 확률 | 한 데이터의 손실 |
| --- | --- |
| 0.9 | 약 0.105 |
| 0.5 | 약 0.693 |
| 0.1 | 약 2.303 |

### Python math 모듈의 log 함수 활용

- 교차 엔트로피는 정답에 준 확률이 낮을수록 큰 손실을 부여한다. 정답 확률에 음의 로그를 적용하면 확신한 오답을 강하게 반영할 수 있다.

**코드 예시**

```python
import math

p = 0.9
loss = -math.log(p)
print(round(loss, 3))  # 0.105
```

**코드 해설**

- 정답에 준 확률이 0.9이면 손실은 약 0.105다. 같은 식에 0.1을 넣으면 약 2.303이 된다. 정답에 낮은 확률을 줄수록 더 큰 손실을 받는 구조다.

- `p`는 정답 클래스에 준 확률이다.
- `math.log(p)` 앞에 마이너스를 붙여 손실로 계산한다.

### 2-1) 가중치 학습에 손실 함수를 사용하는 이유

- 모델을 학습하려면 가중치를 조금 바꿨을 때 예측이 얼마나 좋아지는지 알아야 한다.
- 정답 확률이 `0.6 → 0.7 → 0.8`로 높아져도 세 경우 모두 정답이다. 정확도는 그대로다.
- 교차 엔트로피는 같은 변화에서 약 `0.511 → 0.357 → 0.223`으로 줄어든다.
- 이 변화의 기울기를 구하면, 가중치를 어느 방향으로 바꿀 때 손실이 줄어드는지 알 수 있다.
- 역전파는 그 기울기를 각 가중치까지 계산하고, 옵티마이저는 기울기를 사용해 가중치를 갱신한다.
- **정답 확률 → 손실 → 가중치에 대한 기울기 → 가중치 갱신**이 학습의 연결 순서다.
- 정확도와 F1은 예측한 클래스로 성능을 평가할 때 사용한다. 교차 엔트로피는 예측 확률의 변화를 학습에 반영한다.

## 3. 정확도 상승과 손실 증가가 함께 나타나는 경우

- 같은 데이터 네 건을 두 모델이 예측했다고 하자.
- 아래 숫자는 각 데이터의 **정답 클래스에 준 확률**이다.

### 모델 A의 결과

- 확률: `[0.90, 0.49, 0.49, 0.49]`.
- 첫 데이터만 맞혔으므로 정확도는 `1/4=25%`다.
- 네 데이터의 교차 엔트로피를 평균하면 약 0.561이다.

### 모델 B의 결과

- 확률: `[0.51, 0.51, 0.51, 0.001]`.
- 세 데이터를 맞혔으므로 정확도는 `3/4=75%`다.
- 네 데이터의 손실을 평균하면 약 2.232다.
- 마지막 데이터의 정답 확률 0.001은 손실 약 6.908을 만든다. 이 큰 값이 평균 손실을 높인다.

- 모델 B는 맞힌 개수가 늘었지만, 마지막 오답에서 정답 확률을 매우 낮게 줬다.
- 정확도는 맞힌 개수를 보여 주고, 손실은 이런 확률 차이까지 반영한다.
- 정답 확률이 0.30에서 0.45로 오르면 아직 오답이어도 손실은 줄어든다.

## 4. 에포크별 학습 곡선의 의미

- Learning curve(학습 곡선)는 학습이 진행되면서 손실이나 지표가 어떻게 바뀌는지 그린 것이다.
- 가로축은 Epoch(에포크)다. 전체 학습 데이터를 한 번 사용하면 1에포크다.
- 세로축은 손실이나 정확도다. 손실은 낮을수록, 정확도는 높을수록 좋다.
- Training loss(학습 손실)는 학습 자료의 예측 오차다.
- Validation loss(검증 손실)는 가중치 학습에 사용하지 않은 검증 자료의 예측 오차다.
- 같은 지표의 학습·검증 값을 함께 보면 두 집단에서의 변화 방향을 비교할 수 있다.

- 파란색은 학습 손실, 주황색은 검증 손실이다.

## 5. 학습 손실과 검증 손실의 변화 해석

### 학습·검증 손실이 함께 감소하는 경우

- 학습 자료와 검증 자료 모두에서 예측 오차가 줄어들고 있다.
- 이후에도 검증 성능이 좋아지는지 살펴본다.
- 모델을 저장할 때는 선택 기준으로 정한 검증 지표가 가장 좋은 시점을 보관한다.

### 학습 손실 감소와 검증 손실 증가가 함께 나타나는 경우

- 학습 자료의 오차는 줄어도 새 자료의 오차는 커지는 상태다.
- 이런 변화는 Overfitting(과적합)을 살펴볼 신호다.
- 학습을 더 오래 하면 학습 자료에만 맞춘 세부 규칙이 늘어날 수 있다.
- 검증 성능이 좋았던 시점의 가중치, 규제 강도, 모델 크기를 비교한다.

### 학습·검증 손실이 높은 상태로 유지되는 경우

- 학습 자료에서도 예측 오차를 충분히 줄이지 못하고 있다.
- 입력에 필요한 정보가 있는지, 학습률이 너무 작은지, 모델이 관계를 표현할 수 있는지 살펴본다.
- Underfitting(과소적합)은 모델이 데이터의 관계를 충분히 학습하지 못한 상태다.
- 손실의 높고 낮음은 같은 문제와 같은 손실 함수를 쓴 기준 모델에 비추어 판단한다.

## 6. EarlyStopping과 학습 종료 시점

- 검증 손실이 좋아지지 않는데도 계속 학습하면 계산 시간이 늘고 과적합이 커질 수 있다.
- Early stopping(조기 종료)은 정해 둔 검증 지표의 개선이 멈추면 학습을 끝내는 방법이다.
- 한 번의 작은 변화에 바로 반응하지 않도록 몇 차례 기다릴 수 있다.

| 설정 | 뜻 |
| --- | --- |
| `monitor` | 개선 여부를 볼 지표 |
| `patience` | 개선 없이 기다릴 평가 횟수 |
| `min_delta` | 개선으로 인정할 최소 변화량 |
| `restore_best_weights` | 가장 좋은 시점의 가중치를 복원할지 여부 |

- 예를 들어 검증 손실이 `0.60 → 0.50 → 0.40 → 0.41 → 0.43`이었다고 하자.
- 매 에포크 평가하고 `patience=2`, `min_delta=0`이면, 0.40 이후 두 번 개선되지 않아 학습을 멈춘다.
- 가장 작은 검증 손실 0.40을 만든 가중치를 선택할 수 있다.
- 비교 기준을 최종 테스트 자료와 분리하려고, 멈출 시점은 검증 자료로 정한다.

### keras.callbacks 모듈의 EarlyStopping 클래스의 활용

- 학습을 더 해도 검증 성능이 좋아지지 않으면 종료 시점을 정해야 한다. 조기 종료는 검증 지표의 개선 여부를 여러 에포크에 걸쳐 확인하고 좋은 시점의 가중치를 선택한다.

**코드 예시**

```python
from keras.callbacks import EarlyStopping

stop = EarlyStopping(
    monitor="val_loss",
    mode="min",
    patience=2,
    min_delta=0.0,
    restore_best_weights=True,
)
```

**코드 해설**

- `EarlyStopping(...)`은 종료 조건을 기억할 객체를 만든다. 학습 중 에포크 하나가 끝날 때마다 이 객체가 `val_loss`를 확인한다.
- 최저 검증 손실을 갱신하면 기다린 횟수를 초기화한다. 개선 없이 2에포크가 지나면 학습을 멈추고 가장 좋았던 가중치를 복원한다.

- `mode="min"`은 지표가 작아질 때 개선으로 판단한다.
- `restore_best_weights=True`는 선택한 지표가 가장 좋았던 시점의 가중치를 복원한다.
- `stop`은 조건을 담은 Callback(콜백) 객체다.
- Keras 모델의 `fit(..., callbacks=[stop])`에 전달하면 학습 중 이 조건을 확인한다.
- PyTorch로 학습 반복문을 직접 작성할 때도 검증 지표, 기다린 횟수, 좋은 시점의 가중치를 같은 원리로 관리한다.

## 7. 학습 결과를 해석하는 순서

1. 손실 함수와 평가 지표가 무엇을 계산하는지 확인한다.
2. 학습 자료와 검증 자료 각각에서 값이 어떻게 변하는지 본다.
3. 정확도와 손실이 다르게 움직이면 정답 클래스의 확률도 살펴본다.
4. 정해 둔 검증 지표로 모델과 학습 종료 시점을 고른다.
5. 선택한 모델을 테스트 자료에서 최종 평가한다.

- Dropout을 켠 학습과 끈 평가는 계산 조건이 다르다.
- 학습·검증 손실을 비교할 때는 이런 모드 차이와 규제 비용의 포함 여부를 함께 읽는다.
- 여러 모델을 비교할 때는 같은 검증 자료와 같은 지표를 사용한다.
