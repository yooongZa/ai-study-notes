## 1. 데이터 전처리가 필요한 이유

- 실제 표에는 비어 있는 값, 중복 기록, 문자로 적힌 범주, 단위가 다른 숫자가 섞여 있다.
- 이런 상태로 모델에 넣으면 계산이 멈추거나, 기록 오류와 숫자 크기에 학습이 크게 영향을 받을 수 있다.
- Preprocessing(전처리)은 **데이터의 의미를 확인하고 모델이 계산할 수 있는 형태로 정리하는 과정**이다.
- 예를 들어 대여 기록의 빈 기온, 중복 주문, 요일 문자열은 각각 다른 방식으로 처리한다.

## 2. 결측치의 의미와 채우기·제외 방법

- Missing value(결측치)는 값이 기록되지 않은 상태다. pandas에서는 `NaN`, `None`, `pd.NA` 등으로 표현된다.
- 판매량 0은 판매가 없었다는 관측값이다. 판매량이 비어 있으면 실제 판매량을 모른다는 뜻일 수 있다.
- 기록을 복원할 수 있으면 원래 값을 사용한다. 복원이 어려우면 행을 제외하거나 대표값으로 채운다.
- 평균은 전체 크기를 반영하고, 중앙값은 값을 정렬했을 때 가운데 있는 값이다. 극단적으로 큰 값이 섞인 수치에는 중앙값이 덜 흔들린다.
- 빈 값이 많으면 채운 값이 데이터의 큰 부분을 차지한다. 열별로 비어 있는 개수를 먼저 확인한다.

### pandas DataFrame의 isna 메서드의 활용

- 결측값을 채우거나 제외하기 전에 어느 열에 얼마나 빠져 있는지 확인한다. 각 칸의 결측 여부를 표시한 뒤 열별로 세면 처리 규모를 알 수 있다.

**코드 예시**

```python
missing_count = df.isna().sum()
```

**코드 해설**

- `df.isna()`는 pandas의 `DataFrame` 메서드다. 각 칸이 비어 있으면 `True`, 값이 있으면 `False`인 표를 만든다.
- 뒤의 `.sum()`은 이 표를 열별로 더한다. `True`가 1로 계산되므로 빈 칸의 수가 나온다.
- `missing_count`에는 열별 결측치 개수가 담긴다. 한 열의 세 값 중 두 개가 비어 있다면 그 열의 결과는 2다.

### pandas Series의 fillna 메서드의 활용

- 결측값의 대체 기준은 학습 자료에서 정하고 새 자료에도 그대로 적용한다. 중앙값으로 채우면 일부 큰 값이 대체값을 크게 바꾸는 영향을 줄일 수 있다.

**코드 예시**

```python
median_age = train['age'].median()
train_age = train['age'].fillna(median_age)
test_age = test['age'].fillna(median_age)
```

**코드 해설**

- `train['age'].median()`은 학습 자료의 나이 중앙값을 구한다. 나이가 `[20, 40, 빈 값]`이면 `median_age`는 30이다.
- `train['age'].fillna(median_age)`는 학습 자료의 빈 나이를 30으로 채운 새 `Series`를 반환한다. 그 결과가 `train_age`다.
- `test['age'].fillna(median_age)`도 **학습 자료에서 구한 30**을 사용한다. 평가 자료에 별도의 기준을 만들지 않고 같은 처리를 적용한다.
- `median()`과 `fillna()`는 pandas의 `Series` 메서드다. 원래 표의 열을 갱신하려면 반환된 결과를 해당 열에 저장한다.
- `DataFrame`의 메서드인 `dropna(subset=['age'])`는 나이가 비어 있는 행을 제외한 표를 반환한다.

## 3. 중복 기록과 이상치의 차이

- Duplicate(중복)는 같은 대상을 두 번 이상 기록한 경우다. 주문 번호가 같은 주문이 반복 저장된 경우가 여기에 해당한다.
- 서로 다른 두 사람이 같은 나이를 가진 것은 서로 다른 관측값이다. 중복을 판단할 열을 먼저 정한다.
- `DataFrame`의 메서드인 `duplicated(subset=['order_id'])`는 주문 번호 기준으로 중복된 행을 표시한다.
- 같은 객체의 메서드인 `drop_duplicates(subset=['order_id'], keep='last')`는 같은 주문 번호의 마지막 행을 남긴다.

- Outlier(이상치)는 다른 값들과 비교해 유난히 크거나 작은 값이다.
- 나이 300은 입력 오류를 의심할 수 있다. 판매량 300은 특별 행사로 실제 발생한 값일 수 있다.
- 오류라면 수정하거나 제외한다. 실제 드문 사건이라면 예측하려는 문제에서 그 사건이 중요한지 확인한다.

### 이상치를 찾는 두 가지 수치 기준

- Z-score(표준점수)는 평균에서 얼마나 떨어져 있는지를 표준편차 단위로 나타낸다.

$$z = \frac{x-\mu}{\sigma}$$

- `x`는 현재 값, `μ`는 평균, `σ`는 표준편차다. 표준편차는 값이 평균 주변에 퍼진 정도다.
- 평균 100, 표준편차 10일 때 130의 z값은 3이다. 평균보다 표준편차의 3배만큼 크다는 뜻이다.
- IQR(사분위 범위)은 정렬한 값의 가운데 50%가 차지하는 범위다. `IQR = Q3 - Q1`로 구한다.
- `Q1`은 아래쪽 25% 지점, `Q3`는 아래쪽 75% 지점의 값이다.
- 흔히 `Q1 - 1.5 × IQR`보다 작거나 `Q3 + 1.5 × IQR`보다 큰 값을 따로 살펴본다.
- 이 기준으로 찾은 행은 실제 오류인지 확인한 뒤 처리한다.

## 4. 표준화와 최소 최대 조정의 원리

- 나이는 0~100, 연봉은 수천만 단위로 기록될 수 있다.
- 거리 계산에서는 연봉의 숫자 차이가 훨씬 크게 반영된다. 경사하강법으로 학습할 때도 변수별 크기 차이가 최적화에 영향을 준다.
- Scaling(스케일 조정)은 각 열의 숫자 범위를 조정해 비교와 학습이 쉬워지게 한다.

| 방법 | 계산과 의미 |
| --- | --- |
| Standardization(표준화) | 평균을 빼고 표준편차로 나눈다. 학습 자료의 각 열을 평균 0, 표준편차 1에 맞춘다. |
| Min-max scaling(최소 최대 조정) | `(값 - 최솟값) / (최댓값 - 최솟값)`으로 바꾼다. 학습 자료의 최솟값을 0, 최댓값을 1에 맞춘다. |

- 표준화는 원래 분포의 모양을 유지하면서 평균과 퍼진 정도를 조정한다.
- 평가 자료에 학습 자료의 최댓값보다 큰 값이 있으면 최소 최대 조정 후 1보다 커질 수 있다. 학습 기준을 그대로 적용한 결과다.

### sklearn.preprocessing 모듈의 StandardScaler 클래스의 활용

- 표준화는 특성마다 평균을 빼고 표준편차로 나누어 크기를 맞추는 방법이다. 학습 자료에서 구한 기준을 보관해야 평가 자료도 같은 좌표 기준으로 변환할 수 있다.

**코드 예시**

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
train_scaled = scaler.fit_transform(X_train)
test_scaled = scaler.transform(X_test)
```

**코드 해설**

- `StandardScaler()`는 `sklearn.preprocessing`의 표준화 객체를 만든다. 이 객체가 학습 자료의 열별 평균과 표준편차를 보관한다.
- `scaler.fit_transform(X_train)`은 학습 자료에서 두 기준값을 구하고, 각 값에 `(값 - 평균) / 표준편차`를 적용한다. 학습 열이 `[10, 20, 30]`이면 먼저 평균 20을 뺀다.
- `scaler.transform(X_test)`는 저장된 학습 기준으로 평가 자료를 바꾼다. 평가 자료에서 평균과 표준편차를 다시 구하는 단계는 생략한다.
- 두 입력과 결과의 형태는 각각 `(데이터 수, 특성 수)`다. 행과 열의 대응은 유지하면서 숫자 크기를 바꾼다.
- `MinMaxScaler`도 같은 메서드 구조를 사용하며, 열별 최솟값과 최댓값을 기준으로 변환한다.

## 5. 범주형 데이터의 인코딩과 숫자 구간화

- 요일에 월=1, 화=2, 수=3을 붙이면 모델이 숫자의 크기 차이를 의미 있는 차이로 사용할 수 있다.
- One-hot encoding(원 핫 인코딩)은 범주마다 열을 만들고 해당 범주에만 1을 넣는다.
- 월요일은 `[1, 0, 0]`, 화요일은 `[0, 1, 0]`, 수요일은 `[0, 0, 1]`처럼 표현한다.

### pandas 모듈의 get_dummies 함수의 활용

- 요일처럼 순서나 크기가 없는 범주는 범주별 열에 포함 여부를 표시한다. 각 행의 의미를 유지하면서 모델이 계산할 수 있는 숫자로 표현하는 과정이다.

**코드 예시**

```python
import pandas as pd

days = pd.Series(['Mon', 'Tue', 'Mon'])
encoded = pd.get_dummies(days, dtype=int)
```

**코드 해설**

- `days`에 세 기록의 요일을 담고 `get_dummies()`에 전달한다. 반환된 표의 열은 `Mon`, `Tue`이고 행별 값은 `[1, 0]`, `[0, 1]`, `[1, 0]`이다.

- 학습용과 평가용을 변환한 뒤에는 같은 범주가 같은 열 위치에 있어야 한다.
- sklearn의 `OneHotEncoder` 객체는 학습 자료의 범주를 `fit`으로 저장하고, `transform`으로 같은 열 구조를 적용할 때 사용한다.

- Binning(구간화)은 연속된 숫자를 구간으로 나누는 방법이다.
- 나이를 정확한 숫자 대신 연령대별로 비교할 때 사용할 수 있다. 구간 안의 세부 차이는 하나로 묶인다.
- pandas 모듈의 함수인 `cut`은 지정한 경계로 구간을 만든다. `pd.cut(age, bins=[0, 20, 40, 100])`은 기본적으로 `(0, 20]`, `(20, 40]`, `(40, 100]`으로 나눈다.
- 같은 모듈의 함수인 `qcut`은 각 구간에 비슷한 수의 관측값이 들어가도록 분위수를 기준으로 나눈다.

## 6. 학습·평가 자료에 전처리를 적용하는 순서

1. 각 열의 의미, 자료형, 빈 값과 중복을 확인한다.
2. 예측할 정답과 입력에 사용할 열을 정한다.
3. 학습 자료와 평가 자료를 나눈다.
4. 학습 자료에서 대체값, 스케일, 범주 기준을 구한다.
5. 학습 자료와 평가 자료에 같은 기준을 적용한다.
6. 정리한 입력으로 모델을 학습하고 평가한다.

- Data leakage(데이터 누출)는 평가 자료의 정보나 예측 시점에 알 수 없는 정보가 학습에 들어가는 문제다.
- 평가 자료까지 포함해 평균을 구하면 실제 새 자료를 예측하는 상황보다 유리한 조건에서 학습하게 된다.
- 전처리 기준을 학습 자료에서 구하는 순서가 필요한 이유가 여기에 있다.

## 7. ColumnTransformer의 열별 전처리

- 나이와 국가가 같은 표에 있으면 열마다 필요한 처리가 다르다.
- 나이는 빈 값을 채우고 크기를 조정한다. 국가는 범주별 숫자 열로 바꾼다.
- `ColumnTransformer`는 지정한 열에 각각의 전처리를 적용하고, 결과를 옆으로 합친다.
- `Pipeline`은 같은 입력에 여러 처리를 순서대로 적용한다.
- 둘을 함께 사용하면 **열 선택 → 열에 맞는 처리 → 결과 결합**의 흐름을 한 객체에 담을 수 있다.

### 7-1) 숫자 열을 처리하는 객체 구성

- 표준화에 사용할 통계를 계산하려면 먼저 빈 값을 처리해야 한다. 결측값 보완과 표준화를 순서대로 묶으면 매번 같은 전처리 흐름을 적용할 수 있다.

**코드 예시**

```python
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

numeric = Pipeline([
    ("fill", SimpleImputer(strategy="median")),
    ("scale", StandardScaler()),
])
```

**코드 해설**

- `SimpleImputer`는 `sklearn.impute` 모듈의 클래스다. 학습 자료에서 대체값을 구해 결측값을 채운다.
- `strategy="median"`은 각 열의 중앙값을 대체값으로 사용한다.
- `Pipeline`은 `sklearn.pipeline` 모듈의 클래스다. 위에서는 빈 값을 채운 결과를 `StandardScaler`에 넘긴다.
- `"fill"`과 `"scale"`은 각 단계에 붙인 이름이다. `numeric`은 두 단계를 묶은 객체를 가리키는 변수다.

### 7-2) 숫자 열과 범주 열의 처리 결과 결합

- 숫자 열과 범주 열은 알맞은 변환 방식이 다르다. 열마다 처리 방법을 지정한 뒤 결과를 옆으로 합치면 모델에 넣을 하나의 입력 배열이 된다.

**코드 예시**

```python
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder

train = pd.DataFrame({
    "age": [20, 40, None],
    "country": ["KR", "JP", "KR"],
})
category = OneHotEncoder(
    handle_unknown="ignore", sparse_output=False,
)
prepare = ColumnTransformer([
    ("number", numeric, ["age"]),
    ("category", category, ["country"]),
])
ready = prepare.fit_transform(train)
```

**코드 해설**

- `ColumnTransformer`는 `sklearn.compose` 모듈의 클래스다.
- 각 항목은 `(이름, 처리 객체, 적용할 열)` 순서다.
- `OneHotEncoder`는 `sklearn.preprocessing` 모듈의 클래스다. 학습 자료의 범주를 기억하고 범주별로 0·1 열을 만든다.
- `sparse_output=False`는 예시의 결과를 일반 NumPy 배열로 받는 설정이다.

실행 흐름은 다음과 같다.

1. `age`의 중앙값 30으로 빈 값을 채운다. 값은 `[20, 40, 30]`이 된다.
2. 이 값들로 평균과 표준편차를 구해 숫자의 크기를 조정한다.
3. `country`의 범주 `JP`, `KR`를 기억하고 두 개의 열로 바꾼다.
4. 나이 1열과 국가 2열을 합친다. `ready`의 형태는 `(3, 3)`이다.

- 결과의 첫 행은 약 `[-1.225, 0, 1]`이다. 조정한 나이, JP 여부, KR 여부의 순서다.
- 이 예시에서는 국가 값이 모두 채워져 있다. 범주 열에도 빈 값이 있다면 인코딩 전에 대체 단계를 연결한다.

### 7-3) 새 자료에 같은 전처리 기준 적용

- 새 자료를 예측할 때도 학습에 사용한 열 순서와 변환 기준을 유지해야 한다. 처음 보는 범주를 처리하는 규칙도 전처리 객체에 함께 저장한다.

**코드 예시**

```python
new = pd.DataFrame({"age": [30], "country": ["US"]})
new_ready = prepare.transform(new)
print(new_ready)  # 0. 0. 0.
```

**코드 해설**

- `fit_transform()`은 기준을 구하고 변환한다. `transform()`은 기억한 기준으로 변환한다.
- 나이 30은 학습 자료의 평균과 같으므로 0으로 바뀐다.
- `US`는 학습 자료에 없던 범주다. `handle_unknown="ignore"` 설정에 따라 국가 부분은 `[0, 0]`이 된다.
- 학습 자료와 새 자료 모두 같은 세 열을 사용하므로, 이후 모델도 같은 형태의 입력을 받는다.
