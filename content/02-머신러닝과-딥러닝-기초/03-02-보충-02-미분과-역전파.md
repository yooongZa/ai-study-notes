## 1. 가중치 학습에 역전파가 필요한 이유

- 신경망은 많은 가중치를 거쳐 예측값을 만든다.
- 예측이 틀렸을 때는 각 가중치를 어느 방향으로 얼마나 바꿀지 정해야 한다.
- Gradient(기울기)는 **가중치를 조금 늘렸을 때 손실이 얼마나 변하는지** 나타낸다.
- Backpropagation(역전파)는 손실에서 앞쪽 연산으로 거슬러 가며 각 가중치의 기울기를 구하는 방법이다.
- 이 원리를 알면 `loss.backward()`와 `optimizer.step()`이 각각 맡은 일을 이해할 수 있다.

---

## 2. 미분과 작은 입력 변화의 영향

- 함수가 `y=x²`라고 하자.
- `x=3`이면 `y=9`다.
- `x`를 3.01로 조금 늘리면 `y=9.0601`이 된다.
- 입력은 0.01 늘고 출력은 0.0601 늘었다. 변화량의 비율은 약 6.01이다.
- 입력 변화량을 아주 작게 줄이면 이 비율은 6에 가까워진다.
- 이 순간의 변화율을 Derivative(미분계수)라고 한다.

$$\frac{dy}{dx}=2x$$

- `dy/dx`는 `x`에 대한 `y`의 미분을 뜻한다.
- `x=3`을 넣으면 미분값은 6이다.
- 손실 `L`과 가중치 `w`에도 같은 생각을 적용한다.
- 기울기가 양수이면 `w`를 조금 늘릴 때 손실이 커진다. 경사하강법은 `w`를 줄이는 쪽으로 움직인다.
- 기울기가 음수이면 `w`를 늘리는 쪽으로 움직인다.

---

## 3. 연쇄 법칙과 연결된 변화율

$$h=2w,\qquad y=3h$$

- `w`가 1만큼 늘면 `h`는 2만큼 늘어난다.
- `h`가 1만큼 늘면 `y`는 3만큼 늘어난다.
- 따라서 `w`가 1만큼 늘 때 `y`는 `2×3=6`만큼 늘어난다.

$$\frac{dy}{dw}=\frac{dy}{dh}\frac{dh}{dw}=3\times2=6$$

- Chain rule(연쇄 법칙)은 중간 계산을 거치는 변화율을 이렇게 연결한다.
- 비선형 함수에서는 현재 값에서 구한 각 미분값을 곱한다.
- 같은 가중치가 여러 계산 경로에 사용되면, 각 경로에서 전달된 기울기를 더한다.
- 신경망의 역전파는 곱하기와 더하기를 여러 층에 걸쳐 반복한다.

## 4. 작은 신경망의 예측값과 손실 계산

- 데이터는 두 건이며, 각 데이터에 입력값이 2개씩 있다고 하자.
- 첫 데이터의 입력은 `(1, 2)`, 정답은 10이다.
- 둘째 데이터의 입력은 `(3, 0)`, 정답은 15다.
- 세 가중치를 `a=2`, `b=1`, `c=3`으로 시작한다.

$$h=ax_1+bx_2,\qquad \hat y=ch$$

- `h`는 중간 계산값이다. `ŷ`는 예측값이다.
- 첫 데이터: `h=2×1+1×2=4`, `ŷ=3×4=12`.
- 둘째 데이터: `h=2×3+1×0=6`, `ŷ=3×6=18`.
- 예측에서 정답을 뺀 오차는 각각 2와 3이다.

$$L=\frac{(12-10)^2+(18-15)^2}{2}=6.5$$

- Mean squared error(평균제곱오차)는 오차를 제곱하고 데이터 수로 나눈 값이다.
- 이 예시에서는 데이터 두 건의 오차를 평균한다.
- 가중치 하나가 두 데이터의 예측에 함께 사용된다.

---

## 5. 각 가중치에 대한 손실의 기울기

### 예측값에 대한 손실의 기울기

$$\frac{\partial L}{\partial \hat y_i}
=\frac{2(\hat y_i-y_i)}{2}$$

- `∂`는 여러 값 중 하나를 바꾸는 미분을 표시한다. 나머지 값은 고정해 두고 생각한다.
- 분자의 2는 제곱을 미분해서 생긴다.
- 분모의 2는 데이터 두 건의 평균을 내기 때문에 생긴다.
- 첫 예측값의 기울기는 2, 둘째 예측값의 기울기는 3이다.

### 마지막 가중치 c의 기울기

- `ŷ=ch`이므로 `c`에 대한 예측값의 미분은 `h`다.
- 첫 데이터의 기여는 `2×4=8`이다.
- 둘째 데이터의 기여는 `3×6=18`이다.
- 두 데이터를 합하면 **`c`의 기울기는 `8+18=26`**이다.
- 평균을 내는 분모는 앞의 손실 미분에 이미 포함되어 있다.

### 앞쪽 가중치 a와 b의 기울기

- `h`에 대한 예측값의 미분은 `c=3`이다.
- 이 값을 거쳐 `a`와 `b`까지 기울기를 전달한다.
- `a`에 대한 `h`의 미분은 `x₁`이므로, `a`의 기울기는 `2×3×1 + 3×3×3 = 33`이다.
- `b`에 대한 `h`의 미분은 `x₂`이므로, `b`의 기울기는 `2×3×2 + 3×3×0 = 12`다.
- **세 기울기는 모두 같은 가중치 `a=2, b=1, c=3`을 기준으로 계산한다.**

---

## 6. 기울기와 학습률을 이용한 갱신

$$w_{\text{new}}=w_{\text{old}}-\eta g$$

- `η`는 Learning rate(학습률), `g`는 해당 가중치의 기울기다.
- 학습률을 0.01로 두면 다음처럼 갱신한다.

| 가중치 | 한 번 갱신한 값 |
| --- | --- |
| `a` | `2 − 0.01×33 = 1.67` |
| `b` | `1 − 0.01×12 = 0.88` |
| `c` | `3 − 0.01×26 = 2.74` |

- 새 가중치로 다시 계산한 예측은 약 `[9.3982, 13.7274]`다.
- 새 손실은 약 0.991이다. 처음의 6.5보다 작아졌다.
- **역전파는 기울기를 계산하고, 옵티마이저는 그 기울기로 가중치를 갱신한다.**

## 7. PyTorch의 자동 미분과 옵티마이저 연결

### torch Tensor의 backward 메서드 활용

- 앞에서 손으로 계산한 예측과 미분을 텐서로 옮겨 본다. 입력·정답은 고정하고, 학습할 세 가중치에 대해 기울기를 계산하도록 준비한다.

**코드 예시**

```python
import torch

a = torch.tensor(2., requires_grad=True)
b = torch.tensor(1., requires_grad=True)
c = torch.tensor(3., requires_grad=True)
x1 = torch.tensor([1., 3.])
x2 = torch.tensor([2., 0.])
target = torch.tensor([10., 15.])
```

**코드 해설**

- `a`, `b`, `c`는 각각 2·1·3에서 시작하는 가중치다. `target`은 두 입력에 대응하는 정답 10·15를 담는다.

- `x1`은 두 데이터의 첫 특성을 모은 값이고, `x2`는 둘째 특성을 모은 값이다.
- `requires_grad=True`는 해당 텐서에 대한 미분을 구할 수 있도록 연산을 기록한다.

**다음 예시의 원리**

- 역전파는 최종 손실의 변화가 각 가중치에서 얼마나 비롯됐는지 연결된 연산을 따라 계산한다. 먼저 예측과 손실을 구한 뒤 같은 계산 기록으로 기울기를 구한다.

**코드 예시**

```python
pred = c * (a * x1 + b * x2)
loss = ((pred - target) ** 2).mean()
loss.backward()

print(a.grad.item())  # 33.0
print(b.grad.item())  # 12.0
print(c.grad.item())  # 26.0
```

**코드 해설**

- 먼저 두 예측값 `[12, 18]`을 구한다. 정답 `[10, 15]`와의 오차 `[2, 3]`을 제곱해 평균하면 손실은 6.5다.
- `loss.backward()`는 이 손실을 만든 계산을 거슬러 가며 `a`, `b`, `c`의 기울기를 구한다. 계산한 기울기는 각 텐서의 `grad` 속성에 저장된다.

- `mean()`은 텐서 원소의 평균을 구하는 메서드다.
- `backward()`는 손실로 이어진 연산을 따라 미분하고 결과를 `grad` 속성에 저장한다.
- `item()`은 원소가 하나인 텐서에서 Python 숫자를 꺼내는 메서드다.

### torch.optim의 SGD 클래스와 step 메서드 활용

- 기울기를 구한 뒤에는 학습률을 곱한 만큼 반대 방향으로 가중치를 옮긴다. 앞의 세 기울기를 한 번의 SGD 갱신에 사용한다.

**코드 예시**

```python
optimizer = torch.optim.SGD([a, b, c], lr=0.01)
optimizer.step()

print(round(a.item(), 2))  # 1.67
print(round(b.item(), 2))  # 0.88
print(round(c.item(), 2))  # 2.74
```

**코드 해설**

- `SGD([a, b, c], lr=0.01)`에 갱신 대상을 전달한다. `step()`이 각 값에서 기울기의 0.01배를 빼고, 아래 세 줄이 변경된 값을 확인한다.

- 앞 코드에서 구한 기울기를 사용해 가중치를 한 번 갱신한다.
- 다음 학습 반복을 시작할 때는 `optimizer.zero_grad()`로 이전 기울기를 초기화한다.
- PyTorch는 기본적으로 기울기를 누적한다. `zero_grad()`는 새 배치의 기울기를 계산할 준비를 한다.
- 학습 순서는 **기울기 초기화 → 예측 → 손실 → 역전파 → 갱신**이다.
