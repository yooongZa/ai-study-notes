## 1. 옵티마이저와 학습률이 필요한 이유

- 역전파로 기울기를 구한 뒤에는 실제로 가중치를 얼마나 바꿀지 정해야 한다.
- 너무 크게 바꾸면 손실이 커지거나 흔들리고, 너무 작게 바꾸면 학습이 느리다.
- 작은 데이터 묶음마다 기울기 방향이 달라지는 경우도 있다.
- Optimizer(옵티마이저)는 **기울기를 이용해 가중치를 갱신하는 규칙**이다.
- SGD, Momentum, RMSProp, Adam은 어떤 정보를 기억하고 갱신에 사용하는지가 다르다.

---

## 2. SGD의 가중치 갱신식

$$w_{\text{new}}=w-\eta g$$

- `w`는 현재 가중치, `g`는 손실의 기울기다.
- `η`는 Learning rate(학습률)다. 기울기에 곱할 갱신 비율을 정한다.
- 가중치가 2, 기울기가 3, 학습률이 0.1이면 새 가중치는 `2−0.1×3=1.7`이다.
- 기울기가 −3이면 `2−0.1×(−3)=2.3`으로 증가한다.
- Mini-batch(미니배치)는 한 번의 기울기 계산에 사용하는 작은 데이터 묶음이다.
- SGD는 학습 코드에서 이런 묶음별 기울기를 사용해 반복 갱신하는 방식으로 자주 쓰인다.

### torch.optim 모듈의 SGD 클래스의 활용

- SGD의 기본 갱신은 현재 가중치에서 학습률과 기울기의 곱을 빼는 것이다. 기울기가 일정한 작은 식으로 갱신 한 번의 결과를 확인한다.

**코드 예시**

```python
import torch

w = torch.tensor(2., requires_grad=True)
optimizer = torch.optim.SGD([w], lr=0.1)
loss = 3 * w
loss.backward()
optimizer.step()

print(round(w.item(), 1))  # 1.7
```

**코드 해설**

- `loss.backward()`가 `w.grad`에 3을 저장한 뒤, `optimizer.step()`이 `2 - 0.1×3`을 계산한다. 이때 `w`의 값이 1.7로 바뀐다.

- 이 예시의 손실은 `L=3w`라서 기울기가 3이다.
- `[w]`는 옵티마이저가 갱신할 텐서 목록이다.
- `lr`은 학습률을 지정하는 인자다.
- `step()`은 옵티마이저 객체의 메서드다. 텐서에 저장된 기울기로 값을 바꾼다.

## 3. Momentum과 이전 기울기의 반영

- 배치마다 현재 기울기만 따라가면 갱신 방향이 자주 바뀔 수 있다.
- Momentum(모멘텀)은 이전 기울기를 누적한 값을 다음 갱신에도 사용한다.
- 같은 방향의 기울기가 반복되면 그 방향의 누적값이 커진다.
- 방향이 번갈아 바뀌면 서로 상쇄되어 흔들림을 줄일 수 있다.

$$v_t=\mu v_{t-1}+g_t$$
$$w_{t+1}=w_t-\eta v_t$$

- `v`는 누적한 기울기, `μ`는 이전 값을 남기는 비율이다.
- `μ=0.9`이고 기울기가 두 번 연속 2라면, 누적값은 `0 → 2 → 3.8`이 된다.
- 둘째 계산은 `0.9×2+2=3.8`이다.
- Momentum은 `torch.optim.SGD`의 `momentum` 인자로 설정할 수 있다.

- 모멘텀을 적용하면 직전까지 누적한 방향이 이번 갱신에도 반영된다. 현재 배치의 기울기만으로 방향이 크게 바뀌는 현상을 줄이는 데 쓰인다.

**코드 예시**

```python
optimizer = torch.optim.SGD(
    model.parameters(), lr=0.01, momentum=0.9
)
```

**코드 해설**

- `model`은 앞에서 정의한 PyTorch 모델이라고 가정한다.
- 모델 객체의 `parameters()` 메서드는 학습할 매개변수를 제공한다.
- `momentum=0.9`는 이전 누적값을 얼마나 남길지 정한다.

## 4. RMSProp과 기울기 크기 조정

- 어떤 가중치에는 큰 기울기가 반복되고, 다른 가중치에는 작은 기울기가 반복될 수 있다.
- RMSProp은 **각 가중치의 최근 기울기 제곱을 이동 평균으로 기록**한다.
- 기울기를 제곱하면 부호와 관계없이 크기를 기록할 수 있다.
- 기울기 제곱의 평균이 크면 분모가 커진다. 같은 현재 기울기라도 이 분모가 크면 갱신량이 작아진다.

$$s_t=\alpha s_{t-1}+(1-\alpha)g_t^2$$
$$w_{t+1}=w_t-\eta\frac{g_t}{\sqrt{s_t}+\epsilon}$$

- `s`는 기울기 제곱의 이동 평균이다. 가중치마다 따로 저장한다.
- `α`는 이전 평균을 유지하는 비율이다.
- `ε`는 0으로 나누는 일을 막는 작은 수다.
- 학습률 `η`는 전체 갱신 크기를 정하고, `s`는 가중치별 크기를 조정한다.
- 예를 들어 현재 기울기가 둘 다 2여도 `s=4`인 경우와 `s=100`인 경우는 갱신량이 다르다.
- `ε`를 생략해 비교하면 각각 `2/2=1`과 `2/10=0.2`에 학습률을 곱한다.

## 5. Adam의 기울기 평균과 제곱 평균

- Adam은 최근 기울기의 평균과 최근 기울기 제곱의 평균을 함께 저장한다.
- 기울기의 평균 `m`은 갱신 방향을 정하는 데 쓴다.
- 기울기 제곱의 평균 `v`는 가중치별 갱신 크기를 조정하는 데 쓴다.
- 두 평균은 0에서 시작한다. 초반 값이 작게 잡히는 영향을 Bias correction(편향 보정)으로 조정한다.
- 보정한 평균을 `m̂`, `v̂`라고 쓰면 갱신식은 다음과 같다.

$$w_{t+1}=w_t-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}$$

- 같은 현재 기울기라도 과거에 기록한 평균이 다르면 갱신 결과가 달라진다.
- 학습을 이어서 할 때 옵티마이저 상태를 저장하는 이유도 이 누적값 때문이다.

### torch.optim 모듈의 Adam 클래스의 활용

- Adam은 기울기의 평균으로 방향을 정하고 제곱 평균으로 크기를 조절한다. 두 평균을 유지하는 비율과 전체 학습률을 각각 설정한다.

**코드 예시**

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=0.001,
    betas=(0.9, 0.999),
)
```

**코드 해설**

- `betas`의 첫 값은 기울기 평균, 둘째 값은 기울기 제곱 평균에 적용한다.
- 각 값은 이전 평균을 유지하는 비율이다.
- `lr`은 평균을 반영해 구한 갱신량에 곱하는 학습률이다.

## 6. AdamW의 가중치 감쇠

- 큰 가중치에 비용을 주는 L2 규제는 예측 손실에 가중치 제곱합을 더한다.
- 이 손실을 미분하면 가중치를 줄이려는 항이 기울기에 포함된다.
- Adam에서 이 기울기를 사용하면, 규제의 영향도 두 이동 평균에 함께 들어간다.
- AdamW는 Weight decay(가중치 감쇠)를 이동 평균 계산과 분리한다.
- 가중치 감쇠는 `w`를 `(1−ηλ)w`로 줄이는 계산이다. `λ`가 감쇠 강도다.
- 예를 들어 `w=2`, `η=0.1`, `λ=0.01`이면 감쇠만 적용한 값은 `1.998`이다.
- 그 뒤 손실 기울기로 계산한 갱신량도 반영한다.

### torch.optim 모듈의 AdamW 클래스의 활용

- AdamW는 손실을 줄이는 갱신과 별도로 가중치 크기를 줄이는 감쇠를 적용한다. 학습률과 감쇠 강도가 함께 매개변수의 변화량을 정한다.

**코드 예시**

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=0.001,
    weight_decay=0.01,
)
```

**코드 해설**

- `weight_decay`는 가중치를 줄이는 강도를 정하는 인자다.
- `lr`도 감쇠량에 함께 들어간다.
- 예측 오차를 줄이는 갱신과 가중치 크기를 줄이는 규칙을 함께 적용한다.

## 7. 학습률 스케줄러와 StepLR

- 옵티마이저는 갱신 규칙을 정하고, 학습률은 한 번의 갱신 크기를 조절한다.
- Learning rate schedule(학습률 변화 계획)은 학습 진행에 따라 학습률을 바꾸는 규칙이다.
- 초반에 값이 크게 바뀌는 것을 줄이려면 작은 학습률로 시작할 수 있다.
- Warmup(초기 학습률 증가)은 작은 값에서 시작해 목표 학습률까지 올리는 과정이다.
- 이후 학습률을 낮추면 가중치를 작은 폭으로 조정할 수 있다.

| 구간 | 학습률의 변화 예시 |
| --- | --- |
| 초기 | `0.0001 → 0.0005 → 0.001` |
| 이후 | `0.001 → 0.0005 → 0.0001` |

- 위 숫자는 변화 방향을 보여 주는 예시다.
- Step decay는 정한 시점에 학습률을 줄인다.
- Cosine decay는 코사인 곡선 모양으로 학습률을 부드럽게 낮춘다.
- 어느 옵티마이저를 쓰든 갱신 규칙과 학습률 계획을 함께 정할 수 있다.

### torch.optim.lr_scheduler 모듈의 StepLR 클래스 활용

- 학습 후반에는 작은 폭으로 가중치를 조정하도록 학습률을 낮출 수 있다. StepLR은 정해진 횟수마다 현재 학습률에 일정한 비율을 곱한다.

**코드 예시**

```python
scheduler = torch.optim.lr_scheduler.StepLR(
    optimizer, step_size=2, gamma=0.5
)
```

**코드 해설**

- 현재 학습률이 0.001이고 에포크마다 스케줄러의 `step()`을 한 번 호출한다면, 2에포크가 끝난 뒤 0.0005, 4에포크가 끝난 뒤 0.00025가 된다.
- 스케줄러는 연결된 `optimizer`의 학습률을 바꾼다. 이후 가중치 갱신에는 바뀐 학습률이 사용된다.

- `optimizer`는 학습에 사용하는 옵티마이저 객체다.
- `step_size=2`는 스케줄러를 두 번 진행할 때마다 학습률을 바꾼다는 뜻이다.
- `gamma=0.5`는 기존 학습률에 0.5를 곱한다는 뜻이다.
- 스케줄러 객체의 `step()` 메서드를 매 에포크의 학습 갱신이 끝난 뒤 한 번 호출하면, 2에포크마다 학습률이 절반이 된다.
- 여기서 Epoch(에포크)는 전체 학습 데이터를 한 번 사용한 횟수다.
- 옵티마이저의 `step()`은 가중치를 바꾸고, 스케줄러의 `step()`은 학습률을 바꾼다.

## 8. 역전파·가중치 갱신·학습률 변경의 역할

1. `loss.backward()`가 가중치별 기울기를 구한다.
2. `optimizer.step()`이 기울기와 누적값을 이용해 가중치를 갱신한다.
3. 정해 둔 주기에 `scheduler.step()`이 이후에 사용할 학습률을 바꾼다.

- `SGD`는 현재 기울기, Momentum은 이전 방향, RMSProp은 최근 기울기 크기를 반영한다.
- Adam은 방향과 크기를 함께 기록한다.
- AdamW는 여기에 가중치 감쇠를 분리해 적용한다.
- 모델의 학습 상태는 학습 손실과 검증 성능을 함께 보며 확인한다.
