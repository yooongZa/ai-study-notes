## 1. 신경망에서 행렬 곱이 필요한 이유

- 신경망은 입력의 숫자들을 가중치와 곱하고 더해서 새로운 숫자들을 만든다.
- 입력이 수백 개이고 출력도 수백 개라면, 모든 계산을 하나씩 쓰기 어렵다.
- Matrix multiplication(행렬 곱)은 이 계산을 한꺼번에 표현하는 방법이다.
- 행렬 곱을 이해하면 `Linear(3, 2)`가 왜 입력 3개를 출력 2개로 바꾸는지 알 수 있다.
- Transformer의 Q·K·V도 입력 벡터에 서로 다른 가중치 행렬을 곱해서 만든다.

---

## 2. 벡터와 행렬의 형태

- Vector(벡터)는 여러 숫자를 순서대로 묶은 것이다.
- 예를 들어 집 한 채를 면적과 방 개수로 나타내면 `[20, 2]`처럼 쓸 수 있다.
- Matrix(행렬)는 숫자를 행과 열로 배치한 것이다.
- Shape(형태)는 행과 열의 수를 나타낸다. `(2, 3)`은 2행 3열이다.
- 어떤 축이 데이터 수이고 어떤 축이 특성 수인지는 계산에 앞서 정한다.

$$
x=\begin{bmatrix}2\\3\end{bmatrix},
\qquad W=\begin{bmatrix}4&1\\-1&2\end{bmatrix}
$$

- `x`에는 입력값 2개가 있다.
- `W`의 첫 행 `[4, 1]`은 첫 번째 출력을 계산할 가중치다.
- 둘째 행 `[-1, 2]`는 두 번째 출력을 계산할 가중치다.

---

## 3. 행렬의 행과 출력값 계산

$$
Wx=\begin{bmatrix}4\times2+1\times3\\(-1)\times2+2\times3\end{bmatrix}
=\begin{bmatrix}11\\4\end{bmatrix}
$$

1. 첫 행의 가중치를 입력과 각각 곱하면 8과 3이다.
2. 두 값을 더하면 첫 출력 11이다.
3. 둘째 행도 같은 순서로 계산하면 둘째 출력 4다.
4. 따라서 입력 `[2, 3]`이 출력 `[11, 4]`로 바뀐다.

- 같은 위치의 값끼리 곱해 더하는 계산을 Dot product(내적)라고 한다.
- 각 행은 입력을 어떤 비율로 반영할지 정한다.
- 음수 가중치는 해당 입력이 증가할 때 출력을 줄이는 방향으로 작용한다.

### torch 모듈의 matmul 함수의 활용

- 가중치 행 하나는 입력의 여러 값을 섞어 출력 하나를 만든다. 각 입력에 가중치를 곱해 더하는 계산을 행마다 반복하면 출력 벡터가 된다.

**코드 예시**

```python
import torch

W = torch.tensor([[4., 1.], [-1., 2.]])
x = torch.tensor([2., 3.])
y = torch.matmul(W, x)

print(y)  # tensor([11.,  4.])
```

**코드 해설**

- 첫 출력은 첫 행 `[4, 1]`과 입력 `[2, 3]`을 곱해 더한 `4×2 + 1×3 = 11`이다. 둘째 출력은 `-1×2 + 2×3 = 4`다.
- 이처럼 **가중치 행 하나가 출력 하나를 계산**한다. 가중치 행이 2개이므로 결과도 숫자 2개다.

- 코드의 `x`는 형태가 `(2,)`인 1차원 텐서다. 이 계산에서는 수식의 열벡터 역할로 사용된다.
- `torch.matmul(W, x)`와 `W @ x`는 이 예시에서 같은 결과를 만든다.
- `@`는 Python의 행렬 곱 연산자다.
- `*`는 텐서에서 같은 위치의 원소끼리 곱한다. `W * x`는 행별 덧셈 없이 `[[8, 3], [-2, 6]]`을 만든다.

## 4. 행렬의 열과 입력별 영향

$$
Wx=2\begin{bmatrix}4\\-1\end{bmatrix}
+3\begin{bmatrix}1\\2\end{bmatrix}
=\begin{bmatrix}11\\4\end{bmatrix}
$$

- 첫 입력 2는 첫 열 `[4, -1]` 전체에 곱해진다.
- 둘째 입력 3은 둘째 열 `[1, 2]` 전체에 곱해진다.
- 첫 입력만 1 늘리면 출력은 `[4, -1]`만큼 달라진다.
- **행을 보면 출력 하나의 계산을, 열을 보면 입력 하나의 영향을 읽을 수 있다.**
- 여러 벡터를 일정한 비율로 곱한 뒤 더하는 것을 Linear combination(선형결합)이라고 한다.

---

## 5. 배치 입력과 전치 행렬

- 집 한 채의 특성이 2개라면, 집 5채를 담은 입력 `X`는 `(5, 2)`로 만들 수 있다.
- 각 행이 집 한 채이고, 각 열이 특성 하나다.
- 앞의 `W`는 출력별 가중치를 행으로 가지고 있다.
- 이 배치에 적용할 때는 `X @ W.T`로 계산한다.

$$(5,2)\ @\ (2,2)\ \longrightarrow\ (5,2)$$

- `W.T`는 행과 열을 바꾸는 Transpose(전치) 결과다.
- 가운데 크기 2가 맞으므로 각 입력의 특성 2개를 가중치와 곱해 더할 수 있다.
- 결과는 집 5채에 대한 출력 2개씩이다.
- 일반적인 2차원 행렬 곱은 `(B, D) @ (D, K) → (B, K)`로 읽는다.

### torch Tensor의 T 속성과 행렬 전치

- 데이터가 여러 건이면 입력을 행별로 놓고 같은 가중치를 적용한다. 가중치의 행을 출력별로 저장했다면 전치하여 행렬 곱의 축을 맞춘다.

**코드 예시**

```python
X = torch.tensor([[2., 3.], [1., 0.]])
Y = X @ W.T

print(Y)  # tensor([[11.,  4.],
          #         [ 4., -1.]])
```

**코드 해설**

- `W`는 앞 예시의 가중치 행렬이다.
- 첫 행은 앞에서 계산한 `[11, 4]`다.
- 둘째 행은 새 입력 `[1, 0]`에 대한 결과 `[4, -1]`이다.
- 같은 가중치를 모든 데이터 행에 적용한다.

## 6. Linear 레이어의 가중치와 편향

$$Y=XW^{T}+b$$

- `W`는 각 입력을 출력에 얼마나 반영할지 정한다.
- Bias(편향)인 `b`는 출력마다 더하는 값이다.
- 편향이 `[0.5, -1]`이면 앞의 출력 `[11, 4]`는 `[11.5, 3]`이 된다.
- `Wx`는 Linear transformation(선형변환)이다.
- 편향까지 더한 `Wx+b`는 Affine transformation(아핀변환)이라고 한다. PyTorch의 `Linear` 레이어는 기본 설정에서 이 계산을 한다.

### torch.nn 모듈의 Linear 클래스의 활용

- 선형층은 출력 하나마다 입력 수만큼의 가중치와 편향 하나를 가진다. 따라서 입력·출력 크기를 알면 학습할 숫자의 배치도 알 수 있다.

**코드 예시**

```python
from torch import nn

layer = nn.Linear(3, 2)
print(layer.weight.shape)  # torch.Size([2, 3])
print(layer.bias.shape)    # torch.Size([2])
```

**코드 해설**

- 첫 인자 3은 입력 특성 수, 둘째 인자 2는 출력 특성 수다.
- `weight`는 출력 2개에 필요한 가중치 3개씩을 가진다.
- `bias`는 출력마다 더할 편향 1개씩을 가진다.
- `weight`와 `bias`는 레이어 객체의 속성이다.
- 학습은 이 행렬과 편향 안의 숫자를 바꾸는 과정이다.

## 7. 행렬 곱을 이용한 Q·K·V 생성

- 문장의 토큰 벡터를 행별로 모은 행렬을 `X`라고 하자.
- Q·K·V는 각각 `XW_Q`, `XW_K`, `XW_V`처럼 계산한다.
- 서로 다른 가중치를 사용하므로 같은 입력에서 서로 다른 표현이 나온다.
- 학습은 각 표현이 Attention(어텐션) 계산에 도움이 되도록 가중치를 조정한다.
- 여기서는 가중치를 `(입력 차원, 출력 차원)`으로 적었다. `nn.Linear`는 가중치를 반대 형태로 저장하고 계산할 때 전치한다.
- 수식을 읽을 때는 **입력의 형태 → 가중치의 형태 → 출력의 형태**를 차례로 확인하면 된다.
