## 1. 레이어의 계산 원리를 배우는 이유

- 신경망 코드는 레이어 이름을 여러 개 연결한 형태로 작성된다.
- 각 레이어가 입력을 어떻게 바꾸는지 모르면 출력 크기를 정하거나 오류 원인을 찾기 어렵다.
- 레이어는 **입력 텐서를 받아 특정 계산을 하고 출력 텐서를 만드는 구성 요소**다.
- Linear는 입력값을 가중합으로 바꾸고, Convolution(합성곱)은 가까운 위치의 값을 함께 계산한다.
- 두 계산의 차이를 알면 표와 이미지에 서로 다른 구조를 사용하는 이유를 이해할 수 있다.

---

## 2. 입력 텐서의 배치·채널·공간 축

- 표 데이터의 `(N, D)`는 샘플 `N개`, 특성 `D개`를 뜻한다.
- PyTorch의 일반적인 이미지 배치는 `(N, C, H, W)` 형태다.
- `N`은 이미지 수, `C`는 채널 수, `H`와 `W`는 높이와 너비다.
- RGB 이미지는 빨강·초록·파랑 값을 따로 담으므로 입력 채널이 3개다.
- `(2, 3, 8, 8)`은 8×8 RGB 이미지 2장이다.
- 배치 축은 서로 다른 샘플을 구분한다. 같은 레이어의 가중치가 배치의 모든 샘플에 공통으로 적용된다.

---

## 3. Linear 레이어의 가중합과 출력 크기

$$y_k=\sum_{j=1}^{D}w_{kj}x_j+b_k$$

- 출력 하나를 만들려면 입력마다 가중치를 곱한 뒤 모두 더하고 편향을 더한다.
- 출력이 여러 개이면 출력마다 서로 다른 가중치와 편향을 사용한다.
- 예를 들어 입력 `[2, 3]`, 가중치 `[4, 1]`, 편향 0.5이면 출력은 `2×4 + 3×1 + 0.5 = 11.5`다.
- Dense layer(밀집층), Fully connected layer(완전연결층)는 이런 연결을 가리킬 때 사용하는 이름이다.
- MLP(다층 퍼셉트론)는 이런 레이어와 활성화 함수를 여러 층 연결한 신경망이다.

### torch.nn 모듈의 Linear 클래스의 활용

- 선형층은 샘플마다 같은 가중치와 편향을 적용한다. 샘플 수는 유지하면서 마지막 축의 특성 수를 입력 크기에서 출력 크기로 바꾼다.

**코드 예시**

```python
import torch
from torch import nn

layer = nn.Linear(in_features=3, out_features=2)
x = torch.zeros(5, 3)
y = layer(x)
```

**코드 해설**

- `nn.Linear`는 클래스이며 `layer`는 생성된 레이어 객체다. `layer(x)`는 객체가 가진 가중치·편향으로 `x`를 계산하는 호출이다.
- 입력 5행에 같은 가중치를 적용한다. 각 행에서 숫자 3개를 읽고 출력 2개를 계산하므로 결과는 5행 2열이다.

- 입력은 샘플 5개에 특성 3개이므로 `(5, 3)`이다.
- 각 샘플에 출력 2개를 계산하므로 결과는 `(5, 2)`다.
- `layer.weight.shape`는 `(2, 3)`이다. 출력마다 가중치 3개가 필요하다.
- `layer.bias.shape`는 `(2,)`이다. 출력마다 편향 1개가 필요하다.
- 학습할 매개변수는 `3×2 + 2 = 8개`다. 배치 크기 5는 이 계산에 포함되지 않는다.
- 더 일반적으로 입력 특성 `D`, 출력 특성 `K`이고 편향을 사용하면 매개변수 수는 `D×K + K`다.

## 4. 이미지의 가까운 픽셀과 공간 관계

- 이미지에는 옆 픽셀과 이어지는 선, 경계, 무늬 같은 공간 관계가 있다.
- 모든 픽셀을 펼쳐 Linear에 넣으면 출력마다 전체 픽셀 수만큼 가중치가 필요하다.
- 예를 들어 32×32 RGB 이미지는 `3×32×32 = 3,072개` 값이다. 이를 출력 100개에 연결하면 편향을 포함해 307,300개 매개변수가 필요하다.
- 합성곱은 작은 영역의 값들을 계산하고, 같은 가중치를 다른 위치에도 반복해서 사용한다.
- 그래서 가까운 위치의 패턴을 다루면서 매개변수 수를 줄일 수 있다.

---

## 5. 합성곱의 커널 이동과 가중치 공유

- Kernel(커널) 또는 Filter(필터)는 작은 영역을 계산하는 가중치 묶음이다.
- 한 위치에서 입력 영역과 필터의 같은 위치 값들을 곱하고 모두 더한다.
- 필터를 다음 위치로 옮겨 같은 계산을 반복한다.
- 같은 필터로 각 위치에서 구한 값을 모은 것이 Feature map(특성 맵)이다.
- 필터의 가중치는 학습으로 바뀐다. 입력의 어떤 패턴에 큰 값을 낼지도 학습으로 정해진다.

작은 숫자로 한 위치의 계산을 보면 다음과 같다.

- 입력 영역이 `[[1, 2], [3, 4]]`이고 필터가 `[[1, 0], [0, -1]]`이면 결과는 `1×1 + 2×0 + 3×0 + 4×(-1) = -3`이다.
- 이 계산을 옆 영역에서도 같은 필터로 반복한다.
- RGB 입력에서는 필터가 세 입력 채널에 대한 가중치를 모두 가진다. 채널별 계산 결과까지 더해 출력 채널 하나의 값을 만든다.
- 출력 채널이 4개이면 서로 다른 필터 4묶음을 사용한다. 각 출력 채널은 서로 다른 학습된 특징을 표현한다.

## 6. 커널·스트라이드·패딩과 출력 크기

- `kernel_size`는 한 번에 계산하는 영역의 크기다. 3이면 가로·세로 3칸이다.
- Stride(스트라이드)는 필터를 한 번에 몇 칸 옮기는지다. 2이면 두 칸씩 이동한다.
- Padding(패딩)은 입력의 가장자리에 값을 덧붙이는 것이다. 기본적인 0 패딩은 가장자리에 0을 채운다.
- 패딩을 넣으면 가장자리도 계산에 더 참여하고, 공간 크기를 유지하는 구성도 만들 수 있다.
- 아래 식은 필터 내부 간격을 늘리는 `dilation`이 기본값 1일 때의 출력 높이다. 너비도 같은 방식으로 계산한다.

$$H_{out}=\left\lfloor\frac{H+2P-K}{S}\right\rfloor+1$$

- `H`는 입력 높이, `P`는 한쪽 패딩 크기, `K`는 커널 크기, `S`는 스트라이드다.
- `⌊ ⌋`는 소수점 아래를 버린다는 뜻이다.
- 높이 8, 커널 3, 패딩 1, 스트라이드 1이면 `(8+2-3)/1+1 = 8`이다.
- 같은 조건에서 패딩을 0으로 바꾸면 출력 높이는 6이다.

### torch.nn 모듈의 Conv2d 클래스의 활용

- 합성곱은 작은 커널을 여러 위치에 적용하면서 채널을 함께 조합한다. 커널 크기·이동 간격·가장자리 채우기가 출력의 공간 크기를 정한다.

**코드 예시**

```python
conv = nn.Conv2d(
    in_channels=3,
    out_channels=4,
    kernel_size=3,
    stride=1,
    padding=1,
)
x = torch.zeros(2, 3, 8, 8)
y = conv(x)
```

**코드 해설**

- `Conv2d(...)`에서 RGB 채널 3개로 출력 채널 4개를 계산하도록 정한다. `zeros(2, 3, 8, 8)`은 이미지 두 장의 입력 형태를 만들고, `conv(x)`가 각 위치에 필터를 적용한다.

- 입력 채널은 3개, 출력 채널은 4개다.
- 가로·세로 크기는 8로 유지되어 출력 형태는 `(2, 4, 8, 8)`이다.
- 기본 `groups=1`에서 필터 가중치의 형태는 `(출력 채널, 입력 채널, 커널 높이, 커널 너비)`다.
- 위 가중치는 `(4, 3, 3, 3)`이고, 기본 편향까지 포함한 매개변수 수는 `4×3×3×3 + 4 = 112개`다.
- 이미지의 가로·세로 위치마다 같은 필터를 쓰므로 매개변수 수에 이미지의 높이와 너비를 곱하지 않는다.

## 7. 풀링·Flatten·분류기의 연결

- Pooling(풀링)은 작은 영역의 대표값을 사용해 공간 크기를 줄이는 계산이다.
- Max pooling(최대 풀링)은 영역의 최댓값을 남긴다.
- `torch.nn.MaxPool2d(2)`는 기본적으로 2×2 영역을 두 칸씩 이동하며 최댓값을 고른다.
- 풀링 자체에는 학습할 필터 가중치가 없다.
- `torch.nn.Flatten` 클래스는 여러 축을 한 축으로 펼치는 레이어를 만든다. 기본 설정에서는 배치 축을 유지한다.

- 이미지의 공간 정보를 분류 점수로 바꾸려면 먼저 공간을 줄이고 샘플별 벡터로 펼친다. 펼친 값의 개수가 마지막 선형층의 입력 크기와 맞아야 한다.

**코드 예시**

```python
pool = nn.MaxPool2d(2)
flatten = nn.Flatten()
classifier = nn.Linear(4 * 4 * 4, 10)

pooled = pool(y)
features = flatten(pooled)
logits = classifier(features)
```

**코드 해설**

- `pool`, `flatten`, `classifier`는 앞에서 만든 세 레이어 객체다. 각 줄의 출력이 다음 줄의 입력이 되어 **공간 축소 → 한 줄로 펼치기 → 클래스 점수 계산** 순서로 진행된다.

- 앞 절의 `y`는 `(2, 4, 8, 8)`이다.
- `pool`을 지나면 `(2, 4, 4, 4)`가 된다. 공간 크기가 절반으로 줄어든다.
- `flatten`을 지나면 `(2, 64)`가 된다. 샘플마다 `4×4×4`개 값을 한 줄로 펼친다.
- `classifier`는 `(2, 10)`을 출력한다. 샘플마다 클래스 10개의 점수를 계산한다.

## 8. 입력에서 출력까지 레이어 해석

1. 입력 텐서의 각 축이 무엇인지 확인한다.
2. Linear는 마지막 특성 수를, Conv2d는 입력 채널 수를 확인한다.
3. 해당 레이어가 값을 어떻게 계산하는지 읽는다.
4. 출력의 형태를 계산한다.
5. 다음 레이어가 요구하는 입력 형태와 연결한다.

- 신경망의 구조를 정하면 학습할 가중치의 개수와 배치가 정해진다.
- 학습은 이 가중치들의 실제 수치를 손실이 줄어드는 방향으로 바꾸는 과정이다.
