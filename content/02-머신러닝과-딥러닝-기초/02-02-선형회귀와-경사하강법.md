## 1. 선형 회귀와 학습 원리를 배우는 이유

- 모델을 학습한다는 말을 이해하려면 어떤 값을 바꾸고, 무엇을 기준으로 바꾸는지 알아야 한다.
- Linear regression(선형 회귀)은 입력을 가중치와 곱하고 편향을 더해 수치를 예측한다.
- 구조가 단순해서 **예측 → 오차 계산 → 가중치 수정**이라는 학습 과정을 직접 이해하기 좋다.
- 이 흐름을 익히면 신경망에서도 손실과 기울기와 최적화 코드의 역할을 연결할 수 있다.

---

## 2. 가중치·편향·예측값의 관계

$$\hat y = wx+b$$

- `x`는 입력이다. 예를 들어 집의 면적을 넣을 수 있다.
- `ŷ`는 모델이 예측한 값이다. 실제 정답인 `y`와 구분한다.
- `w`는 Weight(가중치)다. 입력이 1 증가할 때 예측값이 얼마나 변하는지 결정한다.
- `b`는 Bias(편향)다. 입력이 0일 때의 예측값이며, 직선 전체를 위아래로 이동시킨다.
- `w=2`, `b=1`, `x=3`이면 예측값은 7이다.
- Parameter(매개변수)는 학습으로 정하는 모델 안의 수치다. 여기서는 `w`와 `b`가 해당한다.

---

## 3. MSE와 예측 오차의 계산

- 실제값이 5인데 7로 예측했다면 `예측값 - 실제값`은 2다.
- 다른 데이터에서 오차가 -2이면 단순 합계는 0이 된다. 두 예측이 모두 틀렸는데 오차가 상쇄된다.
- MSE(평균제곱오차)는 각 오차를 제곱한 뒤 평균을 구해 이 문제를 해결한다.

$$L=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2$$

- `N`은 데이터 수다. `i`는 각 데이터의 순서를 나타낸다.
- 예측값 `[3, 5]`, 실제값 `[2, 7]`이면 오차는 `[1, -2]`다.
- 제곱한 값은 `[1, 4]`, MSE는 `(1 + 4) / 2 = 2.5`다.
- 큰 오차는 제곱하면서 더 크게 반영된다.

### numpy ndarray의 mean 메서드의 활용

- 예측 오차를 그대로 더하면 양수와 음수가 상쇄될 수 있다. 제곱한 오차를 평균하면 오차의 크기를 하나의 손실값으로 모을 수 있다.

**코드 예시**

```python
import numpy as np

y_pred = np.array([3.0, 5.0])
y_true = np.array([2.0, 7.0])
loss = ((y_pred - y_true) ** 2).mean()
```

**코드 해설**

- 계산 순서는 **빼기 → 제곱 → 평균**이다. 배열 두 개를 빼면 `[1, -2]`, 제곱하면 `[1, 4]`, 평균을 내면 숫자 하나인 2.5가 나온다.

- `numpy` 모듈의 함수인 `array`는 숫자 목록을 계산용 배열로 만든다.
- `-`와 `** 2`는 같은 위치의 원소끼리 뺀 뒤 제곱한다.
- 배열 객체의 메서드인 `mean()`은 결과 두 개의 평균 2.5를 반환한다.

## 4. 미분과 손실의 기울기

- 손실이 크다는 사실만으로는 `w`를 늘려야 할지 줄여야 할지 알기 어렵다.
- Derivative(미분)는 어떤 값을 조금 바꿨을 때 결과가 어느 방향으로 얼마나 변하는지 나타낸다.
- `w`에 대한 손실의 기울기가 양수면 `w`를 늘리는 방향에서 손실이 커진다. 손실을 줄이려면 `w`를 줄인다.
- 기울기가 음수면 `w`를 늘리는 방향으로 움직인다.
- 여러 매개변수에 대한 미분값을 모은 것이 Gradient(기울기)다.

$$\frac{\partial L}{\partial w}
=\frac{2}{N}\sum_{i=1}^{N}(wx_i+b-y_i)x_i$$

$$\frac{\partial L}{\partial b}
=\frac{2}{N}\sum_{i=1}^{N}(wx_i+b-y_i)$$

- `∂L/∂w`는 손실을 `w`에 대해 미분한 값이다. `∂L/∂b`는 `b`에 대한 값이다.
- 두 식 모두 예측 오차를 사용한다. `w`를 바꾸면 입력 `x`만큼 예측에 영향을 주므로 첫 식에는 `x`가 한 번 더 곱해진다.
- 이 두 값이 각각 가중치와 편향을 수정할 방향을 알려준다.

## 5. 경사하강법의 가중치 갱신 원리

$$w_{new}=w-\eta\frac{\partial L}{\partial w}$$

$$b_{new}=b-\eta\frac{\partial L}{\partial b}$$

- Gradient descent(경사하강법)는 손실이 줄어드는 방향으로 매개변수를 조금씩 수정하는 방법이다.
- `η`는 Learning rate(학습률)다. 기울기에 얼마를 곱해서 이동할지 정한다.
- 학습률이 너무 작으면 수정 폭이 작아 학습이 오래 걸린다. 너무 크면 손실이 작은 지점을 지나쳐 오히려 손실이 커질 수 있다.
- 학습률은 사람이 정하는 Hyperparameter(하이퍼파라미터)다. 학습으로 정해지는 `w`, `b`와 역할이 다르다.

### 가중치와 편향을 한 번 갱신하는 계산 예시

- 데이터가 `x=1`, `y=3` 한 개이고, 처음 값이 `w=0`, `b=0`이라고 하자.
- 예측은 0이고 오차는 -3이다. 손실은 9다.
- `w`의 기울기와 `b`의 기울기는 각각 -6이다.
- 학습률이 0.1이면 두 값에 `-0.1 × (-6)`을 더하는 효과가 생긴다. 새 `w`와 `b`는 각각 0.6이다.
- 새 예측값은 `0.6 × 1 + 0.6 = 1.2`, 새 손실은 `(1.2 - 3)² = 3.24`다.
- 한 번의 수정으로 손실이 9에서 3.24로 줄었다. 이 과정을 반복해 매개변수를 찾는다.

## 6. 여러 입력 특성의 가중합과 행렬 곱

$$\hat y=w_1x_1+w_2x_2+\cdots+w_dx_d+b$$

- `d`는 특성 수다. 면적과 방 개수를 쓰면 `d=2`다.
- 각 특성마다 가중치가 하나씩 붙고, 곱한 값들을 더한 뒤 편향을 더한다.
- 행렬로 쓰면 `X @ w + b`다.
- `X`가 `(N, d)`, `w`가 `(d,)`이면 결과는 `(N,)`이다. 데이터마다 예측값 하나가 나온다.

- 여러 특성을 사용하는 선형 모델은 특성별 가중합에 편향을 더한다. 여러 데이터 행을 한 배열에 넣으면 같은 계산을 한 번의 행렬 곱으로 처리할 수 있다.

**코드 예시**

```python
X = np.array([[1.0, 2.0], [3.0, 4.0]])
w = np.array([2.0, 1.0])
b = 0.5
y_pred = X @ w + b
```

**코드 해설**

- `@`는 Python의 행렬 곱 연산자다. NumPy 배열에서는 행별로 가중치와 곱한 값을 더한다.
- 첫 예측값은 `1×2 + 2×1 + 0.5 = 4.5`다.
- 둘째 예측값은 `3×2 + 4×1 + 0.5 = 10.5`다.
- NumPy 배열의 원소별 곱인 `*`와 행렬 곱인 `@`는 계산 방식이 다르다.

## 7. LinearRegression의 학습과 예측 흐름

### sklearn.linear_model 모듈의 LinearRegression 클래스의 활용

- 라이브러리의 선형 회귀 모델도 학습한 계수를 보관하고 새 자료의 가중합을 계산한다. 아래에서는 학습과 예측을 각각 모델의 메서드로 호출한다.

**코드 예시**

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

**코드 해설**

- `model`은 학습한 가중치와 편향을 보관하는 객체다. `fit()`을 마친 뒤 `model.coef_`와 `model.intercept_`에서 그 값을 확인할 수 있다.
- `predict()`는 저장된 값으로 각 행의 가중합을 계산한다. 평가 입력이 10행이면 예측값도 10개를 돌려준다.

- `fit`은 학습 자료의 제곱오차를 작게 만드는 가중치와 편향을 구한다.
- `predict`는 구한 값으로 `X_test`의 예측값을 계산한다.
- `LinearRegression`은 최소제곱 문제를 푸는 계산법을 사용한다. 앞의 경사하강법은 손실을 반복해서 줄이는 학습 원리를 설명하는 방법이다.
- 학습 후 확인할 것은 두 가지다. 학습 손실이 줄었는지, 학습에 쓰지 않은 자료에서도 오차가 작은지 확인한다.

학습 과정을 순서로 기억한다.

1. 매개변수의 초기값을 정한다.
2. 입력으로 예측값을 계산한다.
3. 정답과 비교해 손실을 구한다.
4. 각 매개변수에 대한 손실의 기울기를 구한다.
5. 기울기의 반대 방향으로 매개변수를 수정한다.
6. 새 매개변수로 다시 예측하며 반복한다.
