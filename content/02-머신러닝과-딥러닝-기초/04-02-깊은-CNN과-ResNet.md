title: "깊은 CNN과 VGG와 ResNet의 구조 이해하기"

## 1. 깊은 CNN의 연결 구조를 배우는 이유

- 이미지의 작은 선과 경계만으로는 사물 전체를 구분하기 어렵다.
- 앞 레이어의 결과를 다음 레이어가 다시 결합하면 더 넓은 영역의 관계를 계산할 수 있다.
- CNN(합성곱 신경망)은 합성곱과 활성화 함수 등을 연결해 이미지의 특징을 학습한다.
- 깊이가 늘면 복잡한 관계를 표현할 수 있지만, 많은 단계를 거쳐 가중치를 학습시키는 과정도 어려워진다.
- VGG와 ResNet을 배우는 이유는 **레이어를 연결하는 방식이 표현과 학습에 어떤 영향을 주는지** 이해하기 위해서다.

---

## 2. 이미지 분류 모델의 전체 흐름

1. 픽셀 값을 담은 이미지 텐서를 입력한다.
2. 합성곱과 활성화 함수로 위치별 특징을 계산한다.
3. 풀링이나 스트라이드로 공간 크기를 줄인다.
4. 더 깊은 레이어가 앞에서 만든 특징을 결합한다.
5. 특징을 모아 클래스별 점수를 출력한다.

- 출력이 `(N, 100)`이면 이미지 `N개`에 대해 클래스 100개의 점수가 있다는 뜻이다.
- 최종 클래스를 고를 때는 가장 큰 점수의 위치를 선택한다.
- 학습에서는 점수와 실제 정답을 손실 함수에 넣고 모든 학습 대상 레이어의 가중치를 갱신한다.
- ImageNet은 다양한 사물 이미지가 담긴 데이터셋이다. 대규모 이미지 분류를 학습한 모델을 이해할 때 자주 등장한다.
- AlexNet은 합성곱, ReLU, 풀링, 드롭아웃 등을 조합한 대표적인 초기 심층 CNN이다. VGG와 ResNet은 깊은 구조를 구성하는 다른 방법을 보여준다.

---

## 3. VGG의 합성곱 블록

- VGG는 3×3 합성곱을 반복하고, 일정한 구간마다 풀링으로 공간 크기를 줄이는 구조다.
- VGG16의 16은 가중치를 가진 합성곱 13개와 완전연결 레이어 3개를 센 것이다.
- ReLU와 풀링은 이 숫자에 포함하지 않는다.
- 작은 합성곱을 반복하면 각 출력에 영향을 주는 입력 영역이 넓어진다.
- Receptive field(수용 영역)는 특정 출력값의 계산에 영향을 주는 원래 입력의 영역이다.
- 스트라이드 1의 3×3 합성곱을 두 번 쌓으면 가운데 출력이 영향을 받는 영역은 5×5가 된다.
- 두 합성곱 사이에 ReLU를 넣으면 비선형 변환도 한 번 더 적용된다.

### torch.nn의 Sequential 클래스와 VGG 블록 구성

- VGG 블록은 작은 합성곱을 반복해 특징을 계산한 뒤 풀링으로 공간을 줄인다. 같은 블록의 출력이 다음 블록의 입력이 되어 더 넓은 이미지 구조를 표현한다.

**코드 예시**

```python
from torch import nn

block = nn.Sequential(
    nn.Conv2d(3, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.Conv2d(64, 64, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
)
```

**코드 해설**

- `Sequential`은 넣은 레이어를 순서대로 실행하는 클래스로, `block`은 만들어진 객체다.
- 입력이 `(N, 3, 32, 32)`이면 첫 합성곱은 `(N, 64, 32, 32)`를 만든다.
- 두 번째 합성곱은 공간 크기와 채널 수를 유지한다.
- 마지막 풀링을 지나면 `(N, 64, 16, 16)`이 된다.
- 다음 블록은 이 결과를 입력으로 받아 더 복잡한 특징을 계산한다.

## 4. 깊이가 늘어날 때의 학습 문제

- 역전파에서는 뒤쪽의 손실 변화가 앞 레이어에 미친 영향을 연쇄적으로 계산한다.
- 이때 여러 미분값을 곱한다. 작은 값들이 반복해서 곱해지면 앞쪽으로 전달되는 기울기가 매우 작아질 수 있다.
- Vanishing gradient(기울기 소실)는 이런 이유로 앞 레이어의 가중치가 거의 갱신되지 않는 문제다.
- 큰 값들이 반복해서 곱해지면 기울기가 지나치게 커지는 Exploding gradient(기울기 폭주)가 생길 수 있다.
- 깊은 모델에서는 추가한 레이어가 필요한 변환을 학습하도록 최적화하는 일 자체도 어려워질 수 있다.
- ResNet은 입력을 출력에 직접 더하는 연결을 사용해 깊은 블록의 학습을 돕는다.

## 5. ResNet의 잔차 연결과 입력 더하기

$$y=F(x)+x$$

- `x`는 블록의 입력이다.
- `F(x)`는 블록 안의 여러 레이어가 계산한 값이다.
- 블록은 입력 `x`에 `F(x)`를 더해 출력한다. `F(x)`를 입력에서 더 조정할 부분으로 해석할 수 있다.
- 이런 구조를 Residual block(잔차 블록), 입력을 직접 전달하는 연결을 Skip connection(건너뛰기 연결)이라고 한다.
- `F(x)`가 0에 가까우면 블록의 출력은 입력과 가까워진다. 입력을 유지하는 경우도 쉽게 표현할 수 있다.
- 역전파 때 덧셈의 직접 연결을 따라 기울기가 전달되는 경로가 생긴다. 여러 레이어를 거친 경로와 함께 학습에 기여한다.

- 잔차 연결은 레이어가 계산한 변화량을 입력에 더하는 구조다. 아래의 잔차 변환은 입력과 같은 형태를 출력한다고 가정한다.

**코드 예시**

```python
out = block(x)
out = out + x
```

**코드 해설**

- 이 절의 `block`은 입력과 같은 형태의 출력을 만드는 잔차 변환이라고 가정한다. 앞의 VGG 예시에서 사용한 `block`과는 역할이 다르다.
- 입력값 한 칸이 2이고 변환 결과의 같은 칸이 0.3이면, 더한 결과는 2.3이다. 모델은 입력에 더할 변화량을 학습한다.

- `block`은 학습할 변환 `F`를 구현한 객체라고 가정한다.
- `+`는 같은 위치의 원소끼리 더하는 연산이다.
- 잔차 연결에서는 두 텐서의 채널 수와 공간 크기를 맞춘다.
- 이 두 줄은 입력을 더하는 핵심 구조를 나타낸다. 실제 ResNet 블록에는 합성곱, BatchNorm, ReLU가 함께 배치된다.

## 6. 지름길 변환과 텐서 크기 맞추기

- 블록이 채널을 늘리거나 공간 크기를 줄이면 `F(x)`와 `x`의 형태가 달라진다.
- 이때 직접 연결에도 1×1 합성곱 등을 적용해 더할 수 있는 형태로 맞춘다.
- Projection(투영) 연결은 이런 추가 변환을 포함한 연결을 가리킨다.

- 두 경로의 값을 더하려면 채널 수와 공간 크기가 같아야 한다. 지름길에 1×1 합성곱을 넣으면 채널을 조합하면서 이동 간격으로 공간 크기도 맞출 수 있다.

**코드 예시**

```python
shortcut = nn.Conv2d(64, 128, kernel_size=1, stride=2)
```

**코드 해설**

- `Conv2d`는 `torch.nn` 모듈의 합성곱 레이어 클래스다.
- 입력 `(N, 64, 16, 16)`을 `(N, 128, 8, 8)`로 바꾼다.
- 1×1 합성곱은 한 위치의 채널 값들을 가중합으로 조합한다.
- `stride=2`는 위치를 두 칸씩 이동하므로 공간 크기도 줄인다.
- 본 경로가 같은 `(N, 128, 8, 8)`을 출력하면 두 경로를 더할 수 있다.

### ResNet50의 병목 블록

- Bottleneck(병목) 블록은 `1×1 → 3×3 → 1×1` 합성곱을 연결한다.
- 첫 1×1은 중간 계산에 사용할 채널 수를 줄인다.
- 3×3은 줄어든 채널에서 공간 관계를 계산한다.
- 마지막 1×1은 필요한 출력 채널 수로 바꾼다.
- 공간 계산을 더 적은 채널에서 수행하므로 계산량을 조절할 수 있다.
- 이 본 경로의 결과에 형태를 맞춘 입력 경로를 더한다.

## 7. 전역 평균 풀링과 분류기 입력

- VGG처럼 2×2 풀링을 다섯 번 적용하면 공간 크기가 다섯 번 절반으로 줄어든다.
- 224×224 입력은 7×7, 32×32 입력은 1×1이 된다.
- 직접 만든 모델에서 이 값을 바로 펼쳐 Linear에 넣으면 입력 이미지 크기에 따라 Linear의 입력 특성 수가 달라진다.
- 예를 들어 채널이 512이면 7×7 출력은 25,088개, 1×1 출력은 512개 값이다.

### torch.nn 모듈의 AdaptiveAvgPool2d 클래스의 활용

- 전역 평균 풀링은 채널마다 위치별 값을 평균하여 이미지 전체의 특징을 하나로 요약한다. 공간 크기와 관계없이 채널 수에 맞는 분류기 입력을 만들 수 있다.

**코드 예시**

```python
pool = nn.AdaptiveAvgPool2d((1, 1))
classifier = nn.Linear(512, 100)
```

**코드 해설**

- 첫 줄은 채널마다 공간 값을 하나로 줄이는 풀링을 준비한다. 둘째 줄은 펼친 특징 512개를 클래스 점수 100개로 바꿀 분류기를 준비한다.

- `AdaptiveAvgPool2d((1, 1))`는 채널마다 공간 전체를 평균해 값 하나를 만든다.
- 입력이 `(N, 512, H, W)`이면 출력은 `(N, 512, 1, 1)`이다.
- 배치 축을 남기고 펼치면 `(N, 512)`가 되어 분류기에 전달할 수 있다.
- torchvision의 ResNet은 최종 분류 전 이런 전역 평균 풀링을 사용한다.
- torchvision의 기본 VGG는 분류기 앞에 7×7을 만드는 적응형 풀링이 있다. 작은 입력용으로 직접 만든 VGG와 분류기 입력 크기를 구분해서 읽는다.

## 8. 모델 구조와 사전학습 가중치

- Pretrained model(사전학습 모델)은 다른 데이터에서 이미 가중치를 학습한 모델이다.
- Transfer learning(전이학습)은 그 가중치를 새로운 문제의 출발점으로 사용하는 방법이다.
- 모델 구조를 생성하는 것과 사전학습 가중치를 채우는 것은 서로 다른 선택이다.

### torchvision.models 모듈의 resnet50 함수의 활용

- 모델 구조와 가중치는 함께 예측 계산을 결정한다. 아래에서는 ResNet50의 연결 구조와 출력 클래스 수를 정하고, 가중치는 초기값에서 시작하도록 만든다.

**코드 예시**

```python
from torchvision.models import resnet50

model = resnet50(weights=None, num_classes=100)
```

**코드 해설**

- `resnet50(...)`을 호출하면 여러 레이어가 연결된 모델 객체가 만들어진다. 이후 `model(x)`로 이미지 배치를 넣으면 이미지마다 클래스 100개의 점수를 계산한다.

- `resnet50`은 함수다. 반환값인 `model`은 PyTorch의 모델 객체다.
- `weights=None`은 사전학습 가중치를 사용하지 않고 초기화한 모델을 만든다.
- `num_classes=100`은 출력 클래스 수를 100개로 지정한다.
- 사전학습 가중치를 사용할 때는 그 가중치에 맞는 입력 크기와 정규화 방법도 함께 적용한다.
- `torch.hub` 모듈의 함수인 `load`는 저장소에 정의된 모델 진입점을 통해 모델을 불러오는 방식이다. torchvision의 모델 생성 함수와 구분해서 읽는다.
- 모델을 생성하는 코드를 읽을 때는 가중치 선택, 입력 변환, 마지막 분류기 구성을 확인해야 현재 계산을 이해할 수 있다.

## 9. CNN 구조를 해석하는 순서

1. 입력 이미지의 배치·채널·높이·너비를 확인한다.
2. 합성곱 블록마다 채널 수와 공간 크기가 어떻게 바뀌는지 따라간다.
3. VGG에서는 반복되는 작은 합성곱과 풀링을 찾는다.
4. ResNet에서는 본 경로와 입력을 더하는 경로를 찾는다.
5. 두 경로를 더하는 지점의 형태가 같은지 확인한다.
6. 마지막 풀링과 펼치기 결과가 분류기의 입력 수와 맞는지 확인한다.
7. 최종 출력 수가 예측할 클래스 수와 같은지 확인한다.
