## 1. 과적합과 규제를 배우는 이유

- 학습 자료에는 반복해서 나타나는 관계와 우연히 들어간 잡음이 함께 있다.
- 모델이 학습 자료의 작은 흔들림까지 맞추면, 조금 다른 새 자료에서는 예측이 크게 빗나갈 수 있다.
- Overfitting(과적합)은 학습 자료에서는 성능이 좋지만 새 자료에서는 성능이 떨어지는 상태다.
- Regularization(규제 또는 정칙화)은 **모델이 지나치게 복잡한 규칙을 학습하지 않도록 제약을 주는 방법**이다.
- L1과 L2 규제는 가중치 크기에 비용을 부과해 학습에 영향을 준다.

---

## 2. 학습 손실과 검증 손실의 차이

- 학습 손실은 모델이 학습 중인 자료를 얼마나 맞추는지 나타낸다.
- 검증 손실은 가중치 학습에 사용하지 않은 자료의 예측 오차다.
- 둘 다 높으면 입력의 정보가 부족하거나 모델이 충분히 학습되지 않은 상태를 살펴본다. 모델이 관계를 충분히 표현하지 못하는 Underfitting(과소적합)일 수도 있다.
- 학습 손실은 계속 낮아지는데 검증 손실은 커지기 시작하면 과적합을 의심한다.
- 모델 크기, 학습 횟수, 규제 강도는 검증 자료로 비교한다. 최종 테스트 자료는 선택한 모델의 평가에 사용한다.

---

## 3. 스케일 조정과 규제의 역할

| 방법 | 무엇을 조정하는가 |
| --- | --- |
| Normalization(정규화)과 표준화 | 입력값의 범위나 크기를 조정한다. 예를 들어 나이와 연봉의 단위를 맞춘다. |
| Regularization(규제) | 모델 학습에 제약을 준다. 예를 들어 큰 가중치에 추가 비용을 부과한다. |

- 선형 모델에서는 입력을 100배 키우고 가중치를 100분의 1로 줄여도 같은 예측값이 나온다.
- 가중치에 벌점을 주는 모델을 비교할 때는 입력의 스케일이 중요하다.
- 입력을 비슷한 스케일로 맞추면 특정 열의 단위 때문에 벌점이 달라지는 영향을 줄일 수 있다.

---

## 4. 예측 오차와 가중치 벌점의 결합

$$L_{total}=L_{prediction}+\lambda R(w)$$

- `L_prediction`은 정답과 예측값의 차이다. 회귀에서는 제곱오차 등을 사용한다.
- `R(w)`는 가중치 크기에 따라 계산하는 벌점이다.
- `λ`는 규제 강도다. 벌점을 얼마나 크게 반영할지 정한다.
- 학습은 예측 오차와 벌점을 합한 값을 줄이는 방향으로 진행된다.
- 예측 오차를 아주 조금 줄이기 위해 가중치를 크게 키우는 선택에는 비용이 생긴다.
- 규제를 너무 강하게 주면 필요한 관계까지 충분히 학습하지 못한다. 검증 손실로 적절한 강도를 찾는다.

---

## 5. L1 규제와 Lasso의 가중치 선택

$$R_{L1}(w)=\sum_j |w_j|$$

- 가중치가 `[2, -1, 0]`이면 L1 벌점은 `2 + 1 + 0 = 3`이다.
- 가중치의 부호와 관계없이 크기를 더한다.
- L1 규제에서는 일부 가중치가 정확히 0이 될 수 있다. 해당 특성의 기여가 식에서 사라지므로 특성을 선택하는 효과가 생긴다.
- 0에서의 절댓값 함수 모양 때문에 최적의 해가 가중치 0에 놓일 수 있다.
- 관련성이 약한 특성이 많이 섞인 선형 모델에서 이런 성질을 활용한다.

### 5-1) 가중치 0이 선택되는 작은 계산 예시

- 가중치가 작아지는 것과 정확히 0이 되는 것을 구분하면 L1의 특성 선택을 이해하기 쉽다.
- 가중치 하나 `w`에 대해, 예측 오차가 가장 작은 위치를 `a`라고 하자.
- 계산을 단순하게 만든 손실은 다음과 같다. 앞부분은 `w`와 `a`의 차이, 뒷부분은 L1 벌점이다.

$$L(w)=\frac{1}{2}(w-a)^2+\lambda|w|$$

- `a=0.3`, 규제 강도 `λ=0.5`로 놓고 몇 가지 값을 비교한다.

| 가중치 w | 예측 오차 + 벌점 |
| --- | --- |
| 0.3 | 0 + 0.15 = 0.15 |
| 0.1 | 0.02 + 0.05 = 0.07 |
| 0 | 0.045 + 0 = 0.045 |

- 이 예시의 최소 손실은 `w=0`에서 나온다. 예측 오차가 조금 늘어도 벌점이 더 크게 줄기 때문이다.
- `w>0`에서 손실의 기울기는 `w - 0.3 + 0.5 = w + 0.2`다. 양수 영역에서는 왼쪽으로 갈수록 손실이 작아진다.
- `w<0`에서 기울기는 `w - 0.3 - 0.5 = w - 0.8`이다. 음수 영역에서는 오른쪽으로 갈수록 손실이 작아진다.
- 양쪽에서 손실이 줄어드는 방향이 0으로 모인다.
- 위 식의 해는 `a`의 크기가 `λ` 이하이면 0, 더 크면 0 쪽으로 `λ`만큼 줄인 값이다.
- 예를 들어 `a=2`, `λ=0.5`이면 최적 가중치는 1.5다. 예측에 필요한 기여가 큰 가중치는 남는다.
- `|w|`의 뾰족한 모양 때문에 일정 범위의 `a`에서 해가 0이 된다. 이것이 이 예시에서 L1이 특성을 선택하는 원리다.

### sklearn.linear_model 모듈의 Lasso 클래스의 활용

- L1 규제는 오차에 가중치 절댓값의 합을 벌점으로 더한다. 학습 뒤 일부 계수가 0이 되면 어떤 특성의 기여가 제거됐는지 확인할 수 있다.

**코드 예시**

```python
from sklearn.linear_model import Lasso

model = Lasso(alpha=0.1)
model.fit(X_train_scaled, y_train)
weights = model.coef_
```

**코드 해설**

- `X_train_scaled`는 학습 자료의 기준으로 스케일을 조정한 입력이라고 가정한다.
- `alpha`는 규제 강도를 정하는 인자다. 값을 키우면 가중치 크기에 대한 벌점이 강해진다.
- `fit`은 예측 오차와 L1 벌점을 함께 고려해 가중치를 구하는 메서드다.
- `coef_`는 학습한 가중치를 담은 속성이다. 0인 계수가 있는지 여기서 확인한다.
- 비슷한 정보를 가진 특성이 여러 개라면 그중 일부의 계수가 0이 될 수 있다. 계수는 다른 입력과 함께 학습한 결과로 해석한다.

## 6. L2 규제와 Ridge의 가중치 축소

$$R_{L2}(w)=\sum_j w_j^2$$

- 가중치가 `[2, -1, 0]`이면 L2 벌점은 `4 + 1 + 0 = 5`다.
- 가중치 1의 비용은 1이고, 가중치 3의 비용은 9다. 큰 가중치의 비용이 더 빠르게 커진다.
- L2는 여러 가중치를 작은 값으로 조정하는 성질이 있다.
- 한두 특성에 매우 큰 계수가 생기는 것을 억제하면 입력의 작은 변화에 예측이 심하게 흔들리는 정도를 줄일 수 있다.

### sklearn.linear_model 모듈의 Ridge 클래스의 활용

- L2 규제는 큰 가중치에 제곱 벌점을 주어 크기를 줄이는 방향으로 학습한다. 아래에서는 같은 스케일의 입력으로 계수를 학습하고 평가 자료를 예측한다.

**코드 예시**

```python
from sklearn.linear_model import Ridge

model = Ridge(alpha=1.0)
model.fit(X_train_scaled, y_train)
y_pred = model.predict(X_test_scaled)
```

**코드 해설**

- `Ridge(alpha=1.0)`이 규제 강도를 정한 모델을 만들고, `fit()`이 계수를 구한다. 마지막 `predict()`는 이 계수로 새 입력의 값을 계산한다.

- `fit`은 예측 오차와 가중치 제곱합을 함께 고려해 계수를 구한다.
- `predict`는 학습한 계수로 평가 자료의 값을 예측한다.
- `X_test_scaled`에는 학습 자료에서 구한 스케일 기준을 적용한다.
- Lasso와 Ridge의 목적함수에는 오차 항의 배율 차이가 있다. 두 모델의 같은 `alpha` 숫자를 같은 규제 강도로 해석하기보다 각각 검증 성능으로 선택한다.

## 7. Pipeline을 이용한 전처리와 모델 연결

### sklearn.pipeline 모듈의 make_pipeline 함수의 활용

- 전처리와 모델을 하나로 묶으면 학습·예측에서 필요한 순서를 함께 관리할 수 있다. 학습 때 구한 표준화 기준을 평가 때 재사용한 뒤 회귀 계산으로 이어진다.

**코드 예시**

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge

model = make_pipeline(StandardScaler(), Ridge(alpha=1.0))
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
```

**코드 해설**

- `make_pipeline()`은 순서가 정해진 처리 객체를 만든다. 여기서는 표준화 객체와 회귀 모델 객체 두 개를 한 객체로 묶는다.
- `fit()`에서는 **평균·표준편차 계산 → 입력 표준화 → Ridge 계수 학습**, `predict()`에서는 **같은 기준으로 표준화 → 학습한 계수로 예측** 순서로 진행된다.

- `Pipeline` 객체는 앞의 변환 결과를 다음 단계에 전달한다.
- 위 코드의 `fit`은 학습 자료에서 표준화 기준을 구하고, 변환한 자료로 Ridge를 학습한다.
- `predict`는 저장된 표준화 기준으로 평가 입력을 바꾸고 Ridge 예측값을 반환한다.
- 평가 입력에 학습 때와 같은 전처리가 적용되므로 코드의 순서와 기준을 유지하기 쉽다.

## 8. 규제 강도와 검증 성능의 해석

1. 규제를 적용하기 전 학습 오차와 검증 오차를 확인한다.
2. 입력 스케일을 맞추고 L1 또는 L2 규제를 적용한다.
3. 규제 강도를 바꾸며 검증 오차가 작은 값을 찾는다.
4. L1에서는 0이 된 계수를, L2에서는 큰 계수가 얼마나 줄었는지 살펴본다.
5. 선택을 마친 모델을 테스트 자료에서 평가한다.

- 규제는 학습 자료를 가장 세밀하게 맞추는 정도와 새 자료를 예측하는 능력 사이의 균형을 조정한다.
